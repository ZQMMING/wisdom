## 三、任铁樵衰旺章的真实逻辑结构

### 原典原文（任氏曰部分，627字符）

> 任氏曰；得时俱为旺论，失令便作衰看，虽是至理，亦死法也。夫五行之气，流行于四时，虽日干各有专令，而其实专令之中，亦有并存者在，如春木司令，甲乙虽旺，而此时休囚之戊巳，亦未尝绝于天地也；冬水司令，壬天虽旺，百此时休囚之丙丁，变未尝绝于天地也。物时当退避，不敢争先，而春实春土何尝不生万物，冬日何尝不照万国乎？况八字虽以月令迷重，而旺相休囚，年日时中，亦有损益之权，故生月即不值令，亦能值年值日值时，岂可执一而论？有如春木虽强，金太重而木亦危；干庚辛而支申酉，无火制而不富，逢土生而必夭，是得时不旺也。秋木虽弱，木根深而木亦强，干甲乙而支寅卯，遇官透而能受，逢水生而太过，是失时不弱也。是故日干不论月令休囚，只要四柱有根，便能受财官食神而当伤官七杀。长生禄旺，根之重者也；墓库余气，奶之轻者也。天干得一比肩，不如地支得一余气墓库。墓者，如甲乙逢未，丙丁逢戌，庚辛逢丑，壬癸辰之类是也。余气者，如丙丁逢未，丙丁逢戌，庚辛逢丑，壬癸逢辰之类是也。余气者，如丙丁逢未，甲乙逢辰，庚辛逢戌，壬癸逢丑之类是也，得二比肩，不如支中得一长生禄旺，如甲乙逢亥寅卯之类是也。盖比肩如朋友之相扶，通根如家室之可托，干多不如根挭，理固然也。今人不知此理，见是春土夏水秋木冬火，不问有根无根，，便谓之弱：见是春木夏火秋金冬水，不究克重克轻，便谓这旺，更有任癸逢辰，丙丁逢戌，甲乙逢未，庚辛逢丑之类，不以为通根峰库，甚至求刑冲以开之，竟不思刑冲伤吾本根之气。此种谬论，必宜一切扫除也。

### 任铁樵的真实旺衰框架（五层）

```
第一层：得时（月令）
  ├─ "得时俱为旺论，失令便作衰看"
  └─ 但强调"得时不旺"、"失时不弱"，不能执一而论

第二层：年日时损益
  ├─ "八字虽以月令为重，而旺相休囚，年日时中，亦有损益之权"
  └─ "生月即不值令，亦能值年值日值时"

第三层：有根/通根（核心判据）
  ├─ "是故日干不论月令休囚，只要四柱有根，便能受财官食神而当伤官七杀"
  ├─ 根之重者：长生禄旺
  └─ 根之轻者：墓库余气

第四层：比肩（党众）
  ├─ "天干得一比肩，不如地支得一余气墓库"
  ├─ "得二比肩，不如支中得一长生禄旺"
  └─ "盖比肩如朋友之相扶，通根如家室之可托，干多不如根重"

第五层：批判时弊
  └─ "今人不知此理...不问有根无根，便谓之弱...竟不思刑冲伤吾本根之气"
```

### 关键发现

1. **任铁樵用"得时"，不用"得令"** — 衰旺章中"得令"这个词一次都没有出现！

2. **"有根/通根"是核心判据** — "只要四柱有根，便能受财官食神而当伤官七杀"，这是任铁樵最核心的论断。

3. **根分轻重** — "长生禄旺，根之重者也；墓库余气，根之轻者也"，这是对根的精确分类。

4. **比肩不如通根** — "天干得一比肩，不如地支得一余气墓库"、"得二比肩，不如支中得一长生禄旺"，任铁樵明确认为通根比比肩（党众/得势）更重要。

5. **"有气"不是旺衰判据** — 衰旺章中"有气"作为旺衰判据完全没有出现！任铁樵讨论的是"得时"、"有根/通根"、"比肩"，而不是"得令"、"得地"、"有根"、"有气"。

## 四、"有气"在滴天髓其他章节的真实用法

虽然"有气"在衰旺章中不是旺衰判据，但在滴天髓其他章节确实出现。基于对all_duanyu.json（2672条滴天髓断语）的搜索，"有气"共出现15次，其用法如下：

### "有气"的真实语义

**"有气"是一个语义载体/状态描述机制，可以作用于不同对象：**
- 日主有气
- 用神有气/无气
- 财星有气
- 官星有气
- 伤官有气
- 某五行有气（如"秋金有气"）
- 调候因素有气（如"暖有气"）

**"有气" ≠ "得令"**
**"有气" ≠ "得地"**
**"有气" ≠ "有根"**
**"有气" 不是与得令、得地、有根并列的旺衰四元组之一！**

"有气"更接近"有基本力量/有源/有支撑"的综合描述，其具体含义取决于对象和语境。
