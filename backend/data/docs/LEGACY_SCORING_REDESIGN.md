# Legacy 年份评分逻辑 Redesign 设计文档

**文件**: `.verify_fortune_v2.py`
**审核函数**: `score_disaster` (L165-181), `score_wealth` (L183-199)
**日期**: 2026-08-27
**背景**: 断事准确率基线中财运/灾劫/运势/官非命中率 0%（总命中 17.6% < 随机 20%），`score_wealth` 只用"流年干对日主十神是财星/食伤+权重"，对"哪一年财运好"无区分度。

## 一、现有逻辑的问题分析

### 1.1 `score_disaster` (L165-181) 的设计缺陷

**现有逻辑摘要**:
```python
# 输入: dm=日主, fs=流年干, fb=流年支, fourb=四柱地支
g = self.ten_god(dm, fs)  # 流年干对日主的十神
if g in ("七杀","劫财","枭神","伤官"): s += 2.0   # 凶神
elif g in ("正官","正印"): s += 0.5               # 吉神

# 地支关系: 流年支与四柱的冲/刑/害
for b in fourb:
    if CLASH.get(fb) == b: s += 1.5
    if (fb,b) in PUNISH: s += 1.5
    if HARM.get(fb) == b: s += 1.0
```

**问题一：十神来源不区分"通根 strength"与"仅天干虚浮"**

《滴天髓》命理核心原则：**"天干仅为一念，地支才见真机"**。流年干的财官吉凶，必须看该流年干是否通根有力。现行逻辑将"虚浮的七杀"与"通根的七杀"等同打分，失真严重。

**问题二：未区分"灾"与"劫"的命理机制差异**

《子平真诠·论岁运》明确区分：
- **灾**：官非口舌、破财小人，属"克泄"类，轻量级
- **劫**：重大灾祸、手术、意外，属"冲战冲犯"类，重量级

现行逻辑将二者混用同一评分，均加 2.0 分，无法区分年份严重程度。

**问题三：冲刑害的"受力方"不区分**

《渊海子平·论岁运并临》："岁运并临，灾福立见"。现行逻辑只检查"流年支冲谁"，不检查"谁在冲流年支"：
- 流年支冲日支（自身受损）≠ 流年支冲年支（祖上/旧人）
- 流年支被四柱紧贴支所冲（流年处于被动受害地位）≠ 流年支主动冲人

**问题四：未引入"岁运并临"经典判断**

《滴天髓·岁运论》："杀在杀地祸已深，财在财乡财自发"。当流年干支均为凶神（并临），或流年干支与日柱形成三刑，其灾祸程度远超普通冲克。

**问题五：未区分七杀/枭神/伤官/劫财的"受灾机制"差异**

| 凶神 | 主要应事 | 必要条件 |
|------|---------|---------|
| 七杀 | 意外、手术、突发 | 必须有印星化或羊刃抗 |
| 伤官 | 官非口舌、破财 | 必须有财星泄或印制 |
| 枭神 | 夺食、损友、陷害 | 逢枭神夺食才应灾 |
| 劫财 | 争财、诉讼、伤病 | 逢劫财见财或冲合才应 |

现行逻辑完全忽视"是否有转化路径"这一关键条件。

### 1.2 `score_wealth` (L183-199) 的设计缺陷

**现有逻辑摘要**:
```python
g = self.ten_god(dm, fs)  # 流年干对日主的十神
if g in ("正财","偏财"): s += 2.5   # 财星
elif g in ("食神","伤官"): s += 1.5 # 食伤
elif g in ("正官","正印"): s += 0.5 # 官印

# 地支关系: 流年支生四柱支 (极弱逻辑)
for b in fourb:
    if GEN.get(BRANCH_ELEM[fb]) == BRANCH_ELEM.get(b):
        s += 0.3
```

**问题一：完全缺失"财星通根/透干"判断——这是最致命缺陷**

《三命通会·论财》："财为养命之源，人命不可无财，然财多身弱则为富屋贫人"。现行逻辑将"日主身强+财星透干通根的流年"与"日主无根+财星虚透的流年"等同打分，均给 2.5 分，完全丧失区分度。

**问题二：缺失"财库"（财库冲开）核心判断**

《渊海子平·论财库》："辰戌丑未为四财库，冲开财库主大发"。这是判断"财运好坏"最直接的信号之一：
- 财库在流年被冲开 → 大财运
- 财库在流年被合住 → 财来财去
- 命中无财库而流年见财库 → 虚财

现行逻辑完全没有这一因子。

**问题三：缺失"食伤生财"路径判断**

《子平真诠·论财》："财星清透则可泄于食伤，食伤生财，流转有情"。只有当命中食伤、财星并存时，流年食伤才能生财；若命中无食伤，流年食伤只是"技艺进益"，与正财无直接关系。

**问题四：缺失"身财两停"（日主与财星力量对比）判断**

《滴天髓·论财》："身旺财衰，剥削最重；财旺身衰，耗窃交加"。只有日主有足够力量承受流年财星，才是真正好财运。当前只判断十神属性，不判断力量对比。

**问题五：缺失"流年支与财星地支关系"判断**

《穷通宝鉴》论财星，看重流年支是否与财星藏支产生反应：
- 流年支为财星之"长生/帝旺" → 财运强劲
- 流年支冲财星之"墓/死" → 破财

现行逻辑只检查流年支是否"生"四柱地支（0.3分），这个判断过于边缘且无古籍依据。

**问题六：缺失"官星护财"判断**

《子平真诠》："官为护身之本，财为养命之源"。有官星流年护住财星（官印化杀生财），才是稳健财运；无官护财则财易散。

## 二、古籍理论依据与评分因子设计

### 2.1 财运年份评分因子（基于《滴天髓》《子平真诠》《三命通会》《渊海子平》《穷通宝鉴》）

#### 因子 F1：财星通根/透干程度（权重建议: 0.30）

**古籍依据**：
- 《滴天髓·论天干》："天干虽旺，不及地支之深固"。财星必须通根才有力量。
- 《子平真诠·论财》："财星虚透天干，不足以言财"。
- 《三命通会·论财》："财星无根，终是贫贱之人；财星有根，虽贫亦可望富"。

**实现逻辑**（用户只有出生时间，无详细时辰精确分：
- 流年干（fs）是否与日主同五行且同阴阳 → 比肩帮身，财星更易保住
- 流年干（fs）的地支藏干是否与 fs 相同或相生（通根程度）
- 若财星通根于月令或日时支 → 高分

**评分建议**：
| 情况 | 得分 |
|------|------|
| 财星透干 + 通根于月令或日支 | +2.5 |
| 财星透干 + 通根于年时支 | +1.8 |
| 财星透干但虚浮无根 | +0.8 |
| 财星不透干但流年支含财星藏干 | +1.2 |

#### 因子 F2：财库冲开/被合（权重建议: 0.25）

**古籍依据**：
- 《渊海子平·论财库》："辰戌丑未为四财库，冲开财库大发财；财库被合，财来财去"。
- 《三命通会》："财库在命中最怕被合住，流年见合，财运阻滞"。
- 《滴天髓》："库藏之物，冲开用神"。

**实现逻辑**：
- 四柱中是否存在财库（辰戌丑未任一含财星）
- 流年是否为财库的冲年（辰冲戌、戌冲辰、丑冲未、未冲丑）
- 流年是否为财库的合年（子丑合、寅亥合、卯戌合、辰酉合、巳申合、午未合）

**评分建议**：
| 情况 | 得分 |
|------|------|
| 命中财库 + 流年冲开财库 | +2.5 |
| 命中财库 + 流年合住财库 | +0.5 |
| 流年支本身为财库 + 财星透干 | +2.0 |
| 命中无财库但流年见财库字 | +0.3（横财性质） |

#### 因子 F3：食伤生财路径（权重建议: 0.20）

**古籍依据**：
- 《子平真诠·论食神》："食神生财，秀气流转"。
- 《穷通宝鉴》："食伤为财之根，无食伤则财无源"。
- 《滴天髓》："伤官伤尽最为奇，伤官生财亦可取"。

**实现逻辑**：
- 命中是否有食伤星（食神/伤官）
- 食伤星与财星的十神关系是否形成相生链
- 流年是否为食伤年（+1.5）或财星年（+2.0）+ 命中食伤存在时

**评分建议**：
| 情况 | 得分 |
|------|------|
| 命中有食伤 + 流年食伤透干 | +1.8（食伤生财年） |
| 命中有食伤 + 流年财星透干 | +2.0（生财有源年） |
| 命中无食伤 + 流年食伤年 | +0.6（才艺进益，非正财） |
| 命中有食伤 + 流年食伤与财星同透 | +2.5（财食两旺年） |

#### 因子 F4：身财平衡（权重建议: 0.15）

**古籍依据**：
- 《滴天髓·论财》："身旺财衰，剥削最重；身财两停，方为上格"。
- 《子平真诠》："日主健旺，财星自然归位；日主衰弱，财星反为祸患"。

**实现逻辑**（有限信息下）：
- 流年干是否为日主的比劫（帮身）→ 提升身财平衡
- 流年干是否为日主的印星（印助身）→ 身变强
- 日主在流年是否得令（流年支与月令关系）
- 若无法精确时柱，可用年柱和月令近似判断身强弱

**评分建议**：
| 情况 | 得分 |
|------|------|
| 流年比劫助身 + 财星年 | +1.5 |
| 流年印星助身 + 财星年 | +1.3 |
| 流年食伤泄身 + 财星年（日主偏弱） | +0.5 |
| 流年官杀克身 + 财星年（日主已弱） | -1.0（财多身弱） |

#### 因子 F5：流年支与财星地支的关系（权重建议: 0.10）

**古籍依据**：
- 《穷通宝鉴·论四季取用》："春木财为用，喜见火土；冬水财为用，喜见木火"。
- 《渊海子平》："财星最怕见墓绝，逢之破耗多端"。

**实现逻辑**：
- 流年支是否为财星的长生、帝旺位（在财星旺相之地）
- 流年支是否为财星的死、墓、绝位（财星失令）
- 流年支与命中财星藏支是否产生冲合

### 2.2 灾劫年份评分因子

#### 因子 D1：凶神通根程度（权重建议: 0.35）

**古籍依据**：
- 《滴天髓》："杀无印以化者，非伤即灾"。
- 《子平真诠·论七杀》："七杀必须印化或刃制，否则祸不可测"。

**实现逻辑**：
- 流年七杀/伤官/枭神/劫财是否通根有力
- 通根的七杀祸患远大于虚透的七杀
- 有印星化或羊刃抗时，灾祸减轻

**评分建议**：
| 情况 | 得分 |
|------|------|
| 凶神透干 + 通根有力 + 无转化（无印/刃） | +3.0 |
| 凶神透干 + 通根有力 + 有印星可化 | +1.5 |
| 凶神透干 + 虚浮无根 | +0.8 |
| 凶神不透干 + 流年支含凶神藏干 | +1.2 |

#### 因子 D2：岁运并临（权重建议: 0.25）

**古籍依据**：
- 《渊海子平·论岁运并临》："岁运并临，灾福立见，凶者更凶，吉者更吉"。
- 《滴天髓》："并临之年，十有九凶，唯用神清晰者可解"。

**实现逻辑**：
- 流年干支均为同一凶神（七杀/劫财并临）
- 流年干支与日柱或时柱形成三刑
- 流年与命中年柱天克地冲

**评分建议**：
| 情况 | 得分 |
|------|------|
| 岁运并临（干支同凶神） | +3.5 |
| 流年与日柱三刑（寅巳申/丑戌未） | +2.5 |
| 流年与年柱天克地冲 | +2.0 |
| 流年与命局形成循环三刑 | +3.0 |

#### 因子 D3：冲克日支/日主的力度（权重建议: 0.20）

**古籍依据**：
- 《子平真诠》："日支被冲，灾祸立至；冲力越大，灾祸越重"。
- 《穷通宝鉴》："冲有吉凶，动有真假，真冲祸重，假冲祸轻"。

**实现逻辑**：
- 流年支冲日支（自身最直接）> 流年支冲月支（主气）
- 紧贴之冲（流年支冲时支最近）> 间隔之冲
- 冲中带克（七杀冲日支）> 单纯冲

**评分建议**：
| 情况 | 得分 |
|------|------|
| 流年支直接冲日支 + 凶神主导 | +2.5 |
| 流年支直接冲日支 + 吉神主导 | +1.0 |
| 流年支冲月支（紧贴） | +1.5 |
| 流年支冲年支 | +1.0 |
| 流年支冲时支（日主受损） | +2.0 |

#### 因子 D4：凶神类型与转化路径（权重建议: 0.15）

**古籍依据**：
- 《子平真诠》："七杀无制为仇杀，枭神夺食为损友，伤官见官为官非，劫财见财为争盗"。

**实现逻辑**：
| 凶神 | 必要条件 | 加分条件 | 减分条件 |
|------|---------|---------|---------|
| 七杀 | 无印化/无羊刃抗 | +2.0 | 有印化-1.5 |
| 伤官 | 无财泄/无印制 | +1.8 | 有印制-1.0 |
| 枭神 | 命中无食神/食神弱 | +1.8 | 有食神护-1.2 |
| 劫财 | 命中见财星/冲合财星 | +2.0 | 无财可争-0.5 |

#### 因子 D5：受害方的力量（权重建议: 0.05）

**古籍依据**：
- 《滴天髓》："旺者冲衰衰者拔，衰者冲旺反伤己"。

**实现逻辑**：
- 日主/日支在流年的力量状态（得令还是失令）
- 若日主得令，即使逢凶神冲也不致大灾
- 若日主失令，凶神加乘

## 三、与现有逻辑的对比

### 3.1 核心差异总览

| 维度 | 现有逻辑 | Redesign 逻辑 |
|------|---------|--------------|
| **十神评分基础** | 流年干对日主十神（+2.0/2.5） | 十神 + 通根程度 + 转化路径 |
| **力量对比** | 无 | 身财平衡、身杀平衡 |
| **地支关系** | 冲/刑/害笼统加分 | 区分"冲日支"vs"冲他支"，并区分受力方 |
| **财库判断** | 无 | 核心因子（权重0.25） |
| **食伤生财路径** | 无 | 核心因子（权重0.20） |
| **岁运并临** | 无 | 独立高权重因子（权重0.25） |
| **凶神转化路径** | 无 | 区分有印化/有刃抗 vs 无转化 |
| **流年支对财星影响** | 仅"生"四柱（0.3分） | 财星长生/帝旺/死墓位 |

### 3.2 现有逻辑的根本性问题

**问题根源**：现行评分逻辑是"十神标签 + 简单冲合"，属于**静态规则**，完全缺少：

1. **十神 strength 判断**（通根 vs 虚透）
2. **五行生克流转路径**（食伤生财路径、官星护财路径）
3. **命局结构特征**（财库是否存在、日主身强身弱）
4. **凶神的可化解性**（有印无印、有刃无刃）
5. **流年支对财星地支的精确关系**（长生/帝旺/死墓）

这导致的结果是：**所有流年在这套评分体系下得分高度集中于少数几个离散的分数（2.0/2.5/3.0），无法有效区分具体哪一年更好或更差**，因此多选年题无法排序，命中率接近 0%。

### 3.3 有限信息约束下的设计边界

用户只有"出生时间+出生地+生活地"，不提供时辰精确分，也无法提供行业/事件。

**在此约束下可获取的判断**：
- ✅ 年柱、月柱、日主、日支（可算）
- ✅ 流年干支四柱（可算）
- ✅ 十神关系（可算）
- ✅ 流年与四柱的冲合刑害（可算）
- ✅ 财库是否存在（可算）
- ✅ 食伤是否存在（可算）
- ❌ 时柱精确旺度（无法精确）
- ❌ 纳音五行（可用但不精确）
- ❌ 大运（需要时辰精确）

**设计原则**：在有限信息下，优先使用**结构是否存在**（财库有无、食伤有无、凶神是否有转化路径）而非精确力量计算，作为主要区分因子。

## 四、Proposed Scoring Algorithm（伪代码）

### 4.1 `score_wealth_redesign`

```python
def score_wealth_redesign(self, dm, fs, fb, fourb, chart):
    score = 0.0
    # F1: 财星通根程度 (0.30)
    f1 = self._wealth_stem_root_strength(fs, fb, chart)
    score += f1 * 0.30

    # F2: 财库冲开/合 (0.25)
    f2 = self._wealth_vault_opening(fb, chart)
    score += f2 * 0.25

    # F3: 食伤生财路径 (0.20)
    f3 = self._food_wealth_path(fs, chart)
    score += f3 * 0.20

    # F4: 身财平衡 (0.15)
    f4 = self._body_wealth_balance(dm, fs, fb, chart)
    score += f4 * 0.15

    # F5: 流年支与财星地支关系 (0.10)
    f5 = self._branch_wealth_relationship(fb, chart)
    score += f5 * 0.10

    return score
```

### 4.2 `score_disaster_redesign`

```python
def score_disaster_redesign(self, dm, fs, fb, fourb, chart):
    score = 0.0
    # D1: 凶神通根程度 (0.35)
    d1 = self._evil_god_strength(fs, fb, chart)
    score += d1 * 0.35

    # D4: 凶神类型与转化路径 (0.15)
    d4 = self._evil_god_transformation(fs, fb, chart)
    score += d4 * 0.15

    # D5: 受害方力量 (0.05)
    d5 = self._victim_strength(fb, chart)
    score += d5 * 0.05

    return score
```
