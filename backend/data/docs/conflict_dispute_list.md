## 二、高冲突等级争议（需重点裁决）

### 🔴 冲突 1：旺衰优先 vs 调候优先

**涉及经典**: 滴天髓 (DTS) vs 穷通宝鉴 (QTBJ)

**核心矛盾**:
- **滴天髓立场**: 以日主旺衰为根本，旺衰决定用神取向
  - "须观日主之衰旺，察生时之浅深，究四柱之用神，以论吉凶" (DTS_0324)
  - "人之日主不必生逢禄旺，即月令休囚，而年时日中，得长生禄旺，便不为弱" (DTS_0324)

- **穷通宝鉴立场**: 以月令调候为优先，季节气候决定用神选择
  - "秋月之木，气渐凄凉...初秋之时，火气未除，尤喜水土以相滋" (QTBJ_0010)
  - 逐月论述十干取用，以月令为纲

**冲突场景示例**:
```
某命：甲日生于申月（秋季）
- 滴天髓视角：秋木凋零，日主偏弱，宜水木帮身
- 穷通宝鉴视角：秋月金旺，需火炼金，优先用火
```

**调和方案**:
- 徐乐吾（《滴天髓阐微》）："旺衰为体，调候为用"
- 建议：先论旺衰定基调，再论调候定细节
- **待裁决**: 优先级规则需要明确定义

**冲突证据数量**: ~50条

---

### 🔴 冲突 2：取用神标准差异

**涉及经典**: 子平真诠 (PZZQ) vs 渊海子平 (YHZP)

**核心矛盾**:
- **子平真诠立场**: "用神专求月令"——格局成败取决于月令用神
  - "凡看命者，先观用神之何属，然后或顺或逆" (PZZQ_0030)
  - 强调月令透干为用神来源

- **渊海子平立场**: 注重日主自身状态——身强身弱决定用神取向
  - "此命身旺...乃贵而有权" / "此命身弱...宜乎带病贫薄" (YHZP_0488, YHZP_0489)
  - 综合判断，未形成系统的月令用神理论

**冲突场景示例**:
```
某命：甲日生于酉月（正官格）
- 子平真诠：月令正官为用神，看相神配合
- 渊海子平：先看日主强弱，再定取用
```

**调和方案**:
- 月令定格局，日主定强弱，二者结合
- **待裁决**: 当两者结论相反时的取舍规则

**冲突证据数量**: ~15条

### 🔴 冲突 3：方法论分歧（简化 vs 精细）

**涉及经典**: 滴天髓 (DTS) vs 子平真诠 (PZZQ)

**核心矛盾**:
- **滴天髓立场**: 批判简化，反对奇格异局，主张回归用神本质
  - "看奇格异局，一切神杀，荒唐取用...非关命理体咎" (DTS_0004)
  - 批判将财官字面化理解："不知财官等名，为六亲取用而列，竟认作财可养命，官可荣身"

- **子平真诠立场**: 精细发展，完善格局成败救应体系
  - "相神无破，贵格已成；相神有伤，立败其格" (PZZQ_0055)
  - 建立完整的"成-败-救"分析框架

**冲突本质**:
| 维度 | 滴天髓 | 子平真诠 |
|------|--------|----------|
| 学术定位 | 批判反思派 | 精细发展派 |
| 核心主张 | 回归本源，反对繁复 | 完善体系，注重实操 |
| 方法论 | 一元用神论 | 格局成败救应 |

**调和方案**:
- 批判性吸收：滴天髓的简朴哲学 + 子平的精细方法
- **待裁决**: 如何在系统架构中平衡简化与精细

**冲突证据数量**: ~8条

## 三、中冲突等级争议

### 🟡 冲突 4：格局判定标准

**涉及经典**: 子平真诠 (PZZQ) vs 渊海子平 (YHZP)

**核心矛盾**:
- **子平真诠**: 二分法——正格 vs 杂格（偏格）
  ```
  正格（八格）：
    财、官、印、食 → 顺用
    杀、伤、枭、刃 → 逆用
  
  杂格（外格）：
    从格、化格、专格等
  ```

- **渊海子平**: 三分法——清格、浊格、混合格
  ```
  清格：纯而不杂
  浊格：混杂不清
  混合格：介于两者之间
  ```

**冲突场景**: 同一命局，PZZQ可能判为杂格，YHZP可能判为结构混

**调和方案**: 建立更细致的分类体系，吸收两派优点
**待裁决**: 分类标准采用哪一派，或创建第三方案

**冲突证据数量**: ~10条

---

### 🟡 冲突 5：五行流通观分歧

**涉及经典**: 滴天髓 (DTS) vs 三命通会 (SMTH)

**核心矛盾**:
- **滴天髓**: 五行之气偏全流通论
  - "特五行之气有偏全，故万物之命有吉凶" (DTS_0231)
  - 承认流通转化

- **三命通会**: 五行种性独立论
  - "金有金之种，木有木之种...各各完具不相假借" (SMTH_0010)
  - 强调独立不变

**冲突本质**: 偏全论承认流通，种性论强调独立

**调和方案**: 需进一步实证检验
**待裁决**: 哪一派更符合命理实践？

**冲突证据数量**: ~3条

## 四、低冲突等级争议

### 🟢 冲突 6：阴阳生死观分歧

**涉及经典**: 滴天髓 (DTS) vs 世俗说法

**核心矛盾**:
- **世俗说法**: 阳生阴死，阳死阴生
  - （滴天髓引俗说作为批判对象）

- **滴天髓**: 阴阳同生同死
  - "至于长生沐浴等名，乃假借形容之辞也...古法只有四长生，从无子午卯酉为阴长生之说" (DTS_0324)
  - "由此观之，阴阳同生同死可知也"

- **子平真诠**: 得时不旺失时不弱
  - 以"得时失时"替代阴阳生死说

**冲突本质**: 是否承认阴阳长生理论的不同解释

**调和方案**: 滴天髓的修正观点已被广泛接受
**待裁决**: 确认采用滴天髓修正说

**冲突证据数量**: ~2条
