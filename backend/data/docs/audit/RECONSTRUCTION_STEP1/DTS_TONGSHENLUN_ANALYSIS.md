## 逐句分析

### 第一章：天道
```
原文：欲识三元万法宗，先观帝载与神功。
任注：三元者，天干也。帝载者，天道也。神功者，地道也。
分类：A类（明确判断）
Primitive候选：三元、帝载、神功
关系：认识方法论，非条件判断
```

### 第二章：地道
```
原文：坤元合德机缄通，五气偏全定吉凶。
任注：坤元者，地势也。五气者，五行也。偏全者，得偏得全也。
分类：A类（明确判断）
Primitive候选：坤元、五气、偏全
关系：吉凶由五行偏全决定
```

### 第三章：人道
```
原文：戴天履地人为贵，顺则吉兮凶则悖。
任注：人禀天地之气以生，故人为贵。顺者，顺天地之气也。
分类：A类（明确判断）
Primitive候选：人为贵、顺逆
关系：顺则吉，悖则凶
```

### 第四章：知命
```
原文：要与人间开聋聩，顺逆之机须理会。
任注：命之理奥，非明言不能晓。顺逆之机，尤当理会。
分类：B类（建议性原则）
Primitive候选：顺逆之机
关系：建议性陈述，非条件判断
```

### 第五章：理气
```
原文：理承气行岂有常，进兮退兮宜抑扬。
任注：理者，天命之性也。气者，流行之用也。理随气行，无一定之常。
分类：B类（描述性原则）
Primitive候选：理、气、进退出入
关系：描述理气关系，非条件判断
```

### 第六章：配合
```
原文：配合干支仔细详，定人祸福与灾祥。
任注：干支配合，有君臣、有宾主、有救应、有化格，须仔细详之。
分类：B类（建议性原则）
Primitive候选：配合、君臣、宾主、救应、化格
关系：建议仔细分析配合，非明确条件判断
```

### 第七章：天干（重点）
```
原文：五阳皆阳丙为最，五阴皆阴癸为至。
任注：丙火纯阳，癸水纯阴，皆其至极者也。
分类：A类（明确判断）
Primitive候选：五阳、五阴、丙、癸
关系：明确属性判断

原文：五阳从气不从势，五阴从势无情义。
任注：五阳得阳之气，即能成乎阳刚之势，不畏财杀之势；五阴得阴之气，即能成乎阴顺之义，故木盛则从木，火盛则从火...
分类：A类（明确判断）
Primitive候选：从气、从势、五阳、五阴
关系：明确的条件判断 - "五阳从气不从势"
```

### 第八章：地支（重点）
```
原文：阳支动且强，速达显灾祥。阴支静且专，否泰每经年。
任注：阳支子寅辰午申戌，其性动，其势强；阴支丑卯巳未酉亥，其性静，其气专。
分类：A类（明确判断）
Primitive候选：阳支、阴支、动、静
关系：明确的属性判断

原文：生方怕动库宜开，败地逢冲仔细推。
任注：寅申巳亥为生方，忌冲动；辰戌丑未为库，宜冲开；子午卯酉为败地...
分类：B类（建议性原则）
Primitive候选：生方、库、败地
关系：建议性原则，非明确条件判断
```

### 第九章：衰旺（核心章节）⚠️
```
原文：能知衰旺之真机，其于三命之奥，思过半矣。
任注：旺衰二字，不仅论日主，要分气势之旺衰。
分类：B类（描述性原则）
Primitive候选：衰旺、真机
关系：描述性陈述，非条件判断

原文：旺则宜泄宜伤，衰则喜帮喜助。
任注：形全宜损，形缺宜补之说，即子平「旺则宜泄宜伤，衰则喜帮喜助」之谓也...
分类：B类（建议性原则）⚠️
Primitive候选：旺、宜、泄、伤、衰、喜、帮、助
关系：这是B类语句！"宜"和"喜"是建议性表述，不是条件判断！

原文：然旺中有衰者存，不可损也；衰中有旺者存，不可益也。
任注：旺之极者不可损，以损在其中矣；衰之极者不可益，以益在其中矣。
分类：B类（描述性原则）
Primitive候选：旺中衰、衰中旺
关系：描述性原则

原文：旺之可损，以损在其中矣；衰之极者不可所当损者而损之，反凶。
分类：B类（建议性原则）
关系：建议性表述
```

### 第十章：中和
```
原文：有病方为贵，无伤不是奇。格中如去病，财禄两相宜。
任注：命之有病有伤，乃其真机所在。有病方为贵，无伤不是奇者，言有病之格反贵也。
分类：A类（明确判断）
Primitive候选：病、伤、格
关系：明确的条件判断
```

## 关键发现

### 发现1：B类语句占多数
《通神论》大部分内容是描述性和建议性的，不是明确的条件判断。

### 发现2："旺衰"篇全是B类
"旺则宜泄宜伤，衰则喜帮喜助"是B类语句，不能升级为A类判断。

### 发现3：真正的A类语句有限
只有少数句子是明确的条件判断，如：
- "五阳从气不从势，五阴从势无情义"
- "有病方为贵，无伤不是奇"

### 发现4：格局概念缺失
《通神论》没有讨论"成格"、"破格"等格局判断，这些是子平真诠的内容。
