### 3. A类Condition真实性验证

这是GPT裁决强调的重点！

#### 3.1 Condition来源验证

- [ ] 原典是否明确给出了Condition？

#### 3.2 重点怀疑对象
以下A类语句的Condition设计需要重点验证：

**示例1**："五阳从气不从势"
- 当前设计：日主为五阳之一 + 四柱阳气盛 → 从气不从势
- 问题：原典是否明确说"阳气盛"是条件？
- 原典原文：仅说"五阳从气不从势，五阴从势无情义"
- 风险：可能工程人员补充了"阳气盛"条件

**示例2**："有病方为贵"
- 当前设计：有病因 + 去病 → 贵
- 问题：原典是否明确定义了"病"和"去病"的条件？
- 风险：可能工程人员自己补充了条件

**示例3**："坤元合德机缄通"
- 当前设计：五气偏全 → 吉凶
- 问题：原典是否明确"五气偏全"的判断标准？
