## 生产流程

### 单条断言生产协议

```
1. 原典检索 → 定位五部经典原文
2. Evidence提取 → passage_id + raw_text + text_layer
3. Primitive构建 → 最小语义单元
4. Condition定义 → 可验证的条件表达式
5. Assertion创建 → 完整Canonical Assertion
6. Claude审计 → 独立验证原典一致性
7. GPT裁决 → 最终授权
8. 测试添加 → 验证Condition Evaluator逻辑
9. 提交commit → 记录审计追踪
```

### 批量生产协议

**禁止**: 无审计批量生产
