## 核心理念转变

### 旧模式（错误）
```
Schema定义 → 写代码 → 找原典背书 → 声称生产
```
**问题**：由Schema决定什么可计算，不是由原典决定。

### 新模式（正确）
```
原典挖掘 → 语义分析 → A/B分类 → 提取Primitive → 验证授权 → 写代码
```
**原则**：由原典决定什么可计算，不是由Schema决定。

## 执行步骤

### Step 1: 原典挖掘（当前阶段）
**目标**：深度挖掘五部经典，建立原文-语义-关系的三层结构

#### 1.1 选取重点章节
- 《滴天髓·通神论》全文
- 《子平真诠》格局篇
- 《穷通宝鉴》调候篇
- 《三命通会》专题论
- 《渊海子平》基础论

#### 1.2 逐句提取
对每个句子：
1. 标注原文位置
2. 提取关键概念（Primitive候选）
3. 分类A/B（条件判断 or 描述原则）
4. 验证术语来源
5. 检查逻辑关系

#### 1.3 产出物
- `docs/audit/CLASSICAL_TEXT_ANALYSIS.md` - 原文分析记录
- `data/canonical/primitives.json` - Primitive库（待验证）
- `data/canonical/relationships.json` - 原典关系库（待验证）

---

### Step 2: 语义单元提取
**目标**：从原文中提取真正可计算的语义单元

#### 2.1 Primitive提取标准
- [ ] 术语必须来自原典（非现代工程术语）
- [ ] 概念必须在原典中有明确定义
- [ ] 判断必须可被Canonical State确定表达
- [ ] 如果是B类语句，只能提取为GuidanceAtom

#### 2.2 分类处理
**A类语句**（明确条件→结论）：
- 可以形成Production Primitive
- 可以形成Condition
- 可以形成Judgment

**B类语句**（描述/原则/建议）：
- 只能形成GuidanceAtom
- 只能形成Evidence
- 不能自动升级为A类判断

---

### Step 3: 原典关系验证
**目标**：验证Primitive之间的逻辑关系是否由原典授权

#### 3.1 关系类型
- **AND关系**：原典是否明确说"A且B则C"？
- **OR关系**：原典是否明确说"A或B则C"？
- **SEQUENCE关系**：原典是否明确说"先A后B则C"？

#### 3.2 验证方法
对每个Composite关系：
1. 找到原典中明确授权该关系的原文
2. 如果是A类语句，记录具体位置
3. 如果是B类语句，标注为Research Only
4. 如果没有明确授权，返回Step 2重新提取

---

### Step 4: 小规模重建（最多3条）
**目标**：选取有强原典支持的断言，按新规范重建

#### 4.1 选取标准
- 必须有明确的A类原典语句
- Primitive必须来自原典术语
- Composite关系必须有原典授权
- 不涉及L4力量问题

#### 4.2 重建流程
1. 编写原典核验报告（使用v2.0 checklist）
2. Claude独立语义审计
3. GPT最终裁决
4. 通过后再考虑生产代码

## 重点研究对象

### 《滴天髓·通神论》优先章节

#### 17. 衰旺篇
- 原文："能知衰旺之真机，其于三命之奥，思过半矣。"
- 原文："旺则宜泄宜伤，衰则喜帮喜助"
- **分类**：这是B类语句（建议性原则）
- **处理**：只能形成GuidanceAtom，不能形成Production Judgment

#### 7. 天干篇
- 原文："五阳从气不从势，五阴从势无情义"
- **分类**：这是A类语句（明确判断）
- **处理**：可以考虑作为Production Primitive

#### 12. 独象篇
- 原文："独象喜行化地，而化神要昌"
- **分类**：这是B类语句（描述性原则）
- **处理**：只能形成GuidanceAtom

#### 13. 方局篇
- 原文："方是方兮局是局，要得方，莫混局"
- **分类**：这是A类语句（明确判断）
- **处理**：可以考虑作为Production Primitive

## 禁止事项（硬性约束）

### 禁止1：B类→A类自动升级
**禁止**将"旺则宜泄宜伤"自动升级为"旺→成格"。

### 禁止2：术语混用
**禁止**将滴天髓的"旺衰"概念等同于子平的"格局"概念。

### 禁止3：L4后门恢复
**禁止**引入`KE_XIE_HAO_DOMINANT`等力量比较Primitive。

### 禁止4：先写代码后找原典
**禁止**先有程序结构，再找原典给程序结构背书。
