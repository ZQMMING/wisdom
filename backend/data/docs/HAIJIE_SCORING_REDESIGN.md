# 灾劫/运势/官非 年份评分因子重设计文档

**文件**: `docs/HAIJIE_SCORING_REDESIGN.md`
**背景**: 断事准确率基线中，灾劫/运势/官非三类命中率均为 0%。根本原因：`score_disaster`（及 legacy `.verify_fortune_v2.py` 中的同函数）仅用"流年干十神标签 + 四柱冲刑害"粗评分，无区分度。本设计将灾劫、运势、官非三类拆分为独立评分路径，每条路径引入古籍依据的精细化因子。
**日期**: 2026-08-27
**状态**: 只读分析，不修改生产代码

---

## 一、问题根因总结

### 1.1 当前 `score_disaster` 的实际逻辑

```python
def score_disaster(self, dm, fs, fb, fourb):
    s = 0.0
    g = self.ten_god(dm, fs)
    if g in ("七杀", "劫财", "枭神", "伤官"): s += 2.0   # 凶神一视同仁
    elif g in ("正官", "正印"): s += 0.5
    for b in fourb:
        if CLASH.get(fb) == b: s += 1.5   # 冲
        if (fb,b) in PUNISH: s += 1.5     # 刑
        if HARM.get(fb) == b: s += 1.0    # 害
    return s
```

### 1.2 导致 0% 命中的四个致命缺陷

| 缺陷 | 表现 | 古籍依据缺失 |
|------|------|------------|
| **A. 凶神不分通根与虚浮** | 流年干"七杀"无论有无根气一律 +2.0 | 《滴天髓》："天干虚浮，不足为患；地支有根，方成其害" |
| **B. 灾/劫/官非不分类** | 三者共用同一评分，无法区分应事类型 | 《子平真诠》明确区分灾（小凶）、劫（大凶）、官非（特定组合） |
| **C. 未检查凶神是否有转化路径** | 七杀有印化、劫财有财泄，灾难可解；现行逻辑不检查 | 《子平真诠》："七杀有印化则贵，无印化则灾" |
| **D. 忽略岁运并临/三刑/天克地冲等高阶信号** | 这些是灾年最强信号，完全缺失 | 《渊海子平》："岁运并临，灾福立见" |

## 二、三类主题的定义与古籍依据

### 2.1 灾劫 vs 运势 vs 官非 的命理定义

| 主题 | 核心定义 | 古籍出处 |
|------|---------|---------|
| **灾劫** | 重大灾祸：意外、手术、疾病、破大财、人员伤亡 | 《滴天髓》："杀临旺地而无制，必有血光之灾" |
| **运势** | 广义吉凶趋势：是否"顺"或"逆"，包含好坏两面 | 《穷通宝鉴》："岁运相合，吉凶可见" |
| **官非** | 诉讼、口舌、官职变动、行政处罚 | 《子平真诠》："伤官见官，为祸百端" |

### 2.2 为何当前逻辑对三类均 0% 命中

- **灾劫**：只看七杀/劫财，不看是否通根、不看是否有印化/刃制 → 大量假阳性
- **运势**：完全没有"运势好坏"的概念，只有"凶"与"非凶"二分 → 无法判断哪年更顺
- **官非**：伤官见官是核心机制，但当前逻辑把伤官直接当凶神 +2.0，不检查是否有官星存在 → 条件缺失

## 三、灾劫年份评分因子设计

### D1. 凶神通根程度（权重: 0.30）

**古籍依据**：
- 《滴天髓·通神论》："天干一字，须地支根苗；根苗若实，势力方真"
- 《子平真诠·论七杀》："杀逢根气，方为真杀；杀虚浮者，不足为患"

**实现逻辑**：
1. 流年干（fs）在四柱地支中是否有同五行的藏干（通根）
2. 通根于月令 > 通根于日支 > 通根于年/时支 > 无根（虚浮）
3. 通根程度越高，凶性越大

**评分表**：
| 情况 | 得分 |
|------|------|
| 凶神透干 + 通根于月令 | +3.0 |
| 凶神透干 + 通根于日支 | +2.5 |
| 凶神透干 + 通根于年/时支 | +1.8 |
| 凶神透干但无根（虚浮） | +0.8 |
| 凶神不透干 + 流年支含凶神藏干 | +1.2 |

---

### D2. 岁运并临 / 三刑 / 天克地冲（权重: 0.25）

**古籍依据**：
- 《渊海子平·论岁运并临》："岁运并临，灾福立见，不死自己，必死他人"
- 《滴天髓》："三刑带来非轻，岁运并临祸患深"
- 《三命通会》："天克地冲，其灾立至"

**实现逻辑**：
1. **岁运并临**：流年干支与日柱干支完全相同（如日柱甲子，流年也是甲子）
2. **三刑**：流年与命局形成寅巳申三刑、丑戌未三刑、子卯相刑
3. **天克地冲**：流年干与日主天克（阴阳相反且相克），流年支与日支相冲

**评分表**：
| 情况 | 得分 |
|------|------|
| 岁运并临（干支同） | +3.5 |
| 流年与命局形成完整三刑（如寅巳申） | +3.0 |
| 流年与日柱天克地冲 | +2.5 |
| 流年与日柱单天克或单地冲 | +1.5 |
| 流年与年柱天克地冲 | +2.0 |

---

### D3. 冲克日支力度（权重: 0.20）

**古籍依据**：
- 《子平真诠·论岁运》："日支为配偶宫，亦为自身根基，被冲则根基动摇"
- 《穷通宝鉴》："冲有真假，真冲力大，假冲力微"

**实现逻辑**：
1. 区分"流年支冲日支"vs"流年支冲他支"
2. 区分"被动被冲"（四柱紧贴支冲流年支）vs"主动冲人"（流年支冲四柱）
3. 《滴天髓》："旺者冲衰衰者拔，衰者冲旺反伤己"

**评分表**：
| 情况 | 得分 |
|------|------|
| 流年支直接冲日支（自身根基受损） | +2.5 |
| 流年支冲时支（子女/下属宫） | +2.0 |
| 流年支冲月支（父母/事业宫） | +1.5 |
| 流年支冲年支（祖上宫） | +1.0 |
| 四柱紧贴支冲流年支（流年被动受害） | +1.8 |

---

### D4. 凶神类型与转化路径（权重: 0.15）

**古籍依据**：
- 《子平真诠》："七杀有印化则贵，无印化则灾；伤官有财泄则富，无财泄则贫；枭神夺食，运遇则凶"
- 《滴天髓》："杀宜制不宜化，制者羊刃，化者印绶"

**实现逻辑**：检查四柱中是否存在"化解凶神"的十神

| 凶神 | 化解方式 | 化解存在时 | 化解不存在时 |
|------|---------|-----------|------------|
| 七杀 | 正印/偏印化杀 | -1.5 | +2.0 |
| 劫财 | 食伤泄秀 or 财星引化 | -1.0 | +2.0 |
| 枭神 | 命中有食神可护 | -1.2 | +1.8 |
| 伤官 | 财星泄秀 or 印制 | -1.0 | +1.8 |

---

### D5. 受害方力量评估（权重: 0.10）

**古籍依据**：
- 《滴天髓》："身旺不怕杀，身弱逢杀灾"
- 《子平真诠》："日主健旺，虽遇凶神亦可担当；日主衰弱，吉神亦难为力"

**实现逻辑**（有限信息下）：
- 日主在流年是否得令（流年支与月令的关系）
- 若日主得令/身旺 → 灾祸减轻
- 若日主失令/身弱 → 灾祸加重

**评分表**：
| 情况 | 得分 |
|------|------|
| 日主身旺（月令帮身）+ 凶神年 | +0.5（灾可化解） |
| 日主身弱（月令克泄）+ 凶神年 | +1.0（灾重） |

## 四、官非年份评分因子设计

官非是灾劫的子集，但有独特的触发机制，需单独建模。

### G1. 伤官见官（权重: 0.35）

**古籍依据**：
- 《子平真诠·论伤官》："伤官见官，为祸百端，其灾莫测"
- 《渊海子平》："伤官见官，是非多端，轻则口舌，重则官非"

**实现逻辑**：
1. 命中是否有正官（年/月/日/时柱中出现正官十神）
2. 流年干是否为伤官
3. 伤官与正官是否在同一柱或相邻柱（紧贴则祸重）

**评分表**：
| 情况 | 得分 |
|------|------|
| 命中有正官 + 流年伤官透干 + 紧贴 | +3.0 |
| 命中有正官 + 流年伤官透干 + 隔柱 | +2.0 |
| 命中有正官 + 流年伤官藏于地支 | +1.5 |
| 命中无正官 + 流年伤官年 | +0.5（仅口舌，无官非） |

---

### G2. 劫财争财（权重: 0.25）

**古籍依据**：
- 《滴天髓》："劫财见财，争夺之象"
- 《三命通会》："劫财逢财，必起纷争；财旺劫强，诉讼难免"

**实现逻辑**：
1. 命中是否有财星（正财/偏财）
2. 流年干是否为劫财
3. 流年支是否与财星地支产生冲合

**评分表**：
| 情况 | 得分 |
|------|------|
| 命中有财 + 流年劫财透干 + 流年支冲财支 | +2.8 |
| 命中有财 + 流年劫财透干 + 无冲合 | +2.0 |
| 命中财弱 + 流年劫财旺 | +2.5 |
| 命中无财 + 流年劫财年 | +0.5（无财可争，仅口舌） |

---

### G3. 枭神夺食（权重: 0.20）

**古籍依据**：
- 《子平真诠》："枭神夺食，饥饿之忧；若食神为用，必遭损伤"
- 《穷通宝鉴》："枭旺食衰，是非缠身"

**实现逻辑**：
1. 命中是否有食神（尤其食神为用神时）
2. 流年干是否为枭神（偏印）
3. 枭神是否紧贴食神

**评分表**：
| 情况 | 得分 |
|------|------|
| 命中食神为用 + 流年枭神透干紧贴 | +2.5 |
| 命中食神为用 + 流年枭神透干隔柱 | +1.8 |
| 命中食神弱 + 流年枭神旺 | +2.0 |
| 命中无食神 + 流年枭神年 | +0.5 |

---

### G4. 官杀混杂（权重: 0.20）

**古籍依据**：
- 《子平真诠》："官杀混杂，为祸最深；清者贵，杂者贱"
- 《滴天髓》："官杀混杂，是非不清，官非难免"

**实现逻辑**：
1. 命中是否同时有正官和七杀
2. 流年是否引动官杀冲突（流年干为官或杀，与命中官杀形成竞争）

**评分表**：
| 情况 | 得分 |
|------|------|
| 命中官杀混杂 + 流年引动官杀冲突 | +2.5 |
| 命中官杀混杂 + 流年仅透官或仅透杀 | +1.5 |
| 命中纯官或纯杀 + 流年引动 | +1.0 |

## 五、运势年份评分因子设计

运势是"广义吉凶趋势"，不同于灾劫的"纯凶"和官非的"特定凶"，需要双向评分（好运/坏运）。

### O1. 用神得力程度（权重: 0.30）

**古籍依据**：
- 《子平真诠·立命章》："命局有用药，看岁运助神则为吉，损神则为凶"
- 《滴天髓》："何知其人吉，用神有力；何知其人凶，用神受损"

**实现逻辑**：
1. 确定命局用神（基于日主强弱、格局）
2. 流年干支是否生扶用神
3. 流年干支是否克制用神

**评分表**：
| 情况 | 得分 |
|------|------|
| 流年干支均生扶用神 | +3.0（大吉之年） |
| 流年干支一支生扶用神 | +1.8 |
| 流年干支均克制用神 | -3.0（大凶之年） |
| 流年干支一支克制用神 | -1.8 |
| 流年干支与用神无关 | 0（平年） |

---

### O2. 岁运喜忌（权重: 0.25）

**古籍依据**：
- 《穷通宝鉴》："冬木喜火，夏木喜水；寒暖燥湿，各有所需"
- 《三命通会》："岁运所喜，则事事顺遂；岁运所忌，则诸事蹉跎"

**实现逻辑**：
1. 根据月令判断命局寒暖燥湿
2. 流年干支是否补救命局偏枯

**评分表**：
| 情况 | 得分 |
|------|------|
| 命局偏枯 + 流年补救到位 | +2.5 |
| 命局偏枯 + 流年部分补救 | +1.5 |
| 命局平衡 + 流年加剧偏枯 | -2.0 |
| 命局平衡 + 流年维持平衡 | +0.5 |

---

### O3. 流年与命局合化（权重: 0.20）

**古籍依据**：
- 《渊海子平》："岁运相合，合而化吉则吉，合而化凶则凶"
- 《滴天髓》："合能解冲，亦能制杀"

**实现逻辑**：
1. 流年支与命局地支是否形成六合/三合
2. 合化后的五行是否对命局有利

**评分表**：
| 情况 | 得分 |
|------|------|
| 流年与命局三合化用神 | +2.8 |
| 流年与命局六合化用神 | +2.0 |
| 流年与命局三合化忌神 | -2.5 |
| 流年与命局六合化忌神 | -1.5 |
| 流年与命局有合但合而不论 | +0.5 |

---

### O4. 禄马贵人（权重: 0.15）

**古籍依据**：
- 《三命通会》："岁禄、天乙贵人，皆主吉庆"
- 《渊海子平》："贵人相逢，灾殃自有"

**实现逻辑**：
1. 流年地支是否为日主的禄神
2. 流年天干是否为日主的天乙贵人
3. 流年地支是否为日主的驿马

**评分表**：
| 情况 | 得分 |
|------|------|
| 流年逢天乙贵人 | +1.5 |
| 流年逢禄神 | +1.2 |
| 流年逢驿马（主变动，吉凶参半） | +0.3 |
| 流年无贵人禄马 | 0 |

---

### O5. 大运流年相互作用（权重: 0.10）

**古籍依据**：
- 《子平真诠》："大运管十年之休咎，流年管一年之吉凶"
- 《滴天髓》："岁君 fruitful，大运辅之；岁君无fruitful，大运制之"

**实现逻辑**（需要计算大运，但用户无时辰精确信息时简化）：
- 若大运为喜神运 + 流年也是喜神 → 加倍
- 若大运为忌神运 + 流年也是忌神 → 加倍凶

**评分表**：
| 情况 | 得分 |
|------|------|
| 大运流年同吉 | +1.0 |
| 大运流年同凶 | -1.0 |
| 大运吉流年凶 or 反之 | 0（抵消） |

## 六、三类评分的汇总公式

### 6.1 灾劫评分（Disaster Score）

```
disaster_score = D1×0.30 + D2×0.25 + D3×0.20 + D4×0.15 + D5×0.10
```

**输出解读**：
- score > 2.5：重大灾劫年
- score 1.5~2.5：中等灾害年
- score 0.5~1.5：轻微不顺年
- score < 0.5：安全年

### 6.2 官非评分（Legal Score）

```
legal_score = G1×0.35 + G2×0.25 + G3×0.20 + G4×0.20
```

**输出解读**：
- score > 2.0：高风险官非年
- score 1.0~2.0：中等风险
- score < 1.0：低风险

### 6.3 运势评分（Fortune Score，双向）

```
fortune_score = O1×0.30 + O2×0.25 + O3×0.20 + O4×0.15 + O5×0.10
```

**输出解读**：
- score > 2.0：吉运年
- score 0.5~2.0：小吉/平稳年
- score -0.5~0.5：中性年
- score <-0.5：凶运年
