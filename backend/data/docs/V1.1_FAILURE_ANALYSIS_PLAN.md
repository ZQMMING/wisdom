## 一、诊断原则

### 1.1 三层分离原则

```
┌────────────────────────────────────────────────────────────┐
│ Layer 1: Calculation Layer（计算层）                        │
│   - 输入: 出生信息                                         │
│   - 输出: 结构化计算结果（四柱、卦象、命盘）                  │
│   - 验证标准: 与 MySQL/MingLi/iztro 对比                    │
│   - 成功条件: 计算结果正确                                  │
├────────────────────────────────────────────────────────────┤
│ Layer 2: Interpretation Layer（解释层）                     │
│   - 输入: 计算结果 + 知识库规则                              │
│   - 输出: 结构化信号（EventCandidate）                      │
│   - 验证标准: 规则引用、证据链完整性                         │
│   - 成功条件: 推断逻辑正确                                  │
├────────────────────────────────────────────────────────────┤
│ Layer 3: Prediction Layer（预测层）                          │
│   - 输入: 结构化信号                                        │
│   - 输出: 预测事件（时间、类别、置信度）                     │
│   - 验证标准: 与历史事件匹配                                 │
│   - 成功条件: 预测准确                                      │
└────────────────────────────────────────────────────────────┘
```

### 1.2 当前问题定位

```
当前实现: 仅 Layer 3（简单规则引擎）
缺失:     Layer 1 完整验证 + Layer 2 关系解释
```

### 维度 2: Signal Failure（信号缺失）

**诊断问题**: 算法算对了，但有没有生成正确的信号？

```python
# 测试方法
def test_signal_completeness():
    cases = load_golden_dataset()
    
    for case in cases:
        # 1. 获取实际事件
        actual_events = case.events
        
        # 2. 提取命理信号
        signals = SignalEngine().extract(case)
        
        # 3. 检查每个事件类别是否有对应信号
        for event in actual_events:
            cat = event.category
            has_signal = any(
                s.category == cat or 
                ontology.get_group(s.category) == ontology.get_group(cat)
                for s in signals
            )
            
            if not has_signal:
                record_failure(
                    case_id=case.case_id,
                    event=event,
                    failure_type="SIGNAL_MISSING",
                    reason=f"No signal for category: {cat}"
                )
```

**预期发现**: 
- EXAM 类别有信号但置信度低
- CHILD_BIRTH/PARENT_DEATH 无信号
- JOB_CHANGE 信号被错误归类为 PROMOTION

### 维度 3: Ontology Failure（本体错配）

**诊断问题**: 预测类别 vs 实际类别是否可映射？

```python
# 测试方法
def test_ontology_alignment():
    # 建立映射表
    MAPPING = {
        "EXAM": ["EXAM", "GRADUATION", "ADMISSION"],
        "PROMOTION": ["PROMOTION", "JOB_CHANGE", "RESIGNATION"],
        "FAMILY_CHANGE": ["FAMILY_CHANGE", "NEW_RELATIONSHIP", "RELOCATION"],
    }
    
    cases = load_golden_dataset()
    
    for case in cases:
        for event in case.events:
            actual_cat = event.category
            matched_pred = find_closest_prediction(event, case.predictions)
            
            if matched_pred:
                # 检查是否在映射范围内
                is_mapped = any(
                    actual_cat in MAPPING.get(pred_cat, [])
                    for pred_cat in MAPPING.keys()
                    if pred_cat == matched_pred.category
                )
                
                if not is_mapped:
                    record_failure(
                        case_id=case.case_id,
                        event=event,
                        failure_type="ONTOLOGY_MISMATCH",
                        actual=actual_cat,
                        predicted=matched_pred.category
                    )
```

**关键问题**:
- EXAM（考试）vs GRADUATION（毕业）— 同一组内但不同事件
- JOB_CHANGE（换工作）vs PROMOTION（升职）— 同向/反向混淆
- CHILD_BIRTH（出生）vs FAMILY_CHANGE（家庭变动）— 粒度差异

### 维度 4: Temporal Failure（时间偏差）

**诊断问题**: 预测年份 vs 实际年份的偏移分布？

```python
# 测试方法
def test_temporal_accuracy():
    tolerance_levels = [7, 14, 30, 60, 90, 180, 365, 730]  # 天数
    
    results = {tol: {"precision": 0, "recall": 0, "f1": 0} 
               for tol in tolerance_levels}
    
    for case in cases:
        predictions = predict_events(case)
        
        for event in case.events:
            actual_date = parse_date(event.date)
            
            # 找最近的预测
            closest_pred = min(predictions, key=lambda p: abs(p.year - actual_date.year))
            year_diff = abs(closest_pred.year - actual_date.year)
            
            for tol in tolerance_levels:
                if year_diff <= tol / 365:
                    results[tol]["matched"] += 1
            
            results[tol]["total"] += 1
    
    # 计算各容忍度下的指标
    for tol in tolerance_levels:
        results[tol]["recall"] = results[tol]["matched"] / results[tol]["total"]
```

**当前数据**:
```
±1年  Recall=2.12%, F1=2.67%
±2年  Recall=2.51%, F1=3.15%  ← 当前基线
±3年  Recall=2.90%, F1=3.64%
±5年  Recall=10.04%, F1=12.61%
±7年  Recall=11.20%, F1=14.06%
±10年 Recall=12.55%, F1=15.76%
±15年 Recall=13.90%, F1=17.45%
```

### 维度 5: Severity Failure（强度误判）

**诊断问题**: 预测的严重程度 vs 实际严重程度是否一致？

```python
# 测试方法
def test_severity_accuracy():
    severity_matrix = {
        "predicted_MAJOR": {"actual_MAJOR": 0, "actual_CRITICAL": 0, "actual_MODERATE": 0},
        "predicted_MODERATE": {"actual_MAJOR": 0, "actual_CRITICAL": 0, "actual_MODERATE": 0},
        "predicted_CRITICAL": {"actual_MAJOR": 0, "actual_CRITICAL": 0, "actual_MODERATE": 0},
    }
    
    for case in cases:
        predictions = predict_events(case)
        
        for pred in predictions:
            # 找最接近的实际事件
            matching_event = find_closest_event(pred, case.events)
            
            if matching_event:
                pred_sev = pred.severity  # 当前预测无严重程度
                actual_sev = matching_event.severity
                
                severity_matrix[pred_sev][actual_sev] += 1
```

**当前问题**: 
- 预测没有严重程度字段（全部默认0.5-0.7置信度）
- 无法区分 TRIVIAL/MAJOR/CRITICAL

### 维度 6: Interpretation Failure（推断错误）

**诊断问题**: 关系解释是否正确？证据链是否完整？

```python
# 测试方法
def test_interpretation_quality():
    for case in cases:
        predictions = predict_events(case)
        
        for pred in predictions:
            # 1. 检查证据引用
            has_evidence = pred.source.startswith("rule:") and len(pred.source) > 10
            
            # 2. 检查推断逻辑
            logic_valid = validate_inference_chain(
                input=case.birth_info,
                output=pred,
                evidence=pred.source
            )
            
            if not has_evidence or not logic_valid:
                record_failure(
                    case_id=case.case_id,
                    prediction=pred,
                    failure_type="INTERPRETATION_FAILURE",
                    reason="Missing evidence or invalid logic"
                )
```

**关键问题**:
- 当前预测只有简单规则触发（"if 月柱木 → predict EXAM"）
- 没有证据引用、没有推理链、没有置信度分层
