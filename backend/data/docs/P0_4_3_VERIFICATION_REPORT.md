## 一、语义类型体系

定义 9 种语义类型：

| 类型 | 定义 | 示例关键词 |
|------|------|-----------|
| ① FACT | 事实/状态 | 生克旺相等 |
| ② CONDITION | 条件 | 若...则... |
| ③ SUFFICIENT | 充分条件 | 见...必... |
| ④ NECESSARY | 必要条件 | 须...必... |
| ⑤ PREFERENCE | 倾向/宜忌 | 宜...喜...忌... |
| ⑥ BLOCKING | 制约/阻断 | 不可...畏... |
| ⑦ INFERENCE | 推论 | 故...是... |
| ⑧ COMPOUND | 复合论断 | ...且...而... |
| ⑨ UNKNOWN | 未确定 | - |

## 三、样本示例

### ① FACT（事实/状态）
- "壬水通河，能泄金气，刚中之德，周流不息"
- "能知衰旺之真机，其于三命之奥，思过半矣"

### ④ NECESSARY（必要条件）
- "生克制化，须制中有生，生中有制"
- "一行得二三人之气，则党众而专，须从其势"

### ⑥ BLOCKING（制约/阻断）
- "己土卑湿，中正蓄藏，不愁木盛，不畏水狂"
- "辛金软弱，温润而清，畏土之埋，乐水之盈"

### ⑦ INFERENCE（推论）
- "故太岁乃年中天子，不可犯"
- "是故旺之极者，宜泄而不宜克"

### ⑧ COMPOUND（复合论断）
- "丁火柔中，内性昭融，抱乙而孝，合壬而忠"
- "戊土固重，既中且正，静翕动辟，万物司命"

## 四、关键发现

### 1. 必要条件占比最高（27.7%）
- "须..."、"必..."、"宜..." 是高频表达
- 这些对应 PREREQUISITE 或 SUPPORTING

### 2. 制约/阻断占比次之（17.9%）
- "不可..."、"畏..."、"忌..." 是主要表达
- 这些对应 BLOCKING

### 3. 复合论断占比 11.6%
- "且..."、"而..."、"与..." 连接多个属性
- 需要确认是否映射到 AND

### 4. 推论占比 11.6%
- "故..."、"是..."、"乃..." 表示因果
- 可能是结论而非条件

### 5. UNKNOWN 仍占 23.2%
- 约 1/4 无法判断语义类型
- 符合保守原则
