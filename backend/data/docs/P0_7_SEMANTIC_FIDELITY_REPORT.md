## 五、关键发现

### 日犯岁君的核心问题

**岁君 = 年柱，但当前只用了年干**

这是最关键的 Gap。原典明确：
- "又曰年为太岁"——岁君是年柱
- "甲日见戊年太岁"——太岁包含年干和年支

当前实现只检查 `day_stem克year_stem`，完全忽略了年支。

**犯** 的含义也更丰富：
- 日干克年干（当前已实现）
- 日支克年支（未实现）
- 运克岁君（未实现）
- 岁运冲刑（未实现）

**条件** 更严格：
- 原典要求"甲乙若寅卯亥未日时者"
- 当前无日支条件检查

**程度** 有区分：
- 五阳干重，五阴干轻
- 天月德可救
- 太岁是用神则无咎
- 当前均未实现

### 生克制化的验证

语义忠实度较高，主要确认点：
1. 关系链实现（gen_in_keeps / keeps_in_gen）与原典"制中有生、生中有制"一致
2. "须"作为必要条件的理解正确
3. 太过/不及正确保持 UNRESOLVED
