## 一、Rater 资质要求

### 1.1 必须满足

| 要求 | 说明 | 验证方式 |
|------|------|---------|
| **经典知识** | 熟悉周易、说卦传、至少一家注疏 | 面试 + 测试 |
| **术数基础** | 理解八字/河洛/紫微基本概念 | 面试 + 测试 |
| **独立判断** | 能够独立评估解释质量 | 校准测试 |
| **无利益冲突** | 不是系统开发者、不是项目成员 | 声明 + 审计 |

### 1.2 推荐满足

| 要求 | 说明 |
|------|------|
| 学术背景 | 易学、哲学、汉学相关专业 |
| 实践经验 | 5年以上术数实践 |
| 评估经验 | 参与过类似评估项目 |

### 1.3 禁止资格

| 禁止 | 原因 |
|------|------|
| 系统开发者 | 自我认证循环 |
| 项目投资者 | 利益冲突 |
| Hermes / Codex / Claude | AI 不能充当人类专家 |
| 项目开发人员 | 利益冲突 |
| 系统用户（当前） | 使用偏误 |

## 二、Rater 招募规范

### 2.1 招募渠道

```text
✅ 学术机构（易学、哲学系）
✅ 独立术数从业者（非项目相关）
✅ 专业评估机构
❌ 项目内部人员
❌ 系统用户
❌ AI / LLM
```

### 2.2 招募数量

```text
最少: 2 名独立 Rater
推荐: 3 名独立 Rater (可计算 Krippendorff's α)
```

### 2.3 招募流程

```text
Step 1: 发布招募公告
  └── 明确资质要求、禁止资格、工作内容

Step 2: 资质审核
  ├── 简历筛选
  ├── 利益冲突声明
  └── 经典知识测试

Step 3: 校准测试
  ├── 5 个样本预测试
  ├── 检查评分一致性
  └── 确认理解 Rubric

Step 4: 正式聘用
  ├── 签署独立性协议
  ├── 明确盲评规则
  └── 记录到 rater_registry.json
```

## 三、独立性声明

### 3.1 必须签署

```text
独立性声明模板:

本人 [姓名] 声明:

1. 本人未参与顺天系统的算法、数据集、规则或评估脚本开发
2. 本人不是项目开发者、投资者或当前用户
3. 本人未使用过顺天系统的预测服务
4. 本人将严格遵守盲评协议，不查看其他 Rater 评分
5. 本人将严格按照 Rubric 评分，不因任何外部因素调整
6. 本人理解评分结果将用于学术评估，不得用于商业宣传

签名: _______________
日期: _______________
```

### 3.2 违反后果

```text
如发现违反独立性声明:
  ├── 立即取消 Rater 资格
  ├── 已评分结果作废
  └── 重新招募替代 Rater
```
