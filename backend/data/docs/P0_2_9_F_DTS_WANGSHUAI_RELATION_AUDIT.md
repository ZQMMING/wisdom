## 二、6条关系规则审计

### REL-001：得时不旺触发条件

| 项 | 值 |
|---|---|
| 规则ID | DTS-WS-REL-001 |
| 规则名称 | 得时不旺 |
| 关系类型 | 限定条件（得时 → 不旺的触发条件） |
| 涉及Primitive | DTS-WS-001（得时） + DTS-WS-002（得时不旺） |

**原典依据**：
> "得时俱为旺论，失令便作衰看，虽是至理，亦死法也。"
> "能知衰旺之真机，其于三命之奥，思过半矣。"

**触发条件**（原典隐含，工程推导）：
1. 得时但无根（月令虽旺，四柱无通根）
2. 得时但被重克（官杀多而无印化）
3. 得时但被重泄（食伤多而无财续）
4. 得时但根被冲（根位被冲克）

**关系表达式**：
```
IF 得时 = TRUE
   AND (无根 OR 重克 OR 重泄 OR 根被冲)
THEN 得时不旺 = CANDIDATE
```

**授权等级**：🟡 CLASSICAL_IMPLICIT（原典原则明确，具体触发条件为工程推导）
**状态**：CANDIDATE（需更多原典案例验证）

### REL-002：失时不弱触发条件

| 项 | 值 |
|---|---|
| 规则ID | DTS-WS-REL-002 |
| 规则名称 | 失时不弱 |
| 关系类型 | 限定条件（失时 → 不弱的触发条件） |
| 涉及Primitive | DTS-WS-003（失时不弱） + DTS-WS-005（有根） + DTS-WS-008（比肩） |

**原典依据**：
> "是故日干不论月令休囚，只要四柱有根，便能受财官食神而当伤官七杀。"
> "得时不旺，失时不弱，最宜详辨。"

**触发条件**（原典明确）：
1. 失时但有根（四柱有通根，尤其是根重）
2. 失时但比肩多（天干地支有比劫党众）
3. 失时但印星生扶（有印星生身）
4. 失时但根气完整（根未被冲克）

**关系表达式**：
```
IF 失时 = TRUE
   AND (有根 = TRUE OR 比肩多 = TRUE OR 印星生扶 = TRUE)
   AND 根未被冲 = TRUE
THEN 失时不弱 = CANDIDATE
```

**授权等级**：🟢 CLASSICAL_EXPLICIT（原典明确"不论月令休囚，只要四柱有根"）
**状态**：QUALIFIED（原典依据充分，具体阈值需验证）

### REL-003：根重vs根轻影响

| 项 | 值 |
|---|---|
| 规则ID | DTS-WS-REL-003 |
| 规则名称 | 根重vs根轻 |
| 关系类型 | 状态分级（根的质量影响力量判断） |
| 涉及Primitive | DTS-WS-005（有根） + DTS-WS-006（根之重者） + DTS-WS-007（根之轻者） |

**原典依据**：
> "长生禄旺，根之重者也；墓库余气，根之轻者也。"
> "得一重之根，胜干头之比肩。"

**根的分类**（原典明确）：

| 根类型 | 包含 | 力量等级 |
|---|---|---|
| 根之重者 | 长生、禄（临官）、旺（帝旺） | 强 |
| 根之轻者 | 墓库、余气 | 弱 |

**关系表达式**：
```
IF 有根 = TRUE:
   IF 根位 ∈ {长生, 临官, 帝旺}:
       根重 = TRUE
       力量贡献 = HIGH
   ELIF 根位 ∈ {墓库, 余气}:
       根轻 = TRUE
       力量贡献 = LOW
```

**授权等级**：🟢 CLASSICAL_EXPLICIT（原典明确分类和力量差异）
**状态**：CONFIRMED（分类明确，可直接工程化）

### REL-004：比肩与根的关系

| 项 | 值 |
|---|---|
| 规则ID | DTS-WS-REL-004 |
| 规则名称 | 比肩与根 |
| 关系类型 | 优先级规则（根 > 比肩） |
| 涉及Primitive | DTS-WS-008（比肩） + DTS-WS-005（有根） + DTS-WS-009（干多不如根重） |

**原典依据**：
> "天干多比肩，不如地支一长生禄旺之根。"
> "干多不如根重，支多不如气纯。"

**关系规则**（原典明确）：
1. 根的力量 > 天干比肩的力量
2. 一个重根（长生禄旺）> 多个天干比肩
3. 比肩是辅助，根是核心
4. 无根而比肩多 = 虚浮（非真旺）
5. 有根而比肩少 = 仍有根气（非真弱）

**关系表达式**：
```
优先级: 根重 > 根轻 > 比肩多 > 比肩少
IF 无根 AND 比肩多:
    状态 = 虚浮（CANDIDATE_WEAK）
IF 有根 AND 比肩少:
    状态 = 有根气（CANDIDATE_NOT_WEAK）
```

**授权等级**：🟢 CLASSICAL_EXPLICIT（原典明确"干多不如根重"）
**状态**：CONFIRMED（优先级规则明确，可直接工程化）

### REL-005：年日时损益介入

| 项 | 值 |
|---|---|
| 规则ID | DTS-WS-REL-005 |
| 规则名称 | 年日时损益 |
| 关系类型 | 修正条件（月令之外的位置对旺衰的修正） |
| 涉及Primitive | DTS-WS-004（年日时损益） + DTS-WS-001（得时） |

**原典依据**：
> "得时俱为旺论，失令便作衰看，虽是至理，亦死法也。须察支中党众，干上生扶，方可定其真衰真旺。"
> "月令虽重，年日时亦有损益。"

**关系规则**（原典原则明确，具体为工程推导）：
1. 月令是主要参考，但不是唯一决定因素
2. 年支、日支、时支的藏干可以生扶或克泄日主
3. 年干、日干、时干（非日主）可以生扶或克泄日主
4. 年日时的生扶可以"救"失时
5. 年日时的克泄可以"损"得时

**关系表达式**：
```
基础状态 = 得时/失时（月令判断）
修正 = 年日时生扶计数 - 年日时克泄计数
IF 基础 = 得时 AND 修正 < 阈值:
    得时不旺 = CANDIDATE
IF 基础 = 失时 AND 修正 > 阈值:
    失时不弱 = CANDIDATE
```

**授权等级**：🟡 CLASSICAL_IMPLICIT（原典原则明确，具体阈值和计数方式为工程推导）
**状态**：CANDIDATE（需更多原典案例验证具体阈值）

### REL-006：刑冲伤根触发

| 项 | 值 |
|---|---|
| 规则ID | DTS-WS-REL-006 |
| 规则名称 | 刑冲伤根 |
| 关系类型 | 阻断条件（根被刑冲克害时根力受损） |
| 涉及Primitive | DTS-WS-005（有根） + DTS-WS-010（本根之气） |

**原典依据**：
> "根被冲克，根气受伤。"
> "刑冲害合，皆能损根。"
> （注：此条原典依据需进一步核验，当前为传统命理共识）

**触发条件**（传统命理共识，工程推导）：
1. 根位被冲（如寅根遇申冲）
2. 根位被刑（如寅根遇巳刑）
3. 根位被合化（如寅根遇亥合化木，需辨证）
4. 根位被害（如寅根遇巳害）

**根力受损等级**：
| 损伤类型 | 根力受损程度 |
|---|---|
| 冲 | 重（根被拔起） |
| 刑 | 中（根气受伤） |
| 害 | 轻（根气暗损） |
| 合 | 需辨证（合化为喜则增，为忌则损） |

**关系表达式**：
```
IF 有根 = TRUE:
   IF 根位被冲:
       根力 = DAMAGED_HEAVY
       有根 = QUALIFIED（根力受损，非完整根）
   ELIF 根位被刑:
       根力 = DAMAGED_MEDIUM
   ELIF 根位被害:
       根力 = DAMAGED_LIGHT
```

**授权等级**：🟡 REASONABLE_HYPOTHESIS（传统命理共识，但需更多原典原文验证）
**状态**：CANDIDATE（需原典原文进一步验证）

## 四、组合逻辑说明

**重要原则**：这6条关系规则是**局部关系**，不是最终旺衰判断。

正确的辨证流程：
```
Canonical Facts（四柱、藏干、十神、刑冲合害）
    ↓
Primitive States（得时/有根/比肩/根重/根轻...）
    ↓
Relationship Rules（REL-001~006）
    ↓
Qualified States（得时不旺/失时不弱/根力受损...）
    ↓
【整体旺衰 = UNRESOLVED】（除非有明确原典授权的综合规则）
```

**禁止**：
- ❌ 禁止将这6条规则直接组合成最终身强/身弱
- ❌ 禁止给每条规则赋权重然后加权求和
- ❌ 禁止用评分模型替代经典辨证

**当前状态**：
- 局部关系规则已识别并审计 ✅
- 综合辨证规则尚未建立 ⏳
