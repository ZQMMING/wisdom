## 三、关键发现

### 3.1 条件明确度低（78.4%未解决）

**原因分析**:
- 大多数原典条目是**定义性描述**（如"甲木参天，脱胎要火"），而非条件规则
- 真正的条件规则集中在：
  - 滴天髓·理法（得令/有根/气势相关）
  - 渊海子平·论法（刑冲破害、生克制化）
  - 子平真诠·格局（成败救应）

**样本**:
```
[滴天髓] 理法_生扶克泄耗
  原文: 生克制化，须制中有生，生中有制
  条件: [{"text": "须", "type": "necessary"}]
  范围: composite - 多条件组合规则
```

### 3.2 综合规则占比18.4%

**特征**: 含多个条件或综合性描述
- 滴天髓：13条综合规则
- 渊海子平：47条综合规则
- 子平真诠：10条综合规则

**典型例子**:
```
[渊海子平] 论法_克泄耗论
  原文: 克我者官鬼，我生者子孙，我克者妻财，泄我者食伤，耗我者财源
  条件: []
  范围: composite - 综合性描述
  未解决: ["原文为分类定义，非条件规则"]
```

### 3.3 wangshuai领域证据最多（285条）

**分布**:
- 十干体性（滴天髓）: 10条
- 论法（渊海子平）: 44条
- 强弱（三命通会）: 10条
- 理法（滴天髓）: 9条（含气势/成格败格）

**待处理**: 这285条是P0-3.4的核心输入，需进一步提取条件→Primitive映射。
