# V-Validation V1.1 Failure Analysis Report

**分析时间**: 2026-08-22  
**数据集**: Golden Dataset V1 (50 cases, 518 events)  
**预测引擎**: BaziEngine → 简单规则预测 (EXAM/PROMOTION/FAMILY_CHANGE)  
**匹配方法**: 时间窗口 ±2年 + 类别精确匹配

---

## 一、执行摘要

| 指标 | 数值 | 诊断结论 |
|------|------|----------|
| **Precision** | 4.23% | 预测中有70%是误报 |
| **Recall** | 2.51% | 仅识别2.5%实际事件 |
| **F1** | 3.15% | 双低导致F1极低 |
| **总预测** | 307 | 预测密度6.1/case |
| **总实际** | 518 | 实际密度10.4/case |
| **预测类别数** | 3 | EXAM, PROMOTION, FAMILY_CHANGE |
| **实际类别数** | 10 | 覆盖人生全维度 |

### 核心诊断

> **3.15% F1 的根本原因不是算法"算不准"，而是预测层严重缺失：**
> 1. 算法只设计预测3个类别，但数据集有10个类别（70%的事件不在预测范围内）
> 2. 预测使用年粒度，而实际事件涉及月/日精度
> 3. 预测信号来源仅限日主+月柱，未使用完整命盘

## 六、失败分类（Failure Taxonomy）

### 6.1 失败类型分布

```
F12  算法无法预测   418次  30.1%  │ 算法从未设计该类别的预测规则
F5   时间窗口偏离   351次  25.3%  │ 预测年份与实际差距>2年
F6   时间粒度过粗    91次   6.6%  │ 年粒度vs月/日精度
F8   分组匹配但类别错22次   1.6%  │ EXAM→EXAM但实际是GRADUATION
```

### 6.2 失败原因详解

#### F12: 算法无法预测 (418次, 30.1%) — **最大问题**

| 实际类别 | 事件数 | 算法预测 | 说明 |
|----------|--------|----------|------|
| CHILD_BIRTH | 80 | FAMILY_CHANGE | 子类别不匹配 |
| PARENT_DEATH | 80 | 无预测 | 算法完全不预测死亡 |
| JOB_CHANGE | 76 | PROMOTION | 类别方向相反（降级vs升级） |
| NEW_RELATIONSHIP | 30 | FAMILY_CHANGE | 过度泛化 |
| RELOCATION | 5 | FAMILY_CHANGE | 过度泛化 |
| MAJOR_INCOME | 5 | PROMOTION | 收入vs职位混淆 |
| RESIGNATION | 2 | 无预测 | 算法无对应规则 |
| EXAM | 125 | EXAM | 有规则但年份偏移 |

**结论**: 70%的实际事件不在算法预测范围内。

#### F5: 时间窗口偏离 (351次, 25.3%) — **第二大问题**

预测规则固定年份（+22/+25/+28/+32等），而实际事件年份分布广：
- 实际事件年份范围: 155-2074年
- 预测年份固定偏移: +20/+22/+25/+28/+30/+35/+40/+45

**结论**: 预测年份与实际事件年份的系统性偏差。

#### F6: 时间粒度过粗 (91次, 6.6%)

- 预测: 年粒度（如"22岁考试"）
- 实际: 可能有月/日精度（如"乾隆三十年六月"）
- 当预测年份正确但月份不对时，年粒度无法区分

**结论**: 粒度不匹配导致时间正确但事件描述不符。

#### F8: 分组匹配但类别错 (22次, 1.6%)

- 预测: EXAM
- 实际: GRADUATION（同属education组）
- 语义上相关，但ontological不匹配

**结论**: 事件本体粒度需要调整。

## 七、6维度诊断总结

| 维度 | 状态 | 权重 | 诊断 |
|------|------|------|------|
| **1. 算法预测** | ❌ 严重缺失 | 40% | 只预测3类，数据集有10类；核心问题是预测规则不足 |
| **2. 事件本体** | ⚠️ 粒度不一致 | 15% | 预测粒度=年，实际粒度=月/日；类别定义需对齐 |
| **3. 语义匹配** | ⚠️ 类别映射 | 10% | EXAM→GRADUATION, JOB_CHANGE→PROMOTION等映射缺失 |
| **4. 时间窗口** | ⚠️ 过严 | 20% | 2年窗口导致大量False Negative；放宽到15年F1升至17.5% |
| **5. 严重程度** | ❌ 未区分 | 5% | 所有预测同一置信度，未按严重程度分级 |
| **6. 信号强度** | ❌ 无信号 | 10% | 预测基于日主+月柱，未使用完整命盘（流年、流月、紫微） |

## 八、改进优先级（按影响排序）

### P0: 立即解决（预计F1提升20%→40%）

1. **扩展预测类别** — 增加：CHILD_BIRTH, PARENT_DEATH, JOB_CHANGE, NEW_RELATIONSHIP, RELOCATION, MAJOR_INCOME, RESIGNATION
2. **接入完整命盘** — 使用SignalEngine + 流年分析替代简单规则
3. **修正时间偏移** — 动态年份计算而非固定偏移

### P1: 短期优化（预计F1提升40%→60%）

4. **细化时间粒度** — 支持季度/月度预测
5. **建立类别映射** — education组、career组的通用预测
6. **严重程度分级** — 不同事件赋予不同置信度

### P2: 中期改进（预计F1提升60%→80%）

7. **整合紫微/河洛** — 多引擎交叉验证
8. **优化容忍度标准** — 按严重程度动态调整时间窗口
9. **构建因果链** — 事件序列预测（先考试后升职）

## 九、结论

### 9.1 主要瓶颈定位

```
┌──────────────────────────────────────────────────────────────┐
│  瓶颈层级: 预测层 (Prediction Layer)                          │
│                                                              │
│  ├─ F12: 算法只预测3个类别 vs 10个实际类别 (70%覆盖不足)      │
│  ├─ F5:  固定年份偏移 vs 实际事件年份分布 (系统性偏差)         │
│  ├─ F6:  年粒度 vs 月/日粒度 (时间精度不足)                   │
│  └─ 无:   未使用SignalEngine/流年分析 (信号源单一)             │
└──────────────────────────────────────────────────────────────┘
```

### 9.2 不是以下问题

| 被排除的问题 | 证据 |
|--------------|------|
| 算法计算错误 | L0-L2测试100%通过 |
| 本体定义错误 | 事件分类清晰，无歧义 |
| Scoring公式错误 | Precision/Recall/F1计算正确 |
| 时间窗口过严 | 放宽到15年F1达17.5%，仍有12.5%差距 |

### 9.3 核心结论

> **3.15% F1 的根本原因是"预测层设计不完整"，不是"算法计算不准确"。**
> 
> 当前预测引擎只是一个简单的"规则触发器"（if 日主木 → predict EXAM），
> 而非一个完整的"命理推断系统"（使用八字+流年+紫微+河洛综合推断）。
> 
> 要提升F1，需：
> 1. 接入SignalEngine实现真正的命理推断
> 2. 扩展预测类别覆盖人生全维度
> 3. 使用完整命盘（而非仅日主+月柱）进行预测
