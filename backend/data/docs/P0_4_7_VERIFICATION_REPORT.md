## 三、关键发现

### 1. 大多数原典为定性描述
- 5/6 条原典缺乏明确的定量标准
- 原典使用程度词（炽、荡、重、润、燥）但未定义阈值

### 2. "二三人"语义不确定
- 可能是约数（多数）而非确数（≥2）
- 不能直接写成 `support_count >= 2`

### 3. 隐喻表达难以量化
- "乘龙""骑虎"是隐喻
- "愁逢""畏埋"是程度描述
- 缺乏明确的 Feature 定义

### 4. 唯一 DERIVABLE 的案例
- graph_005（戊己愁逢甲乙）
- 可能有明确条件关系
- 但需要更多原典验证
