## 四、工程禁令（🔴 禁止）

| 禁令 | 原因 |
|------|------|
| 五行计分 → 强弱 | "干多不如根重"直接否定数量=力量 |
| strength_score / root_score | 禁止评分模型 |
| 得时 → 直接判身强 | 得时不旺的情况存在 |
| 失时 → 直接判身弱 | 失时不弱的情况存在 |
| 有根 → 直接判身强 | 有根只是核心判据，不是最终判断 |
| 比肩多 → 身强 | 干多不如根重 |
| 得时+有根+比肩+损益 → 直接组合成身强身弱 | 暂缓，需先做关系层审计 |
| 五部经典混合成一个 strength_score | 五部经典是五套不同辨证知识系统，不是五个权重 |
| 调候 → 强弱 | 调候是独立维度 |
| 长生 → 通根 | 十二长生不能制造藏干根 |

## 六、五部经典工程原则（锁定）

1. **Primitive 必须按经典语境定义，不能跨章节拼装**
   - 《滴天髓·衰旺》的 Primitive 属于 DTS/WANG_SHUAI 域
   - 不能拿其他章节的"气势"塞进来
   - 不能把穷通宝鉴的调候 + 滴天髓的旺衰混成一个 strength_score

2. **五部经典不是五个"权重"，而是五套不同的辨证知识系统**
   - 《滴天髓》：旺衰/气势/生克制化
   - 《子平真诠》：月令/格局/用神/成败救应
   - 《穷通宝鉴》：四时/寒暖燥湿/调候
   - 《三命通会》：干支组合/刑冲合害/结构变化
   - 《渊海子平》：子平基础结构

3. **同一份 Canonical Chart，不同观察坐标系**
   - 不是五套系统投票谁对谁错
   - 而是同一事实，不同专业维度辨识（同一份心电图，不同科室）
