# 倪海厦紫微斗数体系 · 硬约束

本工具包的所有计算与解读必须严格限定在倪海厦（1953-2012）老师的紫微斗数体系内。以下是**不可违反的硬约束**（违反即整批样本作废）。

---

## A. 排盘层

1. **起局**：纳音五行局（水二 / 木三 / 金四 / 土五 / 火六），依据纳音表对照。
2. **命宫**：以寅宫起正月顺数生月，再逆数生时。
3. **身宫**：与命宫同起点，顺数生时。
4. **紫微安星**：以日期与五行局配合求紫微位（由 iztro 库实现）。
5. **十四主星**：紫微、天机、太阳、武曲、天同、廉贞、天府、太阴、贪狼、巨门、天相、天梁、七杀、破军——**一颗不能少**。
6. **六吉星**：文昌、文曲、左辅、右弼、天魁、天钺。
7. **六煞星**：擎羊、陀罗、火星、铃星、地空、地劫。
8. **禄存、天马**必列。

## B. 解盘层

9. **对宫借星**：任何空宫必借对宫主星论事，不得留白。
10. **三方四正**：本宫 + 对宫 + 两个三合宫，缺一不可。
11. **四化类型**：化禄、化权、化科、化忌，四种全部支持。

## C. 时间轴

12. **本命四化**：按**出生年天干**查四化表。
13. **大限四化**：按**大限宫的宫干**查四化表（**不是**本命年干——这是倪师体系最关键的修正点）。
14. **流年四化**：按**当年公历年份对应的天干**查四化表。
15. **流月四化**：按**五虎遁**推月柱天干（甲己年丙作首、乙庚年戊作首、丙辛年庚作首、丁壬年壬作首、戊癸年甲作首），再查四化表。
16. **四重共振**：本命 × 大限 × 流年 × 流月 同一星被多次化，是运势关键触发点。

## D. 飞星层

17. **宫干自化**：每个宫位的宫干都引发一组四化，若其中某化的对象星恰在本宫，称为"自化 X"（禄 / 权 / 科 / 忌）。
18. **来因宫**：某颗星的某种化，追溯到是哪个宫的宫干引发的，那个宫是该化的"根源"。化忌的来因宫尤为重要——**找到来因宫，才能找到问题的根**。
