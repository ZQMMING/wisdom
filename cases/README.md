# 案例库 (Case Library)

> 顺天命理系统验证案例集合
> 
> 本目录包含用于验证命理引擎准确性的真实案例数据，包括八字、紫微、河洛、易经等体系的命例。

---

## 一、案例分类

### 1.1 八字案例 (`bazi/`)

八字命理验证案例，包含：
- 四柱排盘验证
- 十神分析验证
- 旺衰判断验证
- 事件应期验证

**数据来源**:
- Golden Dataset (50个案例)
- 历史名人案例
- 竞赛案例 (contest8)

### 1.2 紫微案例 (`ziwei/`)

紫微斗数验证案例，包含：
- 命盘排盘验证
- 十二宫分析
- 四化飞星验证
- 流年断事验证

### 1.3 河洛案例 (`heluo/`)

河洛理数验证案例，包含：
- 先天卦计算
- 后天卦计算
- 元堂定位
- 流年卦验证

### 1.4 易经案例 (`yi/`)

易经六十四卦验证案例，包含：
- 卦辞引用验证
- 爻辞解释验证
- 象义分析验证

### 1.5 验证案例 (`validation/`)

跨体系综合验证案例，用于测试：
- 多引擎协同
- 证据链完整性
- 断言准确性

### 1.6 黄金案例 (`golden/`)

经人工审核确认的黄金标准案例，用于：
- 回归测试
- 准确性评估
- 性能基准

## 二、案例格式标准

### 2.1 基本结构

```json
{
  "case_id": "案例唯一标识",
  "type": "案例类型",
  "birth_date": "出生日期 (公历)",
  "birth_time": "出生时辰",
  "gender": "性别",
  "birth_location": "出生地点",
  "events": [
    {
      "date": "事件日期",
      "category": "事件类别",
      "severity": 严重程度(1-5),
      "description": "事件描述",
      "evidence_grade": "证据等级(A/B/C)"
    }
  ],
  "metadata": {
    "source": "数据来源",
    "verified": "是否已验证",
    "created_at": "创建时间",
    "updated_at": "更新时间"
  }
}
```

### 2.2 事件类别

| 类别 | 英文标识 | 说明 |
|------|----------|------|
| 出生 | CHILD_BIRTH | 出生事件 |
| 学业 | EXAM | 考试、升学 |
| 事业 | JOB_CHANGE | 工作变动 |
| 晋升 | PROMOTION | 升职加薪 |
| 婚姻 | MARRIAGE | 结婚、离婚 |
| 财运 | WEALTH | 财运事件 |
| 健康 | HEALTH | 健康问题 |
| 家庭 | FAMILY | 家庭事件 |
| 死亡 | DEATH | 逝世 |

### 2.3 证据等级

- **A级**: 明确可验证的历史记录
- **B级**: 较可信的传说/记载
- **C级**: 需要进一步验证

## 四、使用说明

### 4.1 添加新案例

```bash
# 1. 在对应分类下创建JSON文件
# 2. 按照格式标准填写案例信息
# 3. 运行验证脚本确认格式正确
python scripts/validate_cases.py cases/bazi/新案例.json

# 4. 提交到仓库
git add cases/
git commit -m "feat(cases): 添加新案例 XXX"
```

### 4.2 运行案例测试

```bash
# 运行所有案例测试
pytest tests/ -v -k "case"

# 运行特定类型案例
pytest tests/test_bazi_engine.py -v -k "golden"
pytest tests/test_ziwei_engine.py -v -k "celebrity"

# 运行全量回归测试
pytest tests/ --tb=short
```

### 4.3 案例验证流程

1. **输入验证**: 检查案例格式是否正确
2. **引擎计算**: 用命理引擎计算命盘
3. **结果比对**: 与已知结果对比
4. **误差分析**: 分析偏差原因
5. **文档更新**: 更新案例状态
