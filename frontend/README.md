## 河洛动画说明

### 7 个阶段

1. **河图 (Hetu)** — 同心圆结构，中心5白点（十字），外圈黑白点分布
2. **洛书 (Luoshu)** — 3×3幻方网格，九宫数字
3. **数流动** — 外层弧节点轻微流动
4. **数聚合** — 节点向中心收束
5. **成爻** — 六条爻线依次形成
6. **卦象** — 乾卦 (䷀) 呈现
7. **今日之象** — 潜龙勿用

### 交互

- 点击按钮切换阶段
- 点击「播放」观看完整动画
- 键盘：← → 切换，Enter 播放

### 配色

- 背景：#F5F1E8（米白）
- 主文字：#1B1B18（深墨）
- 辅助：#9B988F（灰褐）
- 强调：#A34A3A（朱砂）
