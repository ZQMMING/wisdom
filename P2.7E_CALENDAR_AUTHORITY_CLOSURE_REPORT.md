## Critical Implementation Notes

### 1. Julian Day Conversion

sxtwl returns JD in **Beijing Time (UTC+8)**, NOT UTC.

```python
# CORRECT conversion:
def jd_to_bjdt(jd: float) -> datetime:
    epoch_jd = 2440587.5  # 1970-01-01 00:00:00 UTC
    utc_seconds = (jd - epoch_jd) * 86400
    # sxtwl JD is in Beijing Time, so subtract 8h to get UTC first
    utc_dt = datetime(1970, 1, 1) + timedelta(seconds=utc_seconds - 8*3600)
    # Then convert to Beijing Time
    bj_dt = utc_dt + timedelta(hours=8)
    return bj_dt
```

sxtwl uses odd indices for 节 (solar terms that mark month boundaries):
