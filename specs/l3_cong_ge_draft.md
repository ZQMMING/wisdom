# L3 从格族规格草案

## F0 总闸：日主无根无气

### 定义
```
F0 = 无根 ∧ 无气 ∧ 根气未被救
```

### 【无根】
地支不含日主之本气/中气/余气根：
- 甲乙：寅卯（本气）、辰未（余气）
- 丙丁：巳午（本气）、戌丑（余气）
- 戊己：辰戌丑未（本气）
- 庚辛：申酉（本气）、戌丑（余气）
- 壬癸：亥子（本气）、辰（余气）

**争议点**：墓库余气（如未中乙、戌中丁）是否计入根？
→ 待裁决（需古籍断语支撑）

### 【无气】
天干无比肩劫财、无正印偏印；或比印全被合去/克尽。

### 【根气未尽破】
以下任一情形视为"根犹存"，不从：
- (a) 根支未被冲（寅申、卯酉、巳亥、子午、辰戌、丑未）
- (b) 根支未被合化变性（寅亥合木、辰酉合金等）
- (c) 印星未被财星紧贴克破

**争议点**：根被冲是否算破根？
→ 《滴天髓》任注与《真诠》有分歧，待裁决

## F1-F4 四从

| 从格 | 条件 |
|---|---|
| F1 从财 | 财星独盛，日主弃命从财 |
| F2 从杀 | 官杀独盛，无印化、无食伤制 |
| F3 从儿 | 食伤独盛 |
| F4 从强/从旺 | 印比独盛而日主有根 → 与专旺型交界 |

## F4 界线（专旺 vs 从强）

| 条件 | 归属 |
|---|---|

| 日主无根 + 印比独盛 | 从强型 |
| 日主微根未破 + 印比独盛 | 争议区（待裁决） |
