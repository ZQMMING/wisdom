## 一、审计方法论

### 证据链要求
对每条 check() 调用，建立完整证据链：

```
source → rule → derivation → expected → implementation
```

- **source**: 原典出处（《河洛真数》续修四库全书本 + 三才发秘 + 中华典籍网）
- **rule**: 对应规则编号（HL-01 ~ HL-14）
- **derivation**: 从 source 到 expected 的数学/逻辑推导过程
- **expected**: 测试中的期望值
- **implementation**: 代码实际行为

### 标记定义
- ✅ **PROVEN**: 原典明确引用，推导无歧义
- ⚠️ **UNCERTAIN**: 原典存在但推导有模糊性，或需二次确认
- ❌ **POLLUTED**: expected 来自从实现反推（非独立原典来源）
- 🔴 **DISPUTED**: 实现与原典明确矛盾

```

### 泽地萃 → 九四

**原典引用**（《河洛真数》+ 公开元堂取法资料）：

```
