## 预审目标

**不是"审10条"**，而是**先建立真正的原子候选池**。

---

## 核心原则

### 1. 复合命题必须拆分
```
❌ 禁止：A 或 B 或 C → 结论
✅ 允许：A → 结论（单独）
✅ 允许：B → 结论（单独）
✅ 允许：C → 结论（单独）
```

### 2. 多层结论必须拆分
```
❌ 禁止：条件A → 结论1 + 结论2 + 结论3
✅ 允许：条件A → 结论1（单独）
✅ 允许：条件A → 结论2（单独）
✅ 允许：条件A → 结论3（单独）
```

### 3. 原典未找到不得入池
```
❌ 禁止：先列候选 → 再找原典
✅ 允许：先找原典 → 再列候选
```

### 4. 理论原则直接REJECT
```
❌ 禁止：理论原则 → 进入生产
✅ 允许：理论原则 → 直接REJECT（标记为SEMANTIC_ONLY）
```

---

## 预审流程（七步）

### Step 1: 原典定位确认
- [ ] 确认书名正确
- [ ] 确认章节正确
- [ ] 确认行号正确
- [ ] 确认上下文≥50字
- [ ] 确认是原典原文（非表格、非现代解释）

**未通过则REJECT，不进入下一步**

### Step 2: 语义类型判定
- [ ] 是成格/败格条件？
- [ ] 是定义性命题？
- [ ] 是理论原则？
- [ ] 是评价性命题？

**理论原则/评价性命题 → REJECT（标记SEMANTIC_ONLY）**

### Step 3: 复合命题识别
- [ ] 是否包含"或"？
- [ ] 是否包含"及"？
- [ ] 是否有多个条件组合？
- [ ] 是否有多个结论？

**包含复合结构 → 拆分为多个原子候选**

### Step 4: 原子化拆分
对每个复合命题：
1. 提取所有独立路径
2. 提取所有独立结论
3. 每个路径+结论组成一个原子候选
4. 记录拆分依据

### Step 5: 最小命题验证
对每个原子候选：
- [ ] 能否进一步精简？
- [ ] 是否包含多个结论？
- [ ] 是否有非原典内容？

**不满足则REJECT**

### Step 6: Evidence Span提取
- [ ] 提取明确的原典表述
- [ ] 确认不包含现代解释
- [ ] 确认不包含英文
- [ ] 记录精确字符范围

**未通过则REJECT**

### Step 7: 预审裁决
- [ ] COMPLETE：满足所有标准，进入候选池
- [ ] REJECT：不满足任一标准，移出

## M2 Success Criterion（修改后）

### 原标准（错误）
```
至少5条COMPLETE
```

### 新标准（正确）
```
A. ≥1条COMPLETE（数量不是目标，质量才是）
B. 所有COMPLETE都通过完整七步验证
C. 0 semantic_overreach
D. 0 unsupported_condition
E. 原典独立裁决
F. 证明流程可复制
```

### 关键改变
- **数量目标降为观察指标**（可以5条，可以1条）
- **质量门槛不可妥协**（必须通过七步验证）
- **成功标准是证明流程可复制**（而非生产了多少条）
