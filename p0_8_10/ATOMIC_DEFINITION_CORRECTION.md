# P0-8.10 Atomic Assertion 定义修正

**Commit**: eab73a5（HOLD）  
**修正日期**: 2026-08-31

---

## 原定义（错误）

```
Atomic = 把条件拆到最少
```

**问题**：机械拆分可能破坏原典真值结构

---

## 新定义（正确）

```
Atomic Assertion =
在不改变原典真值条件的前提下，
不可进一步拆分的最小语义命题。
```

**核心原则**：
- ✅ 原子 ≠ 条件数量最少
- ✅ 原子 = 语义完整性 + 不可再分
- ✅ 原典真值结构必须保留

---

## 语义完整性标准

### 判断标准

一个Assertion是Atomic的，当且仅当：

1. **原典真值结构完整**
   - 条件A + 条件B + 条件C → 结论
   - 不能拆成 A→结论、B→结论、C→结论
   - 因为原典的真值是 (A∧B∧C)→结论，不是 (A→结论)∨(B→结论)∨(C→结论)

2. **不可再分**
   - 如果拆分会改变原典的真值条件，则不可分
   - 如果拆分后每个部分都失去原意，则不可分

3. **最小语义命题**
   - 在保持原典真值结构的前提下，尽可能精简
   - 但不能牺牲语义完整性

## 边界案例复核

### 案例1：PZZQ-GEJU-007（阳刃格）

**原典**：
```
阳刃透官煞而露财印，不见伤官，阳刃格成也
```

**错误拆分**：
```
9-A：阳刃透官煞 → 阳刃格成
9-B：露财印 → 阳刃格成
9-C：不见伤官 → 阳刃格成
```

**问题分析**：
- 原典的真值是：(阳刃透官煞 ∧ 露财印 ∧ 不见伤官) → 阳刃格成
- 如果拆成三个独立Assertion，真值变成了：
  - (阳刃透官煞 → 阳刃格成) ∨ (露财印 → 阳刃格成) ∨ (不见伤官 → 阳刃格成)
- 这是完全不同的逻辑！

**正确做法**：
```
保留完整条件组合：
阳刃透官煞 + 露财印 + 不见伤官 → 阳刃格成

这是一个Atomic Assertion，因为：
1. 原典真值结构完整（三个条件缺一不可）
2. 不可再分（拆分后失去原意）
3. 已是最小语义命题（无法进一步精简）
```

**裁决**：✅ 保留为1条Atomic Assertion（不拆分）

### 案例2：YHZP-SUIJUN-002（岁君关系）

**原典**：
```
日犯岁君，灾殃必重；五行有救，其年反必为财
```

**拆分分析**：
```
11-A：日犯岁君 → 灾殃必重
11-B：五行有救 → 其年反必为财
```

**语境依赖检查**：
- "五行有救"的"有救"究竟是什么意思？
- 是"日犯岁君"的救应？还是独立条件？

**原典上下文**：
```
太岁乃年中天子，故不可犯，犯之则凶。
经云：『日犯岁君，灾殃必重；五行有救，其年反必招财。』
```

**语义分析**：
- "五行有救"显然是针对"日犯岁君"的救应
- 不能拆成独立命题"五行有救 → 反必为财"
- 必须保留语境依赖：在"日犯岁君"的前提下，"五行有救"才能"反必为财"

**正确拆分**：
```
11-A：日犯岁君 → 灾殃必重
11-B：日犯岁君 + 五行有救 → 其年反必为财

（11-B必须保留语境依赖）
```

**裁决**：
- ✅ 11-A 可以独立
- ⚠️ 11-B 需要保留语境依赖，标记为"需语境确认"
