## M2验证流程

### Step 1: 原典定位验证（新增约束）
- [ ] 确认书名正确
- [ ] 确认章节正确
- [ ] 确认行号正确
- [ ] 确认上下文完整（不少于50字）
- [ ] 确认是原典原文（非表格、非现代解释）

### Step 2: Evidence Span提取
- [ ] 提取明确的原典表述
- [ ] 确认不包含现代解释
- [ ] 确认不包含英文
- [ ] 确认是原典原文
- [ ] 记录精确字符范围

### Step 3: 最小命题界定（新增约束）
- [ ] 是否是最小语义命题？
- [ ] 是否包含多个结论？
- [ ] 是否有非原典内容？
- [ ] 能否进一步精简？

### Step 4: Semantic Relation建立（新增约束）
- [ ] subject-predicate-object-conclusion是否齐全？
- [ ] 语义方向是否正确？
- [ ] 是否超出了原典明确表述？
- [ ] 是否是成格/败格条件，还是理论原则？

### Step 5: Condition推导验证（新增约束）
- [ ] 是否从Evidence Span合法推导？
- [ ] 是否超出了原典明确表述？
- [ ] 是否合并了多个独立条件？
- [ ] 是否是"喜/忌"型断语（除非原典明确）？

### Step 6: Primitive生成验证（新增约束）
- [ ] 是否从Semantic Relation生成？
- [ ] 是否读取了旧Assertion的primitive/condition？
- [ ] 是否与Evidence独立？
- [ ] 命名是否规范？

### Step 7: 四问裁决
- [ ] 回答四问
- [ ] 只产生COMPLETE或REJECT
- [ ] 不产生PARTIAL
