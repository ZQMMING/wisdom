## M1验证流程

### Step 1: 原典定位验证
- [ ] 确认书名正确
- [ ] 确认章节正确
- [ ] 确认行号正确
- [ ] 确认上下文完整

### Step 2: Evidence Span提取
- [ ] 提取明确的原典表述
- [ ] 确认不包含现代解释
- [ ] 确认不包含英文
- [ ] 确认是原典原文

### Step 3: 最小命题界定
- [ ] 是否是最小语义命题？
- [ ] 是否包含多个结论？
- [ ] 是否有非原典内容？

### Step 4: Semantic Relation建立
- [ ] subject-predicate-object-conclusion是否齐全？
- [ ] 语义方向是否正确？
- [ ] 是否超出了原典明确表述？

### Step 5: Condition推导验证
- [ ] 是否从Evidence Span合法推导？
- [ ] 是否超出了原典明确表述？
- [ ] 是否合并了多个独立条件？

### Step 6: Primitive生成验证
- [ ] 是否从Semantic Relation生成？
- [ ] 是否读取了旧Assertion的primitive/condition？
- [ ] 是否与Evidence独立？
