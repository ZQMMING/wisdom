## 一、原书核心原文（作为布尔规则改写的唯一依据）

### 1. 体用（原书原文）
> "什么是体：如**日主、比肩、禄、印、食**都是体。
> 什么是用：……如**财、官、伤**。"

**布尔判定**：
```
体(x) = x ∈ {日主, 比肩, 劫财, 禄, 印, 食神}
用(x) = x ∈ {财, 官, 伤官}
```

### 2. 做功方式（原书原文）
> "体用、宾主之字进行**刑、冲、克、穿、合、墓**等都是做功的方式。"

**制用结构五种**（原书展开）：
1. 比肩去财 → **比劫制财局**（比劫得势制财）+ **财制比劫局**（财旺制比劫，**比劫当财看=换象**）
2. 伤官去官
3. 食伤制杀
4. **印制食伤**
5. 财来制印

**合用**：日干、日支合的东西；**化用**：用印化官杀（当官格）；
**生用**：食伤生财、**食伤泄秀**（一般不发大财）；**墓用**：得到/控制/占据/拥有。

### 3. 功神/废神（原书原文）
> "八字中凡参与做功的神称为功神……**废神就是不参与做功**/消耗能量不产生效率。"

### 4. 势（原书原文）
> "有势没有功，到老一场空；有功没有势，辛苦活一世。
> 有势又有功，定是富贵翁。……**木成势制土坏金、火成势制金坏水**……"

### 5. 贼神捕神（原书案例原文）
> "局中官杀无制，不属于贼捕结构，喜行捕神的大运和流年。"

### 6. 换象（原书案例原文）
> "财制比劫局……**比肩劫财当财看**。戊癸合……把被制的申财又拉回主位。"

### 7. 看八字入手（原书原文）
> "从日柱入手……其一，日干是否与它干有合（合正官/合正财）；
> 其二，日干无合，就看日干是否有生（食神伤官贴近日干）；
> 其三，日干无生无合，但八字有势，就看**这个势在命局中所做的功**。"

## 二、布尔条件规则算法问题诊断（引擎 vs 原书）

### 问题 1（根因）：体用分类布尔条件错误 —— 伤官归错阵营
```
引擎:  体 = {比劫, 印, 食神, 伤官}    用 = {财, 官杀}
原书:  体 = {日主, 比劫, 印, 食神}    用 = {财, 官, 伤官}
差异:  伤官 —— 引擎归"体"，原书归"用"
```
**连锁后果**：
- 伤官在引擎的"体×用配对"框架里永远只能当"制方"，不能当"做功目标"
- 伤官制官的做功（引擎有✓）依赖伤官=体，碰巧对；但**伤官被制（如印制食伤中的伤官侧）、伤官为追求目标**的结构全部失真

### 问题 2（根因）：做功关系判定缺"刑"布尔条件
```
引擎关系集合: {he, liuhe, chong, chuan, ke_ti_yong, ke_yong_ti,
               sheng_ti_yong, sheng_yong_ti}
原书关系集合: {刑, 冲, 克, 穿, 合, 墓}
差异: 缺 xing（刑）—— 丑未戌三刑、寅巳申三刑等做功结构完全无法判定
```
引擎的刑只在应期触发使用，做功层无刑（BRANCH_SANXING_TRIPLE/DOUBLE/SELF 表已存在但做功判定未消费）。

### 问题 3（根因）：做功框架只有"体×用两两配对"，缺 3 个独立布尔结构
原书做功是多层结构（日柱入手），引擎只有一个平面循环：

| 原书结构 | 布尔条件 | 引擎 | 后果 |
|---|---|---|---|
| 日干合财官 | 日干与它干五合 且 它干∈{正财,正官} | 无专门逻辑（合财/合官来自体用对） | 日干合财官（最高级合用）无法独立识别 |
| 日干有生（食伤贴身） | 食伤贴近日干（月/时干） | 无 | 泄秀/追求目标逻辑缺失 |
| **势做功** | 某五行成势（党≥阈值）且 势五行制其对象 | **完全缺失** | "有势又有功定是富贵翁"无法判定，势党域空缺 |
| **换象** | 财制比劫局中 比劫当财看 | **完全缺失** | 财制比劫局、戊癸合拉财等结构失真 |
| **贼捕** | 官杀无制 → 需捕神制之 | **完全缺失** | 案例"不属于贼捕结构"无法表达 |

### 问题 4：功神/废神二元输出缺废神分支
```
引擎: gong_shen = {WORKING: 体支, TARGET: 用支}    # 只有功神
原书: 功神 = 参与做功的字；废神 = 不参与做功的字
差异: 引擎无"废神"计算 —— 不参与做功的干支应输出为废神
```

### 问题 5：制用五种缺"印制食伤""财制比劫"
```
原书制用五种: 比劫制财 ✓ 伤官去官 ✓ 食伤制杀 ✓ 印制食伤 ✗ 财来制印 ✓
引擎额外有: 官杀制比劫（原书制局通辨·比劫与官杀配置，有出处 ✓）
引擎缺:     印制食伤（印克食伤，因食伤在引擎中归"体"，体×体不在框架内 → 永远无法触发）
            财制比劫（需换象逻辑）
```

## 三、修复所需布尔规则清单（对照原书逐条）

```text
R1 体用分类修正
   IF ten_god == 伤官 THEN 用        # 原书：用=财官伤
   IF ten_god == 食神 THEN 体        # 原书：体含食
   IF ten_god == 比肩/劫财/印 THEN 体
   IF ten_god == 财/官杀 THEN 用

R2 刑做功
   IF 干支关系 == 刑(TRIPLE/DOUBLE/SELF 三刑表) AND 体用/宾主之字 THEN 刑做功

R3 印制食伤
   IF 印(体) 克 食伤(中性→此结构下食伤为被制方) THEN 印制食伤

R4 食伤泄秀
   IF 食伤贴身(月/时干) AND 日干有生 THEN 食伤泄秀(不做发财论)

R5 财制比劫（换象）
   IF 财旺 制 比劫 THEN 财制比劫局 + 换象标记(比劫当财看)

R6 势做功
   IF 某五行党数 ≥ 阈值 AND 势五行克其对象 THEN 势做功(独立于日主做功)

R7 功神/废神
   IF 字参与做功 THEN 功神 ELSE 废神

R8 贼捕结构
   IF 官杀无制 THEN 结构=贼捕候选 + 捕神=制贼之字
```

## 四、诊断结论

**是布尔条件规则算法问题**，不是简单缺方法名：
1. **体用分类条件错**（伤官应归用）→ 结构性错误，影响一切体用配对判定
2. **关系判定缺"刑"条件** → 六种做功方式只实现五种
3. **框架只支持"体×用配对"** → 势做功/换象/贼捕/日干合生 4 个独立布尔结构完全无承载
4. **功神/废神缺废神分支**
