## 域三：正局 / 反局

### 古籍原文（已核证，精读全文）

《盲派中级命理学》第01章 正局、反局：

```
"正局：日柱做功，所表达的意思与原局表达的意思一致。八字无势，日主能做功也称为正局。
 反局：日柱做功所表达的意思与原局表达的意思相反，为凶。
 反局分原局反局、大运反局、流年反局三种，原局反局原局凶，大运反局大运凶，流年反局流年凶。"
```

**看正局反局三法（原文）**：
1. **日支做功方向**："日支做的功与八字的势对抗，就是反局……日支追求的东西与八字势对抗"（如坤造丙戊丁丁 子戌丑未：火土意在去金水，日支丑一合子水=追求子水=反局，反在夫妻宫，夫早死、儿残）
2. **日主之功与日支之功相反**："以日主为主……日主合时柱官做功，要看官坐下的支去干啥了……官的坐支与日支做的功相反时，就反局了"
3. **冲合反局**："年月与日时有冲合反局……日时是冲局、年月反是合局；或日时为合局、年月反是冲局……是反局八字。**干合与支冲不算反局，必须是地支之间的冲合才是反局**"（如乾造戊丁戊戊 申巳子午：日时子午冲+年月巳申合=财星反局=极穷）

**岁运反局**："八字原局很好，做功也明确，但最怕行反局大运，即行运正好与原局表达的意思相反，或行运与原局势力对抗而无法被原局制之，主此大运凶，过了大运则吉。"
**冲合反局（岁运）**："原局有明确的制的时候，怕大运、流年合。如无明确的制，则不怕。"

**关键附属结构（原文）**：
- 连体（红字）："戊申一柱，戊生申为一体，是用金，为原局反局……连体金不可坏，坏则伤寿"
- 官杀制不净当财看（和珅例）："年上午制不净，官杀制不净当财看；时上午制净了，当官看"
- 案例详解 D28 原文："原局大反局：左边伤官制官（乙木克己土），右边合财（壬合丁财），勾陈包局 → 牢狱之象"（原局反局=日主壬合丁财（合财=追求财），同时伤官制官（制官=去官）——日主追求的东西与做功方向冲突=反局）

### 布尔条件规则（草案）

```
ZHENG_FAN_JU(正局/反局):
  反局判据(任一):
    R1 日支做功方向与八字势对抗        # 日支合/冲/穿对象与原局制势相反
    R2 日主做功与日支做功意思相反      # 以日主为主; 日主合官看官坐支, 坐支做功与日支相反
    R3 冲合反局: 年月合∧日时冲 或 年月冲∧日时合 (仅地支间; 干合支冲不算)
    R4 连体被坏: 连体柱(戊申/辛酉/庚子等干支一气之体)被原局制 = 反局(主伤寿)
  岁运反局(时间层):
    R5 原局有明确制 → 大运/流年合掉功神 = 反局
    R6 行运与原局势力对抗且无法被制 = 反局
  正局: 以上皆否 且 日柱做功与原局意一致(或无势日主做功)
  输出: 原局层 zheng_fan_ju + 反局类型(原局/岁运) + 反在哪个宫/字
```

### 决定：✅ 成立，立为 VERIFY-BLIND-035，本期施工（原局层 R1-R4）

- D28 用 R1/R2 可判"原局反局"（日主合财追求财 + 伤官制官去官 = 意向冲突）→ 对齐文献"牢狱之象"。
- R5/R6（岁运反局）属时间层，接盲派应期引擎（blind_yingqi）二期。
- D13（孔祥熙）"癸酉运酉合辰冲卯反局"=R5 案例，二期验证。

## 域六：六亲计数（同胞个数）

| 出处 | 原文 |
|---|---|

| 盲派兄弟口诀 | "兄弟姐妹看四柱，同类五行为手足。天干地支都在内，支藏人元也算数。刑冲穿克往下减，合化五行要看住。不算人元也可以，纳音同类论手足。男命比肩为兄弟，劫财姐妹不差数。女命比肩为姐妹，劫财兄弟是手足。" |

| 案例详解 案例3 | "身旺无官杀 → 以食伤为兄弟姐妹；数水：年干癸+月申中壬+日子中癸+时申中壬+甲申纳音井泉水=五重水→五胎损一" |
| 案例详解 铁断 | "比肩为兄弟，纳音也算数（秘中之秘）；身旺无官以食伤为同胞" |
