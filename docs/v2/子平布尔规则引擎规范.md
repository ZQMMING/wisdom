# 子平引擎（ZIPING）布尔条件规则规范 V1

> 版本：V1 ｜ 状态：规范草案（待用户审定） ｜ 关联：`reasoning/judgment.py` 评分制废弃后的规则引擎基线
> 依据：五部经典（《子平真诠》E-ZQ / 《滴天髓》E-DT / 《穷通宝鉴》E-QTBJ / 《渊海子平》E-YH / 《三命通会》E-SMT）

## 0. 模型声明（硬约束）

1. **判断 = 布尔条件规则匹配**，禁止百分比、加减分、加权求和、阈值档位。
2. 每条规则 = `IF 条件(布尔) THEN 结论 + 证据引用`。命中即输出，不命中即无。
3. **多结论并存**：经典常"兼看并论"，规则层不做归一、不做二选一；综合由下游分析层完成。
4. **冲突处理**：规则带 `priority`（仅用于排序展示，不用于抵消）；两规则同时命中则同时输出。
5. **可审计**：每个结论必须携带 `evidence`（E-文献-维度-序号）与 `source`（经典章名）。
6. 规则条件只消费**确定性事实层**（四柱/十神/藏干/十二长生/神煞/干支关系/纳音等），不消费任何启发字段（NOT_AUTHORIZED）。

## 1. 通用规则格式

```text
rule_id:      ZP-{维度}-{序号}         例: ZP-WS-01
dimension:    维度英文缩写              例: WS
condition:    布尔表达式（AND/OR 组合，操作符见下）
conclusion:   命理论断（事实陈述，零吉凶词汇）
evidence:     E-{文献}-{维度}-{序号}
source:       经典出处（章名/篇名）
priority:     0-9（排序用，数字大优先展示，非权重）
note:         备注/例外说明
```

**条件操作符**（规则引擎统一实现）：

| 操作符 | 含义 | 示例 |
|---|---|---|
| `==` / `!=` | 相等/不等 | `month_branch_major_element == day_master_element` |
| `in` | 属于集合 | `month_season in (寅,卯,辰)` |
| `contains` | 藏干含某干 | `hidden_stems(支) contains day_master` |
| `count(expr) >= n` | 计数 | `count(transparent_stems_god == 印) >= 2` |
| `any(...)` / `all(...)` | 任/全 | `any(b in branches: hidden_major(b) == day_master)` |
| `透/藏` | 天干透出 | `透(用神)` |

**输入事实**（由八字事实层提供，规则只引用不计算）：
`four_pillars / day_master / month_branch / month_season / transparent_gods(天干十神) / hidden_stems(藏干, 本/中/余气) / branch_ten_gods / twelve_growth / shensha / branch_relations(合冲刑害破) / nayin`

## 2. 旺衰（WS）— 月令为纲

> 依据：《子平真诠·论得令》《滴天髓·通神论》
> 核心：**得令者旺，失令者衰**。旺衰以月令为纲，按月令本气五行与日主的关系定性。

| rule_id | 条件（布尔） | 结论 | 证据 |
|---|---|---|---|
| ZP-WS-01 | `month_branch_major_element == day_master_element` | 日主得令（旺） | E-ZQ-WS-01《子平真诠·论得令》 |
| ZP-WS-02 | `month_branch_major_element == 生我(印)之五行` | 日主得令生扶（相） | E-ZQ-WS-02《子平真诠·论得令》 |
| ZP-WS-03 | `month_branch_major_element == 我生(食伤)之五行` | 日主泄气（休） | E-ZQ-WS-03《子平真诠·论得令》 |
| ZP-WS-04 | `month_branch_major_element == 克我(官杀)之五行` | 日主受克（囚） | E-ZQ-WS-04《子平真诠·论得令》 |
| ZP-WS-05 | `month_branch_major_element == 我克(财)之五行` | 日主耗身（死） | E-ZQ-WS-05《子平真诠·论得令》 |
| ZP-WS-06 | `hidden_stems(month_branch) 中气或余气 contains day_master_element` AND `WS-01/02 未命中` | 日主得余气（微根） | E-ZQ-WS-06《子平真诠·论得令》 |
| ZP-WS-07 | `month_branch in (辰,戌,丑,未)` | 月令为墓库，按藏干本气先论（特殊分支） | E-DT-WS-07《滴天髓·地支》 |
| ZP-WS-08 | `WS-01 命中` AND `日主在地支有本气通根` | 得令且得地，旺而有力 | E-DT-WS-08《滴天髓·通神论》 |

**输出**：`{dimension: 旺衰, matched_rules: [...], verdict: 得令/失令/相/休/囚/死(可并存)}`

## 3. 强弱（QR）— 得地 + 通根 + 党众

> 依据：《滴天髓·天干》"得时俱旺，失时便衰；得地者强，失地者弱"；《子平真诠·论强弱》
> 核心：旺衰看月令（上节），强弱看通根深度 + 党众生扶。旺衰与强弱是**两个独立判定**，可并存输出。

| rule_id | 条件（布尔） | 结论 | 证据 |
|---|---|---|---|
| ZP-QR-01 | `any(四支: hidden_stems(支) contains day_master)` | 日主有根 | E-DT-QR-01《滴天髓·天干》 |
| ZP-QR-02 | `count(地支藏干本气 == day_master) >= 2` | 本气通根 ≥2，根深 | E-DT-QR-02《滴天髓·天干》 |
| ZP-QR-03 | `count(地支藏干本气 == day_master) == 1` | 本气通根 1 位，根单 | E-DT-QR-03《滴天髓·天干》 |
| ZP-QR-04 | `QR-01 命中` AND `本气通根 == 0` | 仅中/余气通根，根浅 | E-DT-QR-04《滴天髓·天干》 |
| ZP-QR-05 | `QR-01 未命中` | 日主无根 | E-DT-QR-05《滴天髓·天干》 |
| ZP-QR-06 | `count(透干十神 in (比,劫,印)) - count(透干十神 in (官,杀,财,食,伤)) >= 2` | 党众有力（帮扶胜） | E-DT-QR-06《滴天髓·衰旺》 |
| ZP-QR-07 | `count(透干十神 in (比,劫,印)) - count(透干十神 in (官,杀,财,食,伤)) <= -2` | 党众失力（克泄胜） | E-DT-QR-07《滴天髓·衰旺》 |
| ZP-QR-08 | `WS-01 命中` AND `QR-02 命中` AND `QR-06 命中` | 身强（得令+根深+党众） | E-DT-QR-08《滴天髓·通神论》 |
| ZP-QR-09 | `WS-01 未命中` AND `QR-05 命中` AND `QR-07 命中` | 身弱（失令+无根+失党） | E-DT-QR-09《滴天髓·通神论》 |
| ZP-QR-10 | `QR-08/QR-09 均未命中` | 中和/偏强/偏弱（介于，并置输出各命中项） | E-DT-QR-10《滴天髓·通神论》 |
| ZP-QR-11 | `通根位于月令支` | 得地最重（月令根） | E-DT-QR-11《滴天髓·天干》 |
| ZP-QR-12 | `通根位于日支` | 得地次重（贴身根） | E-DT-QR-12《滴天髓·天干》 |
| ZP-QR-13 | `通根位于年支或时支` | 得地较轻（遥根） | E-DT-QR-13《滴天髓·天干》 |

**输出**：`{dimension: 强弱, matched_rules: [...], verdict: 强/偏强/中和/偏弱/弱(由下游综合, 规则层只给命中项)}`

| ZP-GQ-05 | `通根位置 == 月令支` | 月令根（最有力） | E-ZQ-GQ-05《子平真诠·论通根》 |

## 5. 党众（DZ）— 帮扶 / 克泄

> 依据：《滴天髓·衰旺》"何知其人旺，印比生扶多；何知其人衰，财官克泄众"
> 核心：天干（及透干地支藏干）中，帮身（印比）与克泄耗（官杀财食伤）的力量对比——**定性比较，不计分**。

| rule_id | 条件（布尔） | 结论 | 证据 |
|---|---|---|---|
| ZP-DZ-01 | `count(透干十神 in (比,劫,正印,偏印)) >= 2` | 帮身有力（印比 ≥2 透） | E-DT-DZ-01《滴天髓·衰旺》 |

| ZP-DZ-03 | `count(透干十神 in (正官,七杀,正财,偏财,食神,伤官)) >= 3` | 克泄耗过重（≥3 透） | E-DT-DZ-03《滴天髓·衰旺》 |
| ZP-DZ-04 | `帮身数 > 克泄耗数` | 党众胜（帮扶为主） | E-DT-DZ-04《滴天髓·衰旺》 |
| ZP-DZ-05 | `克泄耗数 > 帮身数` | 党众负（克泄为主） | E-DT-DZ-05《滴天髓·衰旺》 |
| ZP-DZ-06 | `地支藏干 in (比,劫,正印,偏印)` AND `该藏干透于天干` | 支中党众透出，有力 | E-DT-DZ-06《滴天髓·衰旺》 |
| ZP-DZ-07 | `帮身数 == 克泄耗数` | 势均力敌 | E-DT-DZ-07《滴天髓·衰旺》 |

**输出**：`{dimension: 党众, matched_rules: [...], verdict: 党众强/党众弱/势均}`
