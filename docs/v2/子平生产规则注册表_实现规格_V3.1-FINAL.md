## 0. 总则（编译级，写入 AGENTS.md）

1. **所有规则只能是布尔/枚举条件 → 状态结果。**
2. **禁止任何 `+/-`、权重、分数、百分比、数量阈值、概率、投票**（含"内部评分最后不展示"）。
3. **Bazi 已提供的事实直接消费，不在 ZiPing 重算**（排盘/十神/藏干/长生/干支关系均来自事实层）。
4. 经典之间方法分歧处必须标注 `method_scope`，不得伪装成所有子平家一致。
5. 每个最终判断必须携带 `matched_rule_ids` + `evidence_refs`；无规则命中 → `UNDETERMINED`。
6. 特殊结构优先于普通判断（裁决链 P1）。
7. 事实缺失 → 对应判断 `UNDETERMINED`，不得自行补算。

## 1. 规则格式（标准 YAML）

```yaml
rule_id: STRENGTH-012
domain: strength
method_scope:            # 经典门派范围（分歧必标）
  - ziping_zhenquan
requires:                # 前置事实（缺则 UNDETERMINED）
  - month_order
  - effective_root
conditions:
  all:                   # 布尔条件（AND）；亦可用 any:
    - month_order == OUT_OF_SEASON
    - effective_root == TRUE
result:
  state: SHUAI_BUT_NOT_WEAK
overrides: []            # 覆盖的规则
invalidated_by:          # 被谁失效（裁决链上游）
  - SPECIAL_STRUCTURE_VALID
evidence_refs:
  - E-ZQ-STRENGTH-012
forbidden_derivations:
  - score
  - weight
  - count
  - percentage
```

**method_scope 枚举**：`ziping_zhenquan`(子平真诠) / `di_tian_sui`(滴天髓) / `qiong_tong_bao_jian`(穷通宝鉴) / `yuan_hai_zi_ping`(渊海子平) / `san_ming_tong_hui`(三命通会) / `disputed`(经典分歧，由顺天定夺)

**状态枚举规范**：`TRUE/FALSE/PRESENT/ABSENT`、结构状态 `EFFECTIVE/BLOCKED/DAMAGED/CONDITIONAL/TRANSFORMED`、方向状态 `DOMINANT/CONTESTED/MIXED/CONCENTRATED/FLOWING`、结果状态 `STRONG/WEAK/BALANCED/UNDETERMINED/...`。
