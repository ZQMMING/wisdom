# 盲派引擎接入八字排盘 — 案例内容验收报告

> 验收方式：**以引擎实际输出内容为准**，逐字段与盲派规则 V1-FINAL / 命局结构核对，
> 不以测试绿为标准。案例：公历 1980-06-22 10:00 男 广州。

|---|---|---|
| 年柱庚申 / 月柱壬午 / 日柱丙寅 / 时柱癸巳 | 与既有排盘验证一致 | ✓ |

## 二、盲派层（BlindBaziResult 全字段输出）

### 1. 宾主
```
main_branches:  [YIN(日支), SI(时支)]      # 主位=日+时
guest_branches: [WU(月支), SHEN(年支)]     # 宾位=年+月
```
✓ 位置归位正确（与应期引擎 [day,hour] 主位定义一致）。

### 2. 体用
```
ti_branches:  [YIN, WU, SHEN, SI]   # 体=比劫/印/食伤
yong_branches: [SI, SHEN]           # 用=财/官杀
yong_stems:   [GENG(偏财), REN(七杀), GUI(正官)]
```
✓ 逐支核对藏干分类：
- 申藏 庚(偏财=用)/壬(七杀=用)/戊(食神=体) → 申体用双属 ✓
- 巳藏 丙(比肩=体)/戊(食神=体)/庚(偏财=用) → 巳体用双属 ✓
- 午藏 丁(劫财)/己(伤官) → 体 ✓；寅藏 甲(偏印)/丙(比肩)/戊(食神) → 体 ✓
