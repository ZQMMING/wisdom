## 一、V3.2 一期六域三件套

每个域 = 引擎现状缺陷诊断 → 原书原文（布尔条件规则）→ 案例输出验证。

### 域一：燥土脆金（VERIFY-BLIND-031）

| 环节 | 内容 |
|---|---|
| 诊断 | V3.1 把未戌当普通土论生金，缺"燥土不生金反脆金"结构，制金/旺衰误判 |
| 原书 | 《段氏理象学》：**"四柱无水见未戌之燥土定主脆金"** |
| 布尔规则 | `TRIGGERED` = 日主五行≠金 AND 四柱无水 AND 存在未/戌燥土 AND 存在金(干或支)；`NOT_TRIGGERED` = 四柱有水（可生金）；`NO_DRY_EARTH` = 无未戌 |
| 案例验证 | C08（乙巳甲申辛酉乙未·辛金日主）= `NOT_TRIGGERED`（日主是金=脆自己，不触发）；D13 无燥土=`NO_DRY_EARTH`；D23（戊申壬戌戊午壬戌）有壬水=`NOT_TRIGGERED`——与 D23 降档（火燥土势）互不冲突，两域独立 |

### 域二：合绊（VERIFY-BLIND-021）

| 环节 | 内容 |
|---|---|
| 诊断 | V3.1 只认"合"不认"绊"（紧贴六合但被合之物失去自由），宾位合主位误入做功 |
| 原书 | 《盲派中级命理学》："**六合紧贴有合绊之意**"+"**有合先论合**" |
| 布尔规则 | 合绊 = 紧贴六合（干五合/支六合对）；按主宾位归因：全部宾位合 = `INEFFECTIVE`（不参与做功）；涉及主位 = `EFFECTIVE` |
| 案例验证 | C08 合绊归宾位 → 不因合绊升档（V3.1 亦 MEDIUM，非 V3.2 回归）；D28 合绊=EFFECTIVE 且属有效做功 |

### 域三：正反局（VERIFY-BLIND-035，R1-R4）

| 环节 | 内容 |
|---|---|
| 诊断 | V3.1 无反局概念；"日主追求 vs 原局结构对抗"全部漏判 |
| 原书 | 《盲派中级命理学》第01章（正局/反局定义） |
| 布尔规则 | R1：日支做功对象五行 == 势所制五行 → 对抗；R2：日主合财（追求）vs 原局制官杀（结构）→ 意向冲突；R3：年月合 vs 日时冲/反；R4：连体支被冲/穿/刑坏（制=做功不坏；合刑并存合优先） |
| 案例验证 | D28（己巳乙亥壬申丁未·黑道）= `FAN_JU(R2 日主合正财 vs 原局财制印+穿制七杀)` + LARGE，命中"原局大反局牢狱"；C07（戊申己未癸巳己未）= `ZHENG`（R4 巳申合刑并存取合，不再误判反局）；真实 D19（癸卯壬戌戊子甲子·济南地产）= `ZHENG`（R1 精确化后不误判 FAN_JU）；D29（辛卯辛丑丙辰甲午·车间主任）= `FAN_JU(R2)` |

### 域四：制尽三态（VERIFY-BLIND-034）

| 环节 | 内容 |
|---|---|
| 诊断 | V3.1 二态（COMPLETE/UNDETERMINED）粒度不足，制不净=DIRTY 语义被淹没 |
| 原书 | 段氏"制净/制不净"（盲派中级命理学做功章） |
| 布尔规则 | `CLEAN` = 制类目标支孤立（同类无党、无透干）且被制（含目标支被冲=根失）；`PARTIAL` = 有制类方法但目标尚有根气/同党；`UNDETERMINED` = 无制类方法 |
| 案例验证 | D13（庚辰乙酉癸卯庚申·孔祥熙）= `CLEAN`（卯酉冲卯根失=制净）→ 巨财；D23 = `PARTIAL`（制食伤不净）→ 降档；D42 反例（巳孤立但未被制）经"被制"判据修复后不再误 CLEAN |

### 域五：换象（VERIFY-BLIND-022 解锁施工）

| 环节 | 内容 |
|---|---|
| 诊断 | V3.1 无财星案例全部"无财看"落空，官杀/食伤当财结构漏判 |
| 原书 | 《盲派中级命理学》财命专辑 + 《命理珍宝》 |
| 布尔规则 | HX1 无财星有伤食/禄当财；HX3 制不净目标含官杀 = 官杀当财（限定制类方法目标支，防藏干误入）；HX4 比劫当财（旧方法）；HX5 合绊含官 = 官当财 |
| 案例验证 | D13 = `HUAN_XIANG_SHANGSHI_DANG_CAI`（食伤当财=巨财）；D29 = `HUAN_XIANG_GUANSHA_DANG_CAI`（官杀当财·车间主任）；D19 卯官当财（卯戌合）不误收（HX3 目标支来自制类方法 detail，月支戌藏干 CHOU 不再误入） |

## 三、6 个原始 BUG 修复（首次 10 锚点验证暴露）

| BUG | 现象 | 修复 |
|---|---|---|
| BUG-1 | R2 误收（日主壬合丁财把暗合/宾位合收进"追求"） | 只认日干与年/月/时透干天干五合 |
| BUG-2 | R4 连体支被"制"也判坏 | 只认冲/穿/刑坏连体，制=做功不坏 |
| BUG-3 | R4 附加"柱干被五合=连体被合坏"误伤戊癸合 | 撤销该判据 |
| BUG-4 | 合绊 set 重复（支对/干对重复计数） | 去重 |
| BUG-5 | 制尽 CLEAN 判不准（D13 卯根失未识别） | `_target_isolated` 增加"目标支被冲=根失" |
| BUG-6 | HX3 泛触发（任何制类都当官杀当财） | 限定制类方法目标支含官杀 且 PARTIAL |

另有 2 处架构修复：① `_resolve_work_efficiency` 调用位置从 5b 制尽之前移至 5f 换象之后（消费 CLEAN/PARTIAL 与换象，否则读到默认值）；② HX3 目标支改从"制 类方法 detail 中的支"提取（原 `zuo_gong_targets` 混入藏干支，如 D19 的 CHOU 误入）。
