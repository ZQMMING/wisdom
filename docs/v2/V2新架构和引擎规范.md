# 01. 产品定位

顺天不是：

```text
八字 + 紫微 + AI
```

也不是：

```text
多个命理程序 + 一个 LLM + 一个前端
```

顺天定义为：

> **以统一、可复现的时间与出生事实为基础，由多个独立传统计算体系产生可追溯证据，经统一辨层形成结构化判断，再经过解层与现代语义映射，并由受控 AI 完成最终表达的东方时间智能系统。**

核心结构：

```text
一入口
   ↓
一事实源
   ↓
多独立引擎
   ↓
独立计算
   ↓
独立证据
   ↓
统一辨层
   ↓
统一解层
   ↓
现代语义
   ↓
人工验证
   ↓
最终表达
```

```text

   ↓

   ↓
```

```text
   ↓
Bazi Foundation
   ↓
Canonical Bazi State
```

> **系统统一的出生事实与时间事实源。**

包括但不限于：

```text
birth_datetime
timezone
location
calendar_system
solar_time
true_solar_time
day_boundary
year_boundary
month_boundary
year_pillar
month_pillar

```

# 05. 一入口原则

所有以出生信息为基础的引擎：

```text

    ↓

    ↓

    ↓
```

禁止：


* 真太阳时

* 节气边界
* 年界
* 月界


# 23. 互补不比较

这是整个项目的核心原则之一：

> **互补，不比较。**

例如：

```text
子平 → 五行 / 十神 / 格局 / 时序
盲派 → 做功 / 宾主 / 应期
紫微 → 宫位 / 星曜 / 限运
河洛 → 数理 / 卦序 / 时间结构
梅花 → 卦象 / 体用 / 动变 / 事件关系
易经 → 象 / 辞 / 爻 / 理
黄历 → 公共时间信息
```

允许：

```text
A = B
A ≠ B
A 与 B 无直接关系
```

都不代表冲突。

只有：

> **违反本体系自身计算或规则契约**

才属于真正错误。

```text
Expression Only
```
