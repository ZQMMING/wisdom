# 1. LIORIN 前端总原则

## 1.1 产品核心

LIORIN 不是传统意义上的“算命网站”。

产品定位：

> **Oriental Time Intelligence System**

用户看到的不是复杂的术数系统，而是：

> 时间 → 状态 → 洞察 → 行动

后台系统遵循：

```text
算 → 辨 → 解
```

前台体验遵循：

```text
TIME
 ↓
STATE
 ↓
INSIGHT
 ↓
ACTION
```

两者必须保持严格边界。

---

# 2. 前后端职责边界

## 2.1 Frontend 负责

Frontend：

* 展示
* 交互
* 导航
* 状态渲染
* 动画
* Loading
* Error
* Empty State
* Responsive
* Accessibility
* i18n
* Analytics
* 用户输入
* API Contract 消费

Frontend 不负责：

* 八字计算
* 真太阳时计算
* 换日判断
* 时区判断
* DST 判断
* 紫微排盘
* 河洛计算
* 梅花起卦
* 爻选择
* Rule 判断
* Assertion 判断
* Judgment 生成
* 权限裁决

---

# 3. 最重要的禁止事项

Frontend 严禁：

```text
if (premium) {
    calculateSomething()
}
```

严禁：

```text
if (hour > 12) {
    useDifferentDay()
}
```

严禁：

```text
const activeLine = random(...)
```

严禁：

```text
frontend自行计算八字
frontend自行选择卦
frontend自行判断流日
frontend自行生成解释
frontend自行推断用户权限
```

所有计算结果必须来自 Backend Contract。

# 25. 流日卦

流日卦是订阅体系的核心视觉资产之一。

规则：

> 一个流日卦覆盖六天。

每天对应一爻。

```text
Day 1 → Line 1
Day 2 → Line 2
Day 3 → Line 3
Day 4 → Line 4
Day 5 → Line 5
Day 6 → Line 6
```

---

# 26. 流日卦 UX

用户不是每天得到一个完全不同的卦。

而是：

> **六天经历同一个卦的不同阶段。**

这形成连续性。

视觉：

```text
┌──────────────┐
│              │
│     卦象      │
│              │
│      ↑       │
│    当前爻     │
│              │
└──────────────┘

DAY 3 OF 6
```

---

```text

```

# 28. 当前爻动画

Subscriber：

```text
Hexagram
    +
Active Line
```

卦整体：

非常轻微呼吸。

当前爻：

更加明显但仍然克制的呼吸。

建议：

```text

scale 1.000 → 1.015 → 1.000

Active line:
opacity / glow / micro-scale
```

周期：

约 3–5 秒。

# 34. 河洛动画时序

建议：

```text
0–400ms
河洛出现

400–1200ms
轻微旋转

1200–1700ms
缩小 + opacity decrease

1700–2000ms
消失

2000–2500ms
Hexagram scale-in

2500–3000ms
稳定
```

最终时间应由 Motion Prototype 调整。

不要为了遵守数字而牺牲视觉。
