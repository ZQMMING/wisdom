## 二、布尔条件真值表（全布尔，无评分函数）

### EVT-MARRIAGE-001
```
palace_flags（配偶宫状态，flag 集合收敛枚举）:
  CLASHED  := BRANCH_CHONG(day_branch) ∈ 其余三支
  HARMED   := BRANCH_CHUAN(day_branch) ∈ 其余三支
  PUNISHED := day_branch ∈ BRANCH_SANXING_PAIRS[p] ∧ 另一支 ∈ 其余三支（含三刑拆对+自刑）
  HE_BANNED:= day_branch ∈ 任一 he_ban_structures
  palace_state := STABLE（无 flag）/ "_AND_".join(flags)

spouse_star_present  := 透干或藏干 ∃ 十神 ∈ 配偶星组（男=财 GROUP_CAI / 女=官 GROUP_GUAN）
spouse_star_weakened := 星所在支被冲 或 被穿

marriage_state :=
  HARMONIOUS  ← palace_state=STABLE ∧ star_present ∧ ¬star_weakened
  BROKEN      ← broken_palace ∧ star_weakened     （broken_palace:=含 CLASHED/HARMED/PUNISHED 任一）
  CHALLENGED  ← palace_state≠STABLE ∨ star_weakened（BROKEN 未命中时）
  UNDETERMINED← 其余（配偶星缺失等）
```

### EVT-WEALTH-001
```
wealth_present  := 透干或藏干 ∃ 十神 ∈ GROUP_CAI
wealth_positive := ∃ (m,a):（'财'∈m ∨ '冲开'∈m ∨ '冲库'∈m）∧ a=EFFECTIVE
substitution    := image_substitution ≠ UNDETERMINED（换象域）

wealth_state :=
  SUBSTITUTED_AND_ESTABLISHED ← substitution ∧ eff ∈ {LARGE, MEDIUM}
  SUBSTITUTED_CANDIDATE       ← substitution ∧ 其他 eff
  DIRECTED_AND_ESTABLISHED    ← present ∧ positive ∧ eff ∈ {LARGE, MEDIUM}
  DIRECTED_PARTIAL            ← present ∧ positive ∧ 其他 eff
  PRESENT_UNTAKEN             ← present ∧ ¬positive
  ABSENT_NO_SUBSTITUTION      ← ¬present ∧ ¬substitution
  UNDETERMINED                ← 其余
```


## 五、已知边界（L1e 不重判做功，由 L2 校正）

1. **C07 财制印归 INEFFECTIVE**：L1b 宾主归因将巳申合判为合绊，财制印未标 EFFECTIVE，故 L1e 报 PRESENT_UNTAKEN。C07 案例为金融巨头（V3.1 效率=MEDIUM 已承认做功）。按分层职责：L1e 只输出"无 EFFECTIVE 取财方法"这一结构事实，L2 消费 work_efficiency=MEDIUM 时校正为财路成立。**不在此层重判做功**（防 L1 层重复计算）。
2. **UNCONTROLLED 是结构枚举非吉凶断语**：C07/D38 等 UNCONTROLLED 表示"官杀未被制"这一事实，OFF-001"官杀无制必犯官非"仅在 L2 层消费（且需配合反局/其他结构）。
3. **BROKEN 是结构枚举**："配偶宫破+星损"是婚姻结构状态，不等于"必离婚"断语；吉凶定论在 L2。
