## 四、来源链（§57-59，每条事件强制）

```json
{
  "source_chain": {
    "palace": "day",
    "ten_god": "正财",
    "work_id": "EVT-MARRIAGE-001",
    "trigger_id": "chuan:大运:year:SHEN"
  }
}
```

- palace：年/月/日/时宫位（L1e 结构或 L1f trigger.position）
- ten_god：透干十神 / 支主气（首藏干）十神（L1f 支引动补取）
- work_id：产生该结构的 L1e 规则 id；时间层引动类为 UNDETERMINED（触发而非做功）
- trigger_id：L1f trigger 的 kind:source:position:branch
- 缺链 → 事件 status=UNDETERMINED（§59 fail-closed）

## 七、已知边界（L2 不越界）

1. **L2 输出事实吉凶术语，不做现代语言修饰**——"官非""血光"是术语枚举；转人话在 L3，吉凶词汇拦截也在 L3 出口。
2. **UNCONTROLLED 案例未逐条核对官非真实性**：D38（数亿企业）官贵=UNCONTROLLED 但非官非命——L2 只输出 OFFICIAL_OFFENSE_CANDIDATE（候选），需 L1f 时间触发+反局组合才升 ESTABLISHED（待 L1f 施工时接应期确认逻辑）。
3. **L1f 缺口未施工**：应事归属 WHO-WHAT-WHERE、象→事七级过滤（§58）、岁运反局 R5-R6 仍缺；L2 时间事件目前直接消费 triggers（来源链已补），§57 的完整应事归属在 L1f 施工时对齐。
4. **TIME 事件 work_id=UNDETERMINED**：时间引动类触发不指向做功结构；若需关联"引动哪个事件结构"，L1f 施工时补 work 映射。
