## 二、Provenance 标准格式定义

### 2.1 为什么需要标准 Provenance

当前 60bed0e 文档中的原典引用格式是：

```
《滴天髓·通神论·衰旺》："得地为旺，本气根为根气之最重者。"
（任铁樵注）
```

这个格式的问题：
1. 没有版本信息（哪个版本的《滴天髓》？）
2. 没有精确的章节定位
3. "任铁樵注"标注不够精确（是任铁樵的原文注，还是后人整理的？）
4. 没有 source_span（原文在书中的精确位置）
5. 没有 text_type（ORIGINAL / COMMENTARY / LATER_COMPILATION）

### 2.2 标准 Provenance 格式

```yaml
provenance:
  classic: "滴天髓"           # 经典名称
  edition: "任铁樵注本"        # 版本（必须明确）
  chapter: "通神论·衰旺"       # 章节
  text_type: "COMMENTARY"      # ORIGINAL / COMMENTARY / LATER_COMPILATION / UNCERTAIN
  author: "任铁樵"             # 作者（原文作者 vs 注疏作者）
  source_span: "第X页第Y行"    # 原文在书中的精确位置（如能确定）
  source_text: "得地为旺..."   # 原文精确引用
  verification_status: "VERIFIED"  # VERIFIED / PARTIALLY_VERIFIED / UNVERIFIED / DISPUTED
  verification_notes: "..."    # 核验说明
```

### 2.3 text_type 定义

| text_type | 含义 | 授权强度 |
|-----------|------|---------|
| ORIGINAL | 经典原文（京图/刘基/沈孝瞻等原作者的文字） | 最高 |
| COMMENTARY | 注疏（任铁樵注、徐乐吾注等） | 中高（但必须明确标注是注） |
| LATER_COMPILATION | 后人整理/汇编/通俗化解释 | 中低（不能直接当原典授权） |
| UNCERTAIN | 出处不确定，可能是后人伪托或整理 | 低（必须降级处理） |

### 2.4 verification_status 定义

| verification_status | 含义 |
|---------------------|------|
| VERIFIED | 已核对原书版本，确认出处精确 |
| PARTIALLY_VERIFIED | 已确认大致出处，但版本/章节/原文精确性待进一步核验 |
| UNVERIFIED | 仅从二手来源引用，未核对原书 |
| DISPUTED | 出处有争议，或可能是后人伪托 |

- **verification_status**：PARTIALLY_VERIFIED
- **verification_notes**：
  - 多个来源（国学典籍网、读书网、算准网）都引用了这段话，标注为《子平真诠·论十干得时不旺失时不弱》

  - 但尚未核对原书版本（徐乐吾评注本 vs 其他版本）

- **source_text**："得令则旺，失令则衰；根重则强，根轻则弱。"
- **verification_status**：UNVERIFIED / DISPUTED
- **verification_notes**：
  - **关键问题**：在搜索结果中，没有找到这句话的精确出处

### 证据 4-8：十神类证据（RESOURCE_SUPPORT / PEER_SUPPORT / OFFICER_CONTROL / OUTPUT_DRAIN / WEALTH_DRAIN）

#### 原引用（60bed0e 文档）

这五类证据的原典引用主要来自：
- 《渊海子平·论印绶》/《论比劫》/《论官杀》/《论食伤》/《论财星》
- 《滴天髓》相关论述
- 《子平真诠》相关论述

#### 核验结果

**关键问题**：60bed0e 文档中对这五类证据的原典引用比较笼统，没有给出精确的原文和出处。

例如：
- "《渊海子平·论印绶》：'印绶者，生我之神也。... 印绶喜财星，忌比劫。'"
- "《滴天髓》：'生我者为印绶，印绶者，生我之神也。'"

这些引用的问题：
1. 十神的定义（"生我者为印"）是基础事实，几乎所有命理书都有，不需要特别授权
2. 但十神的作用（"印生身"、"官杀克身"等）是命理判断，需要原典授权
3. 60bed0e 文档中引用的很多话可能是后人整理的，不是原典原文
4. 《渊海子平》版本复杂，"论印绶"、"论官杀"等章节的确切内容需要核对

**十神定义 vs 十神作用的区分**：

| 内容 | 类型 | 授权需求 |
|------|------|---------|
| "生我者为印" | 十神定义（基础事实） | 不需要特别授权（所有命理书共识） |
| "我克者为财" | 十神定义（基础事实） | 不需要特别授权 |

## 五、核心原则强化

### 5.1 推理强度 ≤ 原典授权强度（强化版）

| 原典授权强度 | text_type | verification_status | 系统最大输出强度 |
|------------|-----------|-------------------|----------------|
| AUTHORIZED | ORIGINAL | VERIFIED | CONFIRMED |
| AUTHORIZED | ORIGINAL | PARTIALLY_VERIFIED | CONFIRMED（但标注待进一步核验） |
| PARTIAL | ORIGINAL + 工程推导 | PARTIALLY_VERIFIED | QUALIFIED |
| PARTIAL | COMMENTARY | PARTIALLY_VERIFIED | QUALIFIED（必须标注是注） |
| NOT_AUTHORIZED | LATER_COMPILATION / UNCERTAIN | UNVERIFIED / DISPUTED | 不能作为辨证依据 |
| NOT_AUTHORIZED | 无可靠原典依据 | - | 仅作为结构事实记录 |

### 5.2 原文 vs 注疏的边界

**绝对禁止**：
- ❌ 把任铁樵的注当成《滴天髓》原文
- ❌ 把后人整理的口诀当成《渊海子平》原文
- ❌ 把徐乐吾的评注当成《子平真诠》原文
- ❌ 不标注 text_type，统一叫"《滴天髓》授权"

**必须做到**：
- ✅ 每条原典引用都标注 text_type（ORIGINAL / COMMENTARY / LATER_COMPILATION / UNCERTAIN）
- ✅ 注疏必须明确标注作者（任铁樵注、徐乐吾注等）
- ✅ 注疏的授权强度低于原文
- ✅ 出处不确定的引用必须标注 UNVERIFIED，不能作为强授权依据

### 5.3 防止工程推导偷偷升级成原典授权

**用户明确警告**：
> "不要让工程上的'合理命理推导'偷偷升级成'原典授权'。"

**具体防线**：

1. **结构事实 ≠ 辨证证据**
   - "本气根"是结构事实（地支藏干的本气与日主同类）
   - "本气根为根气之最重者"是辨证判断（需要原典授权）
   - 不能因为结构事实可靠，就把辨证判断也当成可靠

2. **十神定义 ≠ 十神作用**
   - "生我者为印"是十神定义（所有命理书共识）
   - "印生身 → 身强"是十神作用（需要原典授权）
   - 不能因为十神定义可靠，就把十神作用也当成可靠

3. **原典说 A ≠ 工程推导 A→B**
   - 原典说"得时俱为旺论"（A）
   - 工程推导"得令 → SUPPORT 证据"（A→B）
   - B 的授权强度必须低于 A，必须标注为 PARTIAL / QUALIFIED

4. **多来源引用 ≠ 原典授权**
   - 多个网站引用同一句话 ≠ 这句话是原典原文
   - 必须核对原书版本，确认精确出处
   - 找不到精确出处的，必须标注 UNVERIFIED
