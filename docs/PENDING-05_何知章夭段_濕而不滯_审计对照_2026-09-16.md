## 三、语义链分析（核心）

整段是「氣濁神枯之命」的**负面特征清单**，从「印綬太旺」到「皆壽歿之人也」全部是病态描述。关键在「濕而不滯，燥而不鬱」与「精流氣洩」的因果：

### 底本读法（濕而不滯，燥而不鬱）
- 濕而**不滯** = 湿气**失于凝滞**（水气散漫，不能凝聚）→ **精**（水之精）不聚而**流**
- 燥而**不鬱** = 燥气**失于蕴藏**（火气浮散，不能收敛）→ **氣**（火之气）不敛而**泄**
- **因果自洽**：不滯 → 精流；不鬱 → 氣洩。四句「X而不Y」全部是「功能失用型」病态（和、专、滞、郁这些正常功能全部失效）→ 精流氣洩 → 壽歿。**逻辑链完整。**

### 通行读法（湿而滞，燥而郁）
- 湿而**滞** = 湿气**壅塞凝滞**（内闭）
- 燥而**郁** = 燥气**郁结不舒**（内闭）
- **因果矛盾**：「滯/鬱」是内闭方向，「精流氣洩」是外泄方向——**既壅塞又外泄，方向相反，逻辑不通**。

### 语义判定
**底本「濕而不滯，燥而不鬱」在「氣濁神枯→壽歿」负面语境中是功能失用型病态，与「精流氣洩」构成完整因果链；通行本「湿而滞，燥而郁」与「精流气泄」方向矛盾。底本语义优于通行本。**
