**目标**: 验证"制中有生、生中有制"的语义完整性

---

## 一、问题发现

当前实现（P0-5.7 初版）只检查：
- `has_gen`: 是否存在相生关系
- `has_keeps`: 是否存在相克关系

**缺陷**: 
```
A 克 B  → has_keeps = True
C 生 D  → has_gen = True
→ 系统错误判定"生克制化"成立
```

这不符合原典语义。

---

## 二、原典语义分析

原文："生克制化，须制中有生，生中有制"

### "制中有生"
- 某五行被克制时，有另一五行生它（通关）
- 例如：木克土，但有火通关（木生火，火生土）
- 关系链：木 → 火 → 土

### "生中有制"
- 某五行生其他五行时，有其他五行克制它（制约）
- 例如：木生火，但有金克木（防止木过度生火）
- 关系链：金 → 木 → 火
