## 6. 已知边界

1. **中州派 0 matched** ⚠️
   - 中州 RuleGraph 期待特定中州讲义特征 (王亭之《飞星紫微斗数》中州派格式)
   - iztro v2.3 输出为标准格式, **不提供** P0-4 中州 RuleGraph 期待的中州派 evidence pattern
   - 这是 RuleGraph 设计预期, 不是引擎 bug
   - 解法: 需中州派真实命盘案例 (本仓库无)

2. **#5 主星入宫检查为结构性** (不是硬编码布局)
   - 30 命盘跨多年份, 每个样本的主星布局不同
   - 改用"14 主星全到 + 各宫不重复 + 命宫 1-2 主星"结构检查

3. **iztro v2.3 mutagen 字段位置**
   - iztro v2.3: `mutagen` 字段在所有 stars (major + minor)
   - 神杀级辅星 (文昌/文曲/左辅/右弼) 也有 mutagen
   - 必须过滤 type=="major" 且在 14 主星集合内
