## 四、核心原则确认

✅ Authorization Monotonicity（授权单调性）
- 聚合只能保持或降低确定性，不能凭空提高
- PARTIAL + PARTIAL ≠ COMPLETE
- UNRESOLVED → 阻断

✅ Evidence Isolation（证据隔离）
- 不同Primitive的证据不得互相借用
- 每个Primitive有独立的Evidence集

✅ UNRESOLVED 阻断
- 只要有UNRESOLVED存在，整体判断为UNRESOLVED
- 不会因其他条件成立而忽略UNRESOLVED
