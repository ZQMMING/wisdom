## 四、使用原则 (与 Governance Contract 一致)

1. **这些资料是原典数据, 不是候选索引** — 可以直接作为 Canonical Source 使用
2. **使用前必须定位原文** — 引用时必须标注: 经典名 + 篇章/卷目 + 原文上下文
3. **TEXT_LAYER 必须区分** — 原文 / 原注 / 后世注释 (如滴天髓的任氏曰)
4. **断语库是提取结果** — 使用断语时必须回查完整原文确认上下文, 不能仅凭断语片段授权
5. **覆盖率不足的部分要标注** — 如渊海子平篇目覆盖率仅8.9%, 三命通会主题覆盖率33.3%
6. **不为提高通过率强行授权** — 找不到原文就标 INSUFFICIENT_SOURCE
