## 二、冲突 1：旺衰优先 vs 调候优先（DTS vs QTBJ）

### 2.1 理论层分析

| 维度 | 滴天髓 (DTS) | 穷通宝鉴 (QTBJ) |
|------|--------------|-----------------|
| **核心命题** | 旺衰为根本 | 调候为优先 |
| **方法论** | 四柱五行系统观 | 月令季节决定论 |
| **用神取向** | 日主旺衰决定 | 季节气候决定 |
| **历史定位** | 清代·批判反思派 | 清代·实务导向派 |

#### DTS核心原文（44条证据）

> **"须观日主之衰旺，察生时之浅深，究四柱之用神，以论吉凶"** (E-DTS-105-001, E-DTS-106-001)

> **"人之日主不必生逢禄旺，即月令休囚，而年时日中，得长生禄旺，便不为弱"** (E-DTS-106-001)

> **"进退之机，不可不知也。非长生为旺，死绝为衰，必当审明理气之进退，庶得衰旺之真机矣"** (E-DTS-107-001)

#### QTBJ核心原文（1,233条证据）

> **"秋月之木，氣漸淒涼，形漸凋敗。初秋之時，火氣未除，尤喜水土以相滋"** (E-QTBJ-ADJ-005)

> **"寒暖适中时"** — 497条证据使用此条件

> **"调候得宜时"** — 497条证据使用此条件

- 方法论: 批判"不论日主之衰旺，总以财官为喜"

#### 场景A：甲日生于申月（秋季）

## 三、冲突 2：取用神标准差异（PZZQ vs YHZP）

> **"予尝观唐书所载，有李虚中者，取人所生年月日时干支生剋，论命之贵贱寿夭之说，已详之矣！至于宋时，方有子平之说；取日干为主，以年为根，以月为苗，以日为花，以时为果"** (E-YHZP-004-001)

> **"此命身旺...乃贵而有权"** / **"此命身弱...宜乎带病贫薄"** (E-YHZP-0488, E-YHZP-0489)

## 五、冲突 4：格局判定标准（PZZQ vs YHZP）

### 5.1 理论层分析

| 维度 | 子平真诠 (PZZQ) | 渊海子平 (YHZP) |
|------|-----------------|-----------------|
| **分类方法** | 二分法 | 三分法 |
| **正格** | 八格（财官印食杀枭刃） | 清格 |
| **杂格** | 从格、化格、专格等 | 浊格、混合格 |
| **判定标准** | 成败救应 | 清浊混合 |

#### PZZQ格局体系

```
正格（八格）：
  财、官、印、食 → 顺用
  杀、伤、枭、刃 → 逆用

杂格（外格）：
  从格、化格、专格等
```

#### YHZP格局体系

```
清格：纯而不杂
浊格：混杂不清
混合格：介于两者之间
```

### 5.2 冲突场景

```
同一命局判定:

某命：甲日卯月，月令劫财，透壬水偏印

PZZQ判定:
  - 月令劫财为用神
  - 透壬水印星为相神
  - 配合得宜 → 正格成功

YHZP判定:
  - 月令劫财，格局混杂
  - 透印可救 → 混合格
  - 清浊判断 → 中等层次
```
