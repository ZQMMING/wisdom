**下一步**：从单因子 → 组合因子归纳（本命结构特征 + 流年引动 + 大运），并按事件类型细分（健康：手术/病/意外等）。

互联网对照组校对发现：多数黄历网站（星座百科、抖音黄历号、乾元日历、汉程测试）的2026-08-27当日卦为**风山渐**，而非我们梅花易数算出的**风水涣**。

### 根因
黄历当日卦存在三套不同体系：
1. **六十甲子配卦**（多数黄历标准）：日柱干支直接映射固定卦象，癸酉→风山渐
2. **梅花易数时间起卦**（占卜用）：年月日时起卦，癸酉日子时→风水涣
3. **天天农历网时辰卦**（小众）：逐日卦表，癸酉日→天火同人

梅花易数适用于占卜问事（需特定时辰起念），不是黄历值日卦的标准体系。

### 方案
切换为六十甲子配卦，口诀"甲子甲午坤乾见，乙丑乙未嗑井连…癸酉癸卯渐妹添…此是玄空真秘诀"。完整60映射表源自易先生配卦表与口诀互证。

### 验证
- 癸酉→风山渐：2026-06-28和2026-08-27两个癸酉日在星座百科/抖音黄历号/乾元日历/汉程多源一致
- 甲子→坤为地、甲午→乾为天、癸卯→雷泽归妹、戊申→风水涣 等口诀关键值验证通过
- 24个黄历测试全绿（含新增test_ganzhi_hexagram_known_values）
- 梅花易数函数_meihua_daily_hexagram保留在代码中供其他场景使用

### 实施
- 新增_GANZHI_HEXAGRAM完整60映射表 + _ganzhi_daily_hexagram()函数
- get_day()切换为六十甲子配卦
- _SOURCE_IDS硬编码更新：meihua_daily_hexagram → ganzhi_daily_hexagram
- calendar_sources.json来源注册更新
- 测试期望值更新：风水涣→风山渐，移除动爻/变卦断言
- 六十甲子配卦为值日卦，无动爻变卦（moving/changed字段为空）

### 存疑
- 甲申和甲寅口诀"未既济"：表中均为水火既济，口诀暗示一为未济一为既济，待精核
- 个别干支（如辛巳=火天大有）口诀"有比连"解析为"大有+比"，与表一致
- 4个干支（甲子/庚寅/甲午/庚申）在易先生表中有双卦记录（运卦+本卦），取本卦（纯卦）
