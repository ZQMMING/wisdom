## 2. 设计目标

### 2.1 Admission Record 模型

```python
@dataclass(frozen=True)
class AdmissionRecord:
    """
    不可伪造的生产准入凭证。
    
    核心设计原则：
    1. 一旦生成，不可修改（frozen）
    2. 包含完整的审核溯源信息
    3. admission_hash 对 asset content + metadata 做完整性校验
    4. verified_by 是 AuditedIdentity，不是裸字符串
    """
    
    # ─── 资产标识 ───
    asset_id: str                    # 规则/资产的唯一标识（如 "ASR-P16-001"）
    asset_type: str                  # "RULE" | "EVIDENCE" | "ASSERTION"
    
    # ─── 原典溯源 ───
    source_work: str                 # 原典作品名（如 "子平真诠"）
    source_chapter: str              # 具体篇目
    passage_ref: str                 # 具体引文位置
    
    # ─── 审核身份 ───
    verified_by: "AuditedIdentity"   # 真实审核者身份（非裸字符串）
    verification_stage: str          # "SOURCE_VERIFIED" | "INDEPENDENT_AUDIT" | "GPT_ADJUDICATED"
    verification_version: str        # 如 "2026.09"
    
    # ─── 准入状态 ───
    admission_scope: "AdmissionScope"  # TEST_FIXTURE | SOURCE_VERIFIED | PRODUCTION_ADMITTED
    admission_timestamp: float       # Unix timestamp
    admission_id: str                # UUIDv7，唯一准入记录 ID
    
    # ─── 完整性校验 ───
    asset_hash: str                  # SHA-256(assets_content)
    admission_hash: str              # SHA-256(asset_hash + metadata_hash)
    
    # ─── 防伪造标记 ───
    synthetic: bool = False          # True = 测试/合成，不得进入生产
```

### 2.2 AuditedIdentity 模型

```python
@dataclass(frozen=True)
class AuditedIdentity:
    """
    可信审核身份。
    
    不是裸字符串，而是带有类型和来源的身份对象。
    防止 verified_by="admin" 这样的弱认证。
    """
    
    identity_type: str             # "HUMAN" | "AGENT" | "SYSTEM" | "GPT"
    identity_id: str               # 唯一标识（如 "audit-bot-v1", "claude-opus-20260902"）
    authority_source: str          # 身份授权来源（如 "admission_registry"）
    credential_hash: str = ""      # 可选：凭证哈希，用于跨系统验证
    
    def __post_init__(self):
        if not self.identity_id or len(self.identity_id) < 3:
            raise ValueError("identity_id must be non-empty and at least 3 chars")
```

### 2.3 AdmissionScope 枚举

```python
class AdmissionScope(str, enum.Enum):
    """
    三态准入范围，严格分离测试/审核/生产。
    
    TEST_FIXTURE:        测试 fixture，不得进入任何生产路径
    SOURCE_VERIFIED:     原典来源已确认，等待独立审计
    PRODUCTION_ADMITTED: 通过完整审核流程，可进入生产
    """
    TEST_FIXTURE = "TEST_FIXTURE"
    SOURCE_VERIFIED = "SOURCE_VERIFIED"
    PRODUCTION_ADMITTED = "PRODUCTION_ADMITTED"
```

### 2.4 Admission Registry 接口契约

```python
class AdmissionRegistry:
    """
    生产准入注册表。
    
    职责：
    1. 记录所有 Admission Record，建立 asset_id → AdmissionRecord 映射
    2. 验证 Admission Record 的完整性（hash 校验）
    3. 提供 PRODUCTION_ADMITTED 资产的查询接口
    4. 不允许外部直接修改（只追加，不覆盖）
    
    设计原则：
    - 持久化到文件系统或 DB（可选）
    - hash 链式结构，防止事后篡改
    - 与 _ProductionRuleLibrary 解耦
    """
    
    def register(self, record: AdmissionRecord) -> str:
        """注册一条 Admission Record，返回 admission_id。"""
        ...
    
    def verify(self, admission_id: str) -> Optional[AdmissionRecord]:
        """验证并返回 Admission Record，None = 不存在或已失效。"""
        ...
    
    def get_produced_assets(self) -> List[AdmissionRecord]:
        """返回所有 PRODUCTION_ADMITTED 的 Admission Record。"""
        ...
    
    def reject_synthetic(self, record: AdmissionRecord) -> bool:
        """检查并拒绝 synthetic=True 的资产。"""
        return record.synthetic and record.admission_scope == AdmissionScope.PRODUCTION_ADMITTED
```

## 3. G1–G4 接口契约

### G1: Admission Registry

**输入**: `AdmissionRecord` (frozen dataclass)
**输出**: `admission_id: str` (UUIDv7)
**不变量**: 
- `admission_hash` 必须匹配 `SHA-256(asset_hash + metadata_hash)`
- 一旦注册，不可修改（append-only）
- `PRODUCTION_ADMITTED` 的记录必须通过完整审核流程

**生产调用方**:
```python
# 在 ProductionRuleLoader.load() 内部调用
registry = AdmissionRegistry.from_file(path)
for rule in admitted_rules:
    record = AdmissionRecord(
        asset_id=rule.rule_id,
        asset_type="RULE",
        source_work=rule.provenance.source_work,
        source_chapter=rule.provenance.source_chapter,
        passage_ref=rule.provenance.passage_ref,
        verified_by=rule.provenance.audited_identity,
        admission_scope=AdmissionScope.PRODUCTION_ADMITTED,
        asset_hash=rule.hash(),
        admission_hash=compute_admission_hash(rule),
    )
    registry.register(record)
```

### G2: verified_by Identity Binding

**变更点**: `RuleProvenance.verified_by: str` → `RuleProvenance.verified_by: AuditedIdentity`

**生产调用方**:
```python
# 在 AssertionRule.provenance 中
provenance = RuleProvenance(
    source_work="子平真诠",
    source_chapter="论官杀",
    passage_ref="卷一·论官杀第一",
    verified_by=AuditedIdentity(
        identity_type="AGENT",
        identity_id="audit-bot-v1",
        authority_source="admission_registry",
    ),
    verification_scope=VerificationScope.PRODUCTION_ADMITTED,
    verification_version="2026.09",
)
```

**向后兼容**: 旧的 `verified_by: str` 字段在 `RuleProvenance.from_dict()` 中转换为 `AuditedIdentity(identity_type="LEGACY", identity_id=verified_by_str)`，但 `is_complete_for_production` 会拒绝 LEGACY 类型。

### G3: Synthetic Hard Stop

**变更点**: `ProductionRuleLoader.load()` 增加 `synthetic` 检查

**实现**:
```python
if provenance.synthetic:
    rejected.append(rule_dict.get("rule_id", "unknown"))
    logger.error(
        "ProductionRuleLoader: HARD REJECT %s — synthetic asset cannot enter production",
        rule_dict.get("rule_id", "unknown"),
    )
    continue
```

**测试**: 新增负向测试，验证 `synthetic=true` + `PRODUCTION_ADMITTED` → 硬拒绝。

### G4: Unified Production Gate

**变更点**: `AssertionRuleLibrary()` 直接构造 → 强制通过 `ProductionGate`

**设计**:
```python
class ProductionGate:
    """
    统一生产准入 Gate。
    
    所有 Production Asset 必须经过此 Gate：
    - ProductionRuleLoader.load() → ProductionGate.admit(rules)
    - 其他潜在入口（如 assertion_producer）也必须经过此 Gate
    
    当前状态：ProductionRuleLoader 是唯一入口，但 AssertionRuleLibrary() 仍可被构造。
    P2.1-D 目标：将 AssertionRuleLibrary 的构造路径也收敛到 ProductionGate。
    """
    
    @classmethod
    def admit(cls, rules: List[AssertionRule], registry: AdmissionRegistry) -> ProductionAsset:
        """将所有规则通过 Gate，返回 ProductionAsset。"""
        ...
```

## 6. 与 P1 Freeze Contract 的一致性验证

| P1 Freeze 原则 | P2.1 设计影响 | 一致性 |
|---------------|--------------|--------|
| `PRODUCTION_ADMITTED` 必须显式授权 | Admission Registry 强制显式注册 | ✅ 加强 |
| Assertion → Judgment fail-closed | 不改生产路径，只加强准入层 | ✅ 无影响 |
| Signal 不得绕过 Rule/Assertion | 不改 assertion matching 逻辑 | ✅ 无影响 |
| Production Runtime 唯一收敛路径 | 不改 ComputeStage 路径 | ✅ 无影响 |
| 互补不比较 | 不影响 cross_domain 语义 | ✅ 无影响 |
| LLM 无事实裁决权 | verified_by 可能含 "GPT" 类型，但不影响方向判断 | ✅ 无影响 |

**结论**: P2.1 设计完全符合 P1 Freeze Contract，且强化而非削弱安全边界。
