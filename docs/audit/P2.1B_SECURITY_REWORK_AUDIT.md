## 裁决背景

上一版 `8414c27` 的 P2.1 被裁决 **🔴 REWORK REQUIRED**，原因是：

> `object.__new__(AdmissionCapability)` 可以绕过 `__new__` 的 TypeError，
> 外部代码可伪造 AdmissionCapability 实例，击穿 G1 核心安全。

---

## 修复内容

### 1. G1: AdmissionCapability 不可伪造 (Critical Fix)

**旧设计（被击穿）**:
```python
class AdmissionCapability:
    def __new__(cls):
        raise TypeError(...)
# 攻击者: object.__new__(AdmissionCapability) → 成功绕过
```

**新设计（v7，无法绕过）**:
```python
class _AdmissionAuthority:
    __slots__ = ()
    def __new__(cls):
        raise TypeError("...")  # __new__ 也拒绝

    def __init__(self):
        raise TypeError("...")  # __init__ 也拒绝

# 模块级单例 — 唯一合法的 capability
_ADMISSION_CAPABILITY = object.__new__(_AdmissionAuthority)

class AdmissionRegistry:
    def __init__(self, capability):
        # 使用 is 检查（而非 isinstance）
        if capability is not _ADMISSION_CAPABILITY:
            raise TypeError("...")
```

**为什么无法绕过**:
- 攻击者无法调用 `_AdmissionAuthority()`（`__new__` 拒绝）
- 攻击者无法通过 `object.__new__(_AdmissionAuthority)` 创建等价对象
  （虽然 `object.__new__` 可以创建裸实例，但 `is` 检查会失败，因为
  攻击者创建的是新实例，不是模块级的 `_ADMISSION_CAPABILITY` 单例）
- `_ADMISSION_CAPABILITY` 是模块级私有变量（`_` 前缀），外部无法 import

**攻击测试**:
```python
# A1: object.__new__(AdmissionCapability) → TypeError（已修复）
cap = object.__new__(_AdmissionAuthority)
assert cap is not _ADMISSION_CAPABILITY  # is 检查失败
AdmissionRegistry(cap)  # → TypeError

# A2-A4: 伪造 identity → unregistered authority_source 拒绝
fake_identity = AuditedIdentity(
    identity_type=IdentityType.AGENT,
    identity_id="arbitrary",
    authority_source="unregistered",
)
registry._create_production_admission(..., verified_by=fake_identity)
# → ValueError: unregistered authority_source
```

### 2. G2: Identity Binding 增强

**新增方法**:
```python
class AuditedIdentity:
    def verify_authority(self) -> bool:
        """检查 authority_source 是否在预注册列表中。"""
        return self.authority_source in _AUTHORITY_CREDENTIALS

    def verify_credential(self) -> bool:
        """检查 credential_hash 是否与 authority_source 匹配。"""
        ...
```

**预注册机制**:
```python
_AUTHORITY_CREDENTIALS: Dict[str, str] = {}

def register_authority_credential(authority_source: str, credential_hash: str) -> None:
    _AUTHORITY_CREDENTIALS[authority_source] = credential_hash

def clear_authority_credentials() -> None:
    _AUTHORITY_CREDENTIALS.clear()
```

**生产路径**:
```python

if not provenance.verified_by.verify_authority():
    logger.error("HARD REJECT %s — unregistered authority_source '%s'", ...)
    continue
```
