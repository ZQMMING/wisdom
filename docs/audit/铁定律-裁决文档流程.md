# 铁定律 - 裁决文档流程

**生效时间：** 2026-08-31  
**约束级别：** 硬禁令（违反即停止）

---

## 规则内容

所有裁决文档必须遵循以下流程：

```
1. 推送到 GitHub (origin/main)
         ↓
2. 通过飞书通知用户文档位置
         ↓
3. 用户终裁
```

---

## 禁止行为

| 编号 | 禁令 | 原因 |
|------|------|------|
| T-01 | 裁决文档仅保存在本地，未推送到 GitHub | 无持久化、无审计追踪 |
| T-02 | 推送到 GitHub 后未通知用户 | 用户无法终裁 |
| T-03 | 绕过 GitHub 直接飞书发送 | 失去版本控制 |
| T-04 | 未经用户终裁直接执行裁决 | 违反三层权威分离 |

---

## 执行检查清单

每次裁决前检查：
- [ ] 文档已提交到 `D:/shuntian/backend/docs/audit/`
- [ ] 已推送到 `origin/main`
- [ ] 已通过飞书通知用户
- [ ] 等待用户终裁确认

---

## 违规后果

违反本规则的操作立即停止，记录违规日志，重新授权后方可继续。
