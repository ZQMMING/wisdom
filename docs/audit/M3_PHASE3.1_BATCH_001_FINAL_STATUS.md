- [ ] Primitive术语必须来自原典（非现代工程术语）
- [ ] 禁止混用不同体系术语（如滴天髓旺衰 + 子平格局）
- [ ] 必须证明术语出处

#### 3. 逻辑授权
- [ ] Composite的AND/OR/SEQUENCE必须有原典明确授权
- [ ] 禁止从"描述现象"推断"必然判断"
- [ ] 必须找到原典的条件判断语句（如"若...则..."）

#### 4. Judgment边界
- [ ] Judgment必须严格在原典授权范围内
- [ ] 禁止从"宜"升级为"必然"
