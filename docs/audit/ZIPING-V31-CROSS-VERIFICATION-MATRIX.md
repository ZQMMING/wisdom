## 验证规则

1. **每代理**:
   - 对分配的X项, 在本典 passages 中找≥2条原文支撑
   - 若本典无原文 → 标 `MISSING_IN_<典>`
   - 若本典与他典矛盾 → 标 `CONFLICT_WITH_<其他典>`
   - 若本典有细化但口径一致 → 标 `CONFIRMED`
   - 若本典明确否定 → 标 `REJECTED`

2. **汇总**:
   - ≥2 典籍 CONFIRMED → 标 **CROSS-VERIFIED** (生产可用)
   - 1 典籍 CONFIRMED + 其他 MISSING → 标 **SINGLE-SOURCE** (待加佐)
   - 多典 CONFLICT → 标 **DISPUTED** (需User裁决)
   - 全部 MISSING → 标 **UNVERIFIED** (禁止断言)

3. **输出格式**: 每代理产出 JSON, 包含: X项ID, 各典结果, 交叉裁定, 原文引用
