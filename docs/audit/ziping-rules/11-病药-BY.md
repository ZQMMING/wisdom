# 11-病药（BY）子平辨证维度 · 全量规则校订底稿

> 维度：**病药（BY）** ｜ 依据规范：《子平布尔规则引擎规范 V1》§12 + 《子平生产规则注册表 V3.1-FINAL》§20/§29/§61
> 本文件为经典原文检索与校订底稿：逐条把 V1 骨架规则与五部经典原文比对，引文一律『经典名·篇名 + passage_id』逐字摘录，定位不到即标『原文未定位』，不编造。
> 依据经典：《滴天髓·病药》「有病方为贵，无伤不是奇；格中如去病，财禄两相随」

**核心原则**：病 = 局中过旺/过弱之点；药 = 制病之神。病药两立则贵，病重药轻则困，病重无药则败。

## 三、经典矛盾 / 方法分歧清单

- **病≠忌**：滴天髓"有病方为贵"与把"忌神"直接等同"病"之法分歧；病药是否独立于喜忌。
  - 方A：滴天髓：病在五行偏枯，药去病则贵。
  - 方B：喜忌法：忌神即病（误）。
  - 处理：V3.1 §61：病=结构失衡（过旺/过弱），非忌神；病药与喜忌分属不同维度。
