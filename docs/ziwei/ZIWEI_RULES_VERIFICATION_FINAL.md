## 二、各流派方法论体系

### 2.1 三合派（南派）

**原典依据**：
- 《紫微斗数全书》（陈希夷传）
- 《紫微斗数捷览》（万历九年，1581年）
- 《紫微斗数全集》（晚清通行本）

**核心方法**：
```
1. 安星顺序：安命身十二宫 → 起寅首 → 定纳音五行局 → 
           安紫微星 → 安其余13颗主星 → 安辅曜神煞星
2. 论命核心：三方四正（命宫+财帛+官禄+迁移）
3. 格局判断：以星曜组合为主，参考庙旺利陷
4. 运限使用：小限 + 大限 + 流年合参
5. 流星群：大限流耀（运马、运羊等）、流年流耀（流马、流羊等）
```

**原典口诀**（已验证代码一致）：

```
【安命身宫】
寅起正月，顺数至生月，逆数生时为命宫。
寅起正月，顺数至生月，顺数生时为身宫。

【起寅首】
甲己年生起丙寅，乙庚年生起戊寅，
丙辛年生起庚寅，丁壬年生起壬寅，
戊癸年生起甲寅。

【定五行局】
甲乙金四局、丙丁水二局、戊己火六局、庚辛土五局、壬癸木三局

【大限方向】
大限由命宫起，阳男阴女顺行；阴男阳女逆行。

【三方四正】
命三方：命宫、财帛宫、官禄宫
福三方：福德宫、夫妻宫、迁移宫
田宅三方：田宅宫、兄弟宫、疾厄宫
交友三方：交友宫、父母宫、子女宫
```

**证据等级**：A级（有古籍原文可逐条核对）

---

### 2.2 中州派

**原典依据**：
- 王亭之《谈斗数》《紫微斗数讲义》
- 《紫微星诀》（传为宋代吴景鸾撰）

**核心特点**：
```
1. 安星法：同三合派基本一致
2. 四化表：戊/庚/壬干特殊（辅弼不入四化，改用太阳/天府）
3. 流年流耀：流昌、流曲（其他派别无流曲）
4. 星曜体系：六十星系互涉理论
5. 空宫借星：对宫主星全借（比三合更严格）
```

**特殊规则**（已核实）：

| 差异点 | 三合派 | 中州派 |
|--------|-------|-------|
| 戊干科星 | 右弼化科 | 太阳化科 |
| 庚干科星 | 太阴化科 | 天府化科 |
| 壬干科星 | 左辅化科 | 天府化科 |
| 流曲 | 无 | 有 |
| 空宫借星 | 部分借 | 全借对宫 |

**证据等级**：B级（现代论述，古谱声称但无独立佐证）

---

### 2.3 飞星派（梁若瑜系）

**原典依据**：
- 梁若瑜《专论四化》
- 《十八飞星策天紫微斗数全集》（传明·黄家骋）

**核心方法**：
```
1. 四化体系：以宫干飞化为主（每个宫位的天干飞出四化）
2. 论命核心：四化串连（禄忌串连、向心/离心）
3. 命盘简化：只用18颗星系即可论命
4. 运限使用：只用流年，不用小限
5. 流耀：不用流曜
```

**术语定义**（原文引用）：
```
飞化：出生年和宫位中的『天干』与『星曜』之间所产生的对应关系
化出宫：A宫的天干与B宫的星曜产生飞化，A宫称为化出宫
化入宫：A宫的天干与B宫的星曜产生飞化，B宫称为化入宫
坐：禄权科坐於某宫
照：禄权科坐於某宫，照对宫
冲：忌坐於某宫，冲对宫
自化：宫位自天干引发自身四化
```

**证据等级**：B级（现代论述系统，古谱引用）

---

### 2.4 钦天门（北派）

**原典依据**：
- 蔡明宏《华山钦天四化紫微斗数飞星秘仪》
- 传自袁阿详→赖圆英→张梅→素心老人

**核心特点**：
```
1. 四化体系：与三合同，但重点在自化系统
2. 自化分类：离心化（本宫天干飞出自化）、向心化（他宫飞入）
3. 立极宫：以某一宫为太极中心展开分析
4. 佛道融合：主张"命随人心转"
5. 精简星曜：重点用18主星，辅星简化
```

**关键术语**：
```
向心化：他宫飞入本宫的四化（如命宫飞忌入夫妻，视为向心）
离心化：本宫飞出自化（如命宫自化忌）
立极：以某一宫为太极中心重新审视全盘
来因宫：生年四化所在宫位揭示此生课题根源
```

**证据等级**：C级（口传为主，公开文献有限，历史真实性有争议）

```
六五四三二，酉午亥辰丑，
局数除日数，商数宫前走；
若见数无余，便要起虎口，
```
