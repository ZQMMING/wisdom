| 《紫微斗数捷览》 | 明万历九年（1581） | ✅ 有刻本 | 最早以"紫微斗数"命名 | A级 |
| 《紫微斗数全集》 | 晚清木刻本 | ✅ 流通最广 | 安星诀、论命歌诀 | A级 |
| 梁湘润标点本 | 现代 | ✅ 学术界公认最佳整理本 | — | B级 |

**关键证据摘录**：
```text
【庚干四化差异 - 明代原版】
《紫微斗数全书》嘉靖序刻本：
  庚：太阳化禄、武曲化权、太阴化科、天相化忌

后世通行版（含倪海厦体系）：
  庚：太阳化禄、武曲化权、太阴化科、天同化忌

争议原因：
  1. 明代刻本原文为"天相化忌"
  2. 后世可能因"天同化气为福，不主化忌"而改
  3. 中州派沿用"天同化忌"但有特殊处理（见下文）
```

**中州派特殊声明**：
```text
【中州派四化表差异 - 王亭之明确声明】
来源：《王亭之谈斗数》、百度百科"中州派"词条

声明内容：
  "庚、戊和壬干的四化星也和传统的有所不同"

具体差异：
  戊干：以太阳/天府化科替代右弼化科
  庚干：以天府化科替代太阴化科
  壬干：以天府化科替代左辅化科

传承脉络：
  白玉蟬/吴景鸾（唐代）→ 口传 → 陆斌兆 → 王亭之（公开传播）
```
