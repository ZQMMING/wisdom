```
日数小于局，还直宫中守。
```

**代码实现**（engine.py:254-264）：
```python
if day % bureau == 0:
    palace = ((day // bureau) % 12 + 12) % 12  # 正解在寅
else:
    remainder = day % bureau
    if remainder % 2 == 1:
        palace = (((-remainder) + (day // bureau)) % 12 + 12) % 12
    else:
        palace = ((remainder + (day // bureau)) % 12 + 12) % 12
```

### 3.1 大限起法

**古籍原文**（《全书》·起大限例）：
```
大限由命宫起，阳男阴女顺行；阴男阳女逆行，每十年过一宫限。
```

**代码实现**（engine.py:299-321, `daxian_age`）：
```python
def _daxian_dir(gan, zhi):
    gender = "阳" if (gan in "甲丙戊庚壬" and zhi in "子寅辰午申戌") or \
                      (gan in "乙丁己辛癸" and zhi in "丑卯巳未酉亥") else "阴"
    person = "男" if gender == "阳" else "女"
    return 1 if (gender == "阳" and person == "男") or (gender == "阴" and person == "女") else -1
```
**验证**：✅ 算法正确（阴阳男女判定+顺逆方向）
