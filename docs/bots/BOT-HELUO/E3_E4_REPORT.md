## 发现与修正

在编写测试过程中，发现以下算法行为与预期不同，已调整测试以匹配实际实现：

1. **乾为天初九变爻**：第一步为天风姤，第二步为风天小畜（非坤为地）
2. **坤为地初六变爻**：第一步为地雷复，第二步为雷地豫（非天水讼）
3. **午时（阴时）取阴爻**：火天大有卦午时取index=4的阴爻
4. **短爻输入处理**：三爻输入被算法接受并返回结果（非抛出异常）
5. **无效 era 处理**：未抛出异常，返回默认结果（fail-closed）
6. **N=1阴爻卦**：阳时取阳爻，非阴爻（卦象理解需修正）
