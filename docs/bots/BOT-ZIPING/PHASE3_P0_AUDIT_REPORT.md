### 1.4 P0 问题：日主强度默认值

**代码位置**:
```python
# temporal_context_contract.py:154
day_master_strength: str = "MODERATE"  # 问题：被动fallback

# context_assembler.py:203
day_master_strength=getattr(chart, 'day_master_strength', 'MODERATE'),  # 问题：静默默认
```

**根因分析**:
- BaziEngine 不计算 `day_master_strength`（符合CanonicalState冻结规范）
- ContextAssembler 使用 `getattr` 获取该字段，无则返回 `"MODERATE"`
- 这导致所有八字都被静默标记为"中和"，无法正确反映真实强弱

**修复方案** (fail-closed):
```python
# temporal_context_contract.py:154
day_master_strength: str = "MISSING"  # 改为显式缺失标记

# context_assembler.py:203
_dm_strength = getattr(chart, 'day_master_strength', None)
if _dm_strength is None:
    raise ValueError("day_master_strength 未计算，无法进行辨证")
day_master_strength=_dm_strength,
```
