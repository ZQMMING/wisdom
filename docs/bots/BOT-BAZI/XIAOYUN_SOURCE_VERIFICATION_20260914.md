## 二、算法原文（逐字摘录）

### 口径 A：正文定论（SMTH_0244）
> "此小运所以**男起丙寅顺行，女起壬申逆行**，一定而不可易也。觧者谓男子阳火元气起戊子三十丁巳十月至丙寅此木生火，女之阴水元气起庚子二十辛巳十月至壬申为金生水，此其数也。…**或者以甲子旬如上起甲申旬男起丙戌女起壬辰，甲午旬男起丙申女起壬寅，甲辰旬男起丙午女起壬子，甲寅旬男起丙辰女起壬戌，则非。**"

要点：
- 起点固定：男命一律**丙寅**，女命一律**壬申**（与生时、年柱无关）
- 顺逆：男**顺行**、女**逆行**
- 明确驳斥"按生时所在旬另起"（旬起法 → "则非"）

### 口径 B：引述醉醒子（SMTH_0245）
> "醉醒子以为**男女小运皆由时生而行之逆顺亦以年定**，如阳命阳年甲子时生，**堕地即行乙丑，二岁丙寅**，一位一年，周而复始。阴命阳年逆行亦然。尝试用之屡验。…**童限未交大运专用此法**。"

要点：
- 起点由**生时柱**定（甲子时生 → 堕地即行乙丑 = 时柱顺推一位）
- 一岁一位，一年一换
- 顺逆以年定（阳命阳年顺行？文中"阴命阳年逆行亦然"——逆顺由年之阴阳定）

### 口径 C：按旬起法（被正文驳斥）
甲子旬起丙寅…甲申旬男丙戌女壬辰…——SMTH_0244 明言"则非"，**不可采**。

## 三、异文与疑点

1. **女起起点异文**：SMTH_0243 作"男起丙寅**女起丙申**"，SMTH_0244 定论作"女起**壬申**"。两处不一致（传抄异文或版本差异），以定论段 SMTH_0244"壬申"为准，但需在实现时标注。
2. **口径 A 未言明岁数起法**：正文未明确"出生当年行丙寅/壬申，还是满一周岁起"。结合"小运掌一岁之灾祥"与醉醒子"堕地即行"（口径 B 明确），口径 A 的起岁点需裁决（出生即行 vs 周岁起）。
3. **口径 B 逆顺规则未全展开**："行之逆顺亦以年定"只给了"阴命阳年逆行亦然"一例，未穷举四类（阳男/阴男/阳女/阴女）与年干阴阳的组合。若采口径 B，逆顺判定表需按原文推导并标注推导依据。

## 四、命例核验

SMTH_0245 有"尝试用之屡验"的叙述性背书，但未附完整命例；卷九"六庚日庚辰时"命例（`...太岁戊辰小运庚辰，己未五十四岁凌迟死`）只有流年/小运干支，无完整四柱与起岁，**不足以唯一验证口径 A 或口径 B**。无可用 oracle 佐证。
