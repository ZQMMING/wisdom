# 第一部分 · 流年卦的起卦（推演）

## 一、基础定位（大象 / 小象）
- **大象**（先天卦/后天卦的大运）：类似八字的**大运**
- **小象**（流年卦）：类似八字的**流年**
- **月日时三卦**：类似流月、流日、流时
- **节候卦**：节气对应卦
- 河洛理数是**查询式**字典，非解读式——流年卦出来后直接查64卦逐爻判词

## 二、大运排法（阳9阴6）
- 大运从**元堂爻**起，自下往上
- **阳爻管9年、阴爻管6年**
- 行到上爻回头，再行到元堂下一位
- 先天卦行完再转后天卦元堂行

## 三、流年卦推演（核心）

### 方法一：大运爻法（阳爻大运行9个流年）
1. 确定流年落在先天/后天卦的哪个**大运爻**内
2. 以该大运爻起排流年卦
3. **大运初年为阳年**：以先天/后天卦为第1个流年卦；然后依次变爻得第2-9卦：
   - 第2卦：变换与大运爻**相隔两爻**的爻阴阳
   - 第3卦：变换**大运爻位置**的爻
   - 第4卦：变换大运爻**上一爻**…依此类推
4. **大运初年为阴年**：先变换大运爻阴阳作为第1卦，其余同

### 方法二：阴爻大运（行6个流年）
- 不论阴年阳年：先变换大运爻阴阳为第1卦；再以第1卦为本变换大运爻上一爻为第2卦，依此类推共6卦

### 方法三：小象逐岁法（国学软件/四岁起）
- 自4岁起以流年卦为基准自下往上一岁一爻
- 一岁流年为阴年：元堂爻阳变阴、阴变阳后为流年卦
- 二岁取元堂之**应爻**变化；三岁取二岁卦之应爻变化……

## 四、流月卦（当年流年卦→12月）
- 先起阳月卦（一、三、五、七、九、十一月）：以当年流年卦为本，变元堂前一爻为正月卦，逐月向前
- 后起阴月卦（二、四、六、八、十、十二月）：由阳月卦变应爻而得
- **卢某案例**：流年卦大畜(艮)，流月卦为正月大有、二月鼎、三月艮、四月渐、五月剥、六月坤、七月晋、八月噬嗑、九月否、十月讼、十一月萃、十二月咸

# 第二部分 · 解卦核心框架

## 一、解卦四要素
| 要素 | 作用 |
|---|---|
| **得时** | 出生月份与卦之旺时是否相符（如乾卦属四月、乾金秋旺） |
| **纳甲本命** | 出生年干支是否在卦的纳甲范围 |
| **叶 / 不叶** | 命局与卦爻时机相合（叶）或不合（不叶），决定吉凶程度 |
| **岁运逢爻** | 流年/大运走到某爻，结合爻辞断具体事件 |

## 二、元气化工（命之根基）
- **元气**（年柱配合）= 类似比劫印：人生得元气 → 富寿宜高位
- **化工**（月柱配合）= 类似食伤财官：人生得化工 → 荣显作名公
- **流年遇元气** → 必然得财利
- **流年遇化工** → 中举中进士、生贵子
- **关键**：元气化工是命之根基、年之用神；爻辞虽凶不免灾眚，但于富贵天年不碍。**不要拘泥爻辞吉凶**

## 三、爻辞三层断法（叶者 / 不叶者 / 岁运逢之）

每爻爻辞判词固定分三层：

### 1. 叶者（与时机相合）
- 命理吉象、富贵之兆
- 例乾九二"见龙在田"：叶者贵而有利名、富有产业

### 2. 不叶者（与时机不合）
- 命理凶象、困顿之兆
- 例乾上九"亢龙有悔"：不叶者自尊自大、招尤启衅

### 3. 岁运逢之（走大运/流年到此爻）
- 按身份细分：
  - **在仕**（官员）：升迁/贬谪
  - **在士**（读书人）：科甲/淹留
  - **在庶俗**（平民）：财利/灾病
  - **女命**：婚姻/内助
- 例乾九五"飞龙在天"岁运逢之：在仕未遂清高之职位、在士飞黄腾达、在庶俗遇尊贵抬举

## 四、正对反对卦（生死大凶断）
- 凡流年先后天**大象**遇正对/反对卦，更值爻辞凶、卦无元气化工 → **必死**；不死亦有横灾
- **正对**：此阳彼阴（六爻全对换）
- **反对**：本卦倒转（上下旋转180度）
- 命卦正对/反对是《复》《临》《泰》《大壮》《夬》《乾》《姤》《遁》《否》《观》《剥》《坤》之一 → 不吉（若卦中相生或与月卦相投可去凶）

## 五、数之凶吉（数凶者身亡）
- **天数/地数有余** → 按出生时月判断吉凶
- 例卢某：地数40为有余 → 生于三月（谷雨-芒种）不可妄行致凶 → **数凶**
- 判词补充："数凶者身亡，但德小者不能当之"

# 第四部分 · 流年卦解卦实战案例

## 案例一：卢某（女）——流年卦定位死年，流月卦定位死月

**命造**：1964年三月初七生，八字 甲辰 戊辰 丁酉 癸卯。死于1987年3月车祸（23岁）。

**起卦**：
- 先天卦：屯(坎)；后天卦：豫(震)
- 天数30（有余）、地数40（有余）
- 年干元气相反(坤)、年支元气相反(震)

**解卦过程**：
1. **数凶**：地数40为有余 → 判词"谷雨到芒种之候不可妄行致凶" → 卢某生三月正合此候 → 数凶
2. **23岁流年卦 = 大畜(艮)**，元堂上九：
   - 判词："叶者间世奇英，当时重望，功高千古；不叶者志大心高，机深祸重。变泰上爻，有城复于隍之象"
   - 诗："天衢一道总亨通，深浅根基谩费工。一个妇人携锦袱，龙牙虎爪伏场中"——描述妇人被龙牙虎爪撕碎 → **流年大凶**
3. **流年卦大畜之流月卦**：二月 = 鼎(离)：
   - 判词："岁运逢之，在仕未仕者进职…数凶者身亡，但德小者不能当之" → **二月死**

**结论**：流年卦大畜定23岁必死，流月卦鼎定死于阴历二月（3月）。**三层卦（数凶→流年卦→流月卦）逐层定位应期**。

## 案例二：一掌经×河洛合参（B站学员实战）

- 命主先天卦反元气、爻辞不吉 → 易有无妄之灾
- **25年流年卦 = 雷地豫**，卦气阴过重 → 防小人；但坤为天元气、坤卦解灾 → 无大碍
- 启示：流年卦 + 串宫压运（一掌经）合参可互证

## 案例三：SO玄奥命例（2013年乾造）——81年流年卦逐岁爻辞

**先天艮为山 / 后天地山谦**，完整81年流年卦+爻辞：
- 1岁山地剥（六三剥之无咎）、2岁坤为地（上六龙战于野其血玄黄·凶）、3岁地山谦（九三劳谦吉）、9岁天泽履（六三履虎尾咥人凶）、56岁地水师（六三师或舆尸凶）、62岁山地剥（上九君子得舆小人剥庐）……
- 解卦要点：每岁流年卦**动爻爻辞**即该年吉凶要义

# 第五部分 · 解卦步骤总结

## 完整解卦流程
1. **看流年落哪个大运爻**：先天/后天卦的大运爻（阳9阴6）
2. **排出该年流年卦**（大运爻法 / 小象逐岁法）
3. **看流年卦的元堂/动爻**：动爻爻辞即该年吉凶要义
4. **查64卦逐爻判词**（三门观易/原典）：
   - 叶者：吉象
   - 不叶者：凶象
   - 岁运逢之：按在仕/在士/在庶俗/女命细分
5. **看元气化工**：流年遇元气得财、遇化工中举生贵子；爻辞凶但元气化工足，仅灾眚不碍富贵
6. **看正对反对卦**：流年大象遇之 + 爻辞凶 + 无元气化工 → 生死大凶
7. **看数之凶吉**：天地数有余/不足，按生月合节判断
8. **细看流月卦**：定位应期到月份（必要时流日卦到日）

## 解卦心法
- 河洛理数是**查询式字典**——流年卦出来直接查判词，不用命理师解读
- **"数"（天地数）与"时"（生月合节）**是根本，爻辞是应验细节
- 爻辞未言吉凶者，吉凶自取，靠后天修为改运（非宿命论）
- 与紫微（定宫定流）、一掌经（串宫压运）可合参互证
