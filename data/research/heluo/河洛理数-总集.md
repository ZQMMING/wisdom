# 第一部分 · 基本框架与起卦

## 一、河洛理数是什么
- **作者**：传为宋·陈抟著、邵雍述
- **核心思想**：把四柱八字转化为**河洛数**，再演化为**卦**，用卦象、卦辞、爻辞推演命运吉凶
- **性质**：查询式字典（流年卦出来直接查判词），非解读式；与八字最大不同是"十神 vs 八卦"——八字以干支关系定十神，河洛理数以干支数字算八卦

## 二、完整推演步骤（六步）
1. **排四柱八字**：排出出生年、月、日、时的干支
2. **干支换算河洛数字**：分**天数（奇数）**、**地数（偶数）**
3. **求先天卦**：以天地余数求得**先天卦（本命根基）**
4. **寻元堂爻**：从出生时辰推出**元堂爻**（一卦核心，等同八字日主）
5. **变后天卦**：由先天卦 + 元堂爻变出**后天卦（人生发展走势）**
6. **起大运流年**：依托元堂爻，排出大运、流年、流月、流日卦，并按卦辞爻辞断吉凶

## 三、干支换河洛数（起卦基础）

**地支取数（口诀）**：
- 亥子一六水，寅卯三八真
- 巳午二七火，申酉四九金
- 辰戌丑未五与十（土）

**奇偶分天地**：
- **天数** = 奇数之和
- **地数** = 偶数之和
- 天数减25（或倍数）余数取卦，地数减30（或倍数）余数取卦

**取卦法**：余数去掉十位以个位取卦（0则以十位；得5用寄宫法）。阳男阴女天数在上地数在下；阴男阳女相反。口诀：一数坎兮二数坤，三震四巽数中分，五寄中宫六乾是，七兑八艮九离门。
- 若个位得0则以十位取卦；得10以1数取坎，得20以2数取坤；得5用寄宫（分上中下三元：上元阳干寄离/阴干寄兑等）

## 四、先天卦与后天卦
- **先天卦**：本命根基、先天属性，是"体"，影响一辈子（性格中最强、最猛的性向）
- **后天卦**：人生发展走势、后天修为，是"用"
- **变法**：先天卦上卦作后天卦下卦、下卦作上卦，同时**元堂爻阴阳互变**
  - 例：先天卦火山旅（元堂九三爻）→ 后天卦地火明夷（元堂上六爻）
  - 例：天风姤（元堂上九）→ 后天风泽中孚（元堂三爻）
  - 例：比卦三爻 → 蹇卦 → 上下对调 → 蒙卦上爻

**至尊卦换卦**（特殊）：坎、水雷屯、水山蹇作为先天命卦，元堂在九五或上六时变法不同：
- 元堂九五阳爻：生阴月不换上下卦（坎→师、屯→复、蹇→谦）；生阳月换上下卦（坎→比、屯→豫、蹇→剥）
- 元堂上六阴爻：生阴月换上下卦（坎→井、屯→恒、蹇→蛊）；生阳月不换（坎→涣、屯→益、蹇→渐）
- 出生月阴阳：阳月=一、三、五、七、九、十一月；阴月=二、四、六、八、十、十二月

## 五、元堂爻（核心概念）
- **元堂**：先天卦中的一个爻，由出生时辰推出，等同八字的**日主**
- 是先天卦中的"动爻"，变此爻得后天卦
- 阴阳时生人取法不同：
  - **阳时生**（子丑寅卯辰巳）：寻卦中阳爻论，自下而上
  - **阴时生**（午未申酉戌亥）：寻卦中阴爻论，自下而上
  - 一/二阳（阴）爻需重数再寄；三阳（阴）爻只往复不寄；四/五阳（阴）爻先寄后往复；纯阳（乾）/纯阴（坤）男女取法有别

## 六、大运、流年与八字的类比
- 大运：先天卦元堂爻起，自下往上，**阳爻管9年、阴爻管6年**；行到上爻回头，行到元堂下一位，再换后天卦元堂行
- 流年：自4岁起以流年卦为基准自下往上一岁一爻；阴年则元堂爻阴阳互变后起卦
- 与八字类比：
  - **元堂** = 日主
  - **元气**（年柱配合）= 类似比劫印
  - **化工**（月柱配合）= 类似食伤财官
  - **大象**（先天卦大运）= 类似八字大运
  - **小象**（流年）= 类似流年
  - 月、日、时三卦 = 流月、流日、流时；节候卦 = 节气对应卦

# 第二部分 · 流年/流月/流日/气候卦 推演算法（完整版）

## 一、推演总览
```
先天卦 + 元堂爻
   ├── 大运卦（阳9阴6年）——类似八字大运
   ├── 流年卦（一年一卦）——类似八字流年（小象）
   ├── 流月卦（一月一卦）
   ├── 流日卦（一日一卦/一爻）
   └── 气候卦（二十四气）
```

## 二、大运卦排法
- 阳爻值运**9年**、阴爻值运**6年**
- 由先天命卦的**元堂爻**开始，自下向上行；行完上爻后从初爻再行，直到行到元堂下一爻（即行完先天六爻）
- 之后从**后天命卦的元堂**开始行起，方法同
- 岁数均为**虚岁**（出生即1岁）
- 例：先天卦艮为山（元堂九三）→ 第一运管2013(1岁)-2021(9岁) [阳爻9年]

## 三、流年卦推演

### 方法一：大运爻法
1. 先确定流年落在先天/后天卦的哪个**大运爻**内，再以该大运爻起排流年卦
2. **阳爻大运（行9个流年）**：
   - **大运初年为阳年**：以先天/后天卦为第1个流年卦；然后依次变爻得第2-9卦：
     - 第2卦：变换**与大运爻相隔两爻**的爻阴阳
     - 第3卦：变换**大运爻位置**的爻阴阳
     - 第4卦：变换大运爻**上一爻**
     - 第5卦：变换大运爻**上两爻**…依此类推至第9卦
   - **大运初年为阴年**：先变换大运爻阴阳为第1卦，其余同
3. **阴爻大运（行6个流年）**：不论阴年阳年，先变换大运爻阴阳为第1卦；再以第1卦为本变换大运爻上一爻为第2卦，依此类推共6卦

**实例：甲子年出生（元堂在六爻）**
- 一至九岁流年运：甲子年生 → 本大运首年为阳年 → 以本卦为第1流年卦，逐爻变
- 十至十五岁：起阴爻大运流年卦
- 十六至廿四岁：己卯年（阴年）→ 变换大运爻阴阳为第1卦

### 方法二：小象逐岁法（每爻代表一年）
**原典原文（起例卷上）**：
> 下而上不必取應亦無陰陽之分。假如同人六二爻為元堂，則一變為乾九二，再變為履六三，三變為中孚六四，四變為損六五，五變為臨上六，六變為師初六。一年變一爻為一卦，餘倣此。

- 以元堂爻为起点，**一年变一爻**，自下而上推演流年卦
- 初爻为阳爻：根据年份阴阳决定是否变爻（阳年不变、阴年变）
- 初爻为阴爻：直接变爻，每一年一变，与初阳爻剩余爻变化方式相同
- **每爻代表一年** → 一生流年卦逐年推出

### 方法三：国学软件法（四岁起）
- 自4岁起以流年卦为基准自下往上一岁一爻
- 一岁流年为阴年：元堂爻阳变阴、阴变阳后为流年卦
- 二岁取元堂之**应爻**变化；三岁取二岁卦之应爻变化……

## 四、流月卦推演

### 起月卦例（原典原文·观卦上九为元堂例）
> **凡起月卦，就年卦中前一位起，單月變爻，雙月變應爻。**
> 假如觀卦上九為元堂，流年進一位，從初爻變起：
> - 正月：變觀初六為益初九
> - 二月：變益六四為夬九四（益上卦三爻，双月变应爻）
> - 三月：變益六二為中孚九二
> - 四月：變中孚九五為損六五
> - 五月：變小畜六三為夬九三
> - 六月：變小畜上九為需上六
> - 七月：變小畜六四為乾九四
> - 八月：變乾初九為姤初六
> - 九月：變乾九五為夬六五
> - ……（依此类推）

**关键规则**：
- **單月（阳月）變爻**：从年卦元堂前一位（初爻）起，逐爻向上变，得正月、三月、五月、七月、九月、十一月卦
- **雙月（阴月）變應爻**：在阳月卦基础上，变该月所动爻的**应爻**，得二月、四月、六月、八月、十月、十二月卦

### 壹风水方法（同原典，现代表述）
1. 先起**阳月卦**（一、三、五、七、九、十一月）
2. 后起**阴月卦**（二、四、六、八、十、十二月）
3. 以每年之**流年卦为本**，变元堂（如流年刚好在先天/后天卦内，则以先天/后天卦元堂位计）**以前一爻**为正月卦，逐月向前变换得出阳月卦
4. 阴月卦由阳月卦变换而得：以正月卦之变爻的**应爻**变换成二月卦，三月之变爻的应爻再变换成四月卦，依此类推

### 起月卦定式（识典古籍原文·节气）
> 月卦之法，悉從二十四氣，非從朔望也。
> - 子月起者，冬至一氣也；午月生者，夏至一氣也
> - 前以正月起者，非（注意：不能一律按农历正月起）
> - 子月、丑月冬至小寒大寒，乃去年三氣，非本年節候；子月大雪一氣乃本年節候
> - **陽世、陰世者，論本歲元堂之爻也**

**要点**：流月卦从**节气**起（冬至/夏至定子午月），不从农历朔望起！

## 五、流日卦推演

### 月卦推日卦（原典卷例·万历二十三年七月）
> 其法將月卦為主。假如萬歷二十三年七月月卦是既濟二爻，除此爻不變，只將既濟九三變為屯六三，**每管六日**，自下爻行至上爻，蓋取六日也。
> 然日卦行起必須按月卦節氣方不誤。如本年七月初二日午時立秋節，則屯卦初九爻即從初二日午時管起，屯卦二爻……（以此类推）

### CSDN 步骤（即济卦月爻在二爻为例）
- **Step1**：从月卦爻**下一爻**开始，自下而上进行**五个爻**的爻变，每个新卦代表**6天**
- **Step2**：每卦自下而上用**每爻代表一天**
- **注意点**：
  - 每个卦自下而上用每个爻代表一天
  - 每天日期都使用**阴历**
  - 1~6天并非代表每月初一到初六（需按节气调整）
- **节气调整**：日爻遇到二十四节气中当日为**节（月初）**或**气（月中）**时，所代表日期需要变更
  - 例：屯卦本代表初一到初六，但该月初二立秋（节），则初爻不能作为初一，而作为**立秋节开始时**（文中精算到立秋从初二午时开始）

### 起日卦例（原典·乾卦为例）
> 假如乾九二居位，進一爻起節氣。假如正月節氣在十二月小盡二十八日立春，就從二十八日起數是也：
> - 二十八日變乾九三為履六三
> - 二十九日變履九四為中孚六四
> - 初一日變中孚九五為損六五
> - 初二日變……

**要点**：流日卦从**节气日**起算（如立春日起），逐日变爻得当日卦。

## 六、气候卦（节气卦）
- 河洛理数除流年/流月/流日外，还有**气候卦**（对应二十四节气）
- 节=月初、气=月中；流日卦的日期变更与节气密切相关

**易冒引河洛理数（冬至起卦）**：
> 期日卦爻，以謂冬至法頤六四，而震、兌、坎、離弗能均布其中，因置於升降之外也。其法以冬至日起山雷頤之六四，一日行一爻，一月行五卦，一年共六十卦；而震兌坎離加於二至二分之時，弗能自然，故置於升降之外。**獨河洛理數貴之。**凡正月小過……

## 七、起月日数（断流月流日吉凶·纳音法）
- **流年数 + 月建数 = 月数**，以千百为上旬、十位为中旬、个位为下旬，断流年中**流月**之吉凶
- **月数 + 日建的大定数 = 日数**，便见**一日**之事吉凶，须凭星辰考之
- **月数吉凶节要**：
  1. 先看流年：流年吉，月数吉，其福应在此月；流年凶，月数凶，其祸应在此月
  2. 凶星与太岁相冲祸不可言，吉星与太岁相合福自天来
  3. 以卦前后断吉凶：如坤在乾前、兑在离前，其年作事反复

# 第三部分 · 解卦体系

## 一、解卦四要素
| 要素 | 作用 |
|---|---|
| **得时** | 出生月份与卦之旺时是否相符（如乾卦属四月、乾金秋旺） |
| **纳甲本命** | 出生年干支是否在卦的纳甲范围（如乾卦纳甲甲子甲寅甲辰壬午壬申壬戌） |
| **叶 / 不叶** | 命局与卦爻时机相合（叶）或不合（不叶），决定吉凶程度 |
| **岁运逢爻** | 流年/大运走到某爻，结合爻辞断具体事件（仕/士/庶俗/女命不同） |

## 二、爻辞三层断法（叶者 / 不叶者 / 岁运逢之）
每爻爻辞判词固定分三层：
1. **叶者**（与时机相合）：命理吉象、富贵之兆
   - 例乾九二"见龙在田"：叶者贵而有利名、富有产业
2. **不叶者**（与时机不合）：命理凶象、困顿之兆
   - 例乾上九"亢龙有悔"：不叶者自尊自大、招尤启衅
3. **岁运逢之**（走大运/流年到此爻），按身份细分：
   - **在仕**（官员）：升迁/贬谪
   - **在士**（读书人）：科甲/淹留
   - **在庶俗**（平民）：财利/灾病
   - **女命**：婚姻/内助

## 三、元气化工（命之根基）
- **元气**（年柱配合）= 类似比劫印：人生得元气 → 富寿宜高位
- **化工**（月柱配合）= 类似食伤财官：人生得化工 → 荣显作名公
- **流年遇元气** → 必然得财利
- **流年遇化工** → 中举中进士、生贵子
- **关键**：元气化工是命之根基、年之用神；爻辞虽凶不免灾眚，但于富贵天年不碍。**不要拘泥爻辞吉凶**

## 四、正对反对卦（生死大凶断）
- 凡流年先后天**大象**遇正对/反对卦，更值爻辞凶、卦无元气化工 → **必死**；不死亦有横灾
- **正对**：此阳彼阴（六爻全对换）
- **反对**：本卦倒转（上下旋转180度）
- 命卦正对/反对是《复》《临》《泰》《大壮》《夬》《乾》《姤》《遁》《否》《观》《剥》《坤》之一 → 不吉（若卦中相生或与月卦相投可去凶）

## 五、数之凶吉（数凶者身亡）
- **天数/地数有余** → 按出生时月判断吉凶
- 例卢某：地数40为有余 → 生于三月（谷雨-芒种）不可妄行致凶 → **数凶**
- 判词补充："数凶者身亡，但德小者不能当之"
- 天数至弱（4-8）、地数至弱（8-12）；阳数太过（40-60）等特殊数理

# 第六部分 · 实战案例

## 案例一：卢某（女）——流年卦定位死年，流月卦定位死月
**命造**：1964年三月初七生，八字 甲辰 戊辰 丁酉 癸卯。死于1987年3月车祸（23岁）。
**起卦**：先天卦屯(坎)、后天卦豫(震)；天数30（有余）、地数40（有余）；年干元气相反(坤)、年支元气相反(震)。

**解卦过程**：
1. **数凶**：地数40为有余 → 判词"谷雨到芒种之候不可妄行致凶" → 卢某生三月正合此候 → 数凶
2. **23岁流年卦 = 大畜(艮)**，元堂上九：
   - 判词："叶者间世奇英，当时重望，功高千古；不叶者志大心高，机深祸重。变泰上爻，有城复于隍之象"
   - 诗："天衢一道总亨通，深浅根基谩费工。一个妇人携锦袱，龙牙虎爪伏场中"——描述妇人被龙牙虎爪撕碎 → **流年大凶**
3. **流年卦大畜之流月卦**：正月大有、二月鼎、三月艮、四月渐、五月剥、六月坤、七月晋、八月噬嗑、九月否、十月讼、十一月萃、十二月咸
   - 死于1987年3月=阴历二月 → 二月 = 鼎(离)：判词"岁运逢之，在仕未仕者进职…数凶者身亡，但德小者不能当之" → **二月死**

**结论**：流年卦大畜定23岁必死，流月卦鼎定死于阴历二月（3月）。**三层卦（数凶→流年卦→流月卦）逐层定位应期**的完整范例。

# 第七部分 · 断命核心原则汇总

## 一、河洛理数断命七步
1. 排四柱八字
2. 干支换河洛数（分天数奇数/地数偶数）
3. 求先天卦（天地余数）
4. 寻元堂爻（出生时辰）
5. 变后天卦（先天+元堂）
6. 排大运流年流月
7. 综合判断：阳数、阴数、元堂、元气、化工、卦象、得势、得时、得体

## 二、判断依据要素
| 要素 | 作用 |
|---|---|
| **元堂** | 一卦核心，等同日主，看先天性格与起点 |
| **元气** | 年柱配合，影响富寿官位 |
| **化工** | 月柱配合，影响荣显科甲贵子 |
| **得时** | 出生月份与卦之旺时是否相符 |
| **得势** | 卦象整体气势 |
| **得体** | 卦象是否合乎本命 |

## 三、大运流年规则
- **大运**：阳爻管9年、阴爻管6年，从元堂起向上
- **流年**：先天卦阳爻行9个流年，阴爻行6个流年
- **流月**：当年流年卦为本，变元堂前一爻为正月卦，逐月变换（单月变爻、双月变应爻）
- **流日**：月卦爻下爻起，自下而上5爻变，每卦代表6天，遇节气日变更

## 四、非宿命论
- 爻辞未言吉凶者，吉凶自取，靠后天修为改运（如刘君祖"比之匪人"可转吉）
- 先天本命为体，后天修为可改运
- "君子得舆，小人剥庐"——是君子还是小人有智慧德行决定

# 第八部分 · 核心要点与学习路径

## 核心要点总结
1. **时间粒度**：大运（阳9阴6年）→ 流年（一年一卦）→ 流月（一月一卦）→ 流日（一日一卦）
2. **推演链条**：先天卦+元堂 → 后天卦 → 大运卦 → 流年卦 → 流月卦 → 流日卦，层层下钻
3. **解读核心**：看流年/月/日卦的**动爻爻辞**，结合叶/不叶、数之凶吉、岁运逢爻断吉凶
4. **应期定位**：用流年卦定年份、流月卦定月份、流日卦定日期（如卢某：流年大畜→23岁，流月鼎→阴历二月）
5. **现代应用**：可与紫微（定宫/定流）、一掌经（串宫压运）等合参，互为验证
6. **非宿命论**：卦辞未言吉凶者吉凶自取，靠后天修为改运

## 学习路径
1. 先掌握**干支→河洛数→先天卦**的起卦
2. 再学**元堂爻位式**（阴阳时、爻数规则）
3. 学**先天卦变后天卦**（上下对调+元堂变爻）
4. 学**大运流年排法**（阳9阴6）与**流月/流日卦**推演
5. 最后学**卦辞爻辞断命**（叶/不叶、岁运逢爻、身份分断）

## 注意事项
- 断卦重在**"象、数"**结合——象（卦象）与数（河洛数）
- 分析卦象断吉凶罕有真传，靠个人悟性与易卦修为
- **河洛理数非宿命论**：先天本命为体，后天修为可改运；爻辞未言吉凶者，吉凶自取
