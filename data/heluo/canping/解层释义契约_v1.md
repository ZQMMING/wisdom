# 河洛参评诗断 解层释义契约（封板版）

> 版本：v1.0 封板｜2026-09-16
> 适用：参评诗断（金锁银匙四位编号六句诗）+ 五命/扩展断语，永久复用。
> 总原则：**原文证据 → 释经 → 精义 → 现代释义**，禁止 原文→LLM自由发挥→用户故事。

---

## 一、解层分层（永久）

```
L0 事实（生辰/性别/地域/节气）
 ↓
L1 河洛计算（策数/太元/卦变）
 ↓
L2 金锁银匙定局（出参评编号）
 ↓
L3 参评诗断（本契约：六句诗 → 精义 → 现代释义）
 ↓
L4 卦爻辞 / 卦象断语（已完成，706 单元）
 ↓
L5 五命扩展断语（五块单独建表，见三）
 ↓
Evidence / Assertion → 精义 → 现代释义 → 前端表达
```

**状态判断铁律**：以后任何模块的「解层完成」，必须分层报——哪层已做、哪层没做。
禁止再说「解层完成」，必须说「L3 参评诗断解层 / L4 卦爻辞解层 / L5 五命扩展解层」分别到哪一步。

## 二、单条释义 Schema（L3 参评诗断，每条固定六字段）

```json
{
  "no": "3306",
  "part": "jin",
  "source_text": ["鶴在白雲棲", "鴟鴞不翔舉", "..."],
  "jingyi": "精义：只概括这一组诗断真正在判断的命理/人生主题。",
  "modern_explanation": "现代释义：把精义翻译成现代人能直接懂的话。",
  "semantic_tags": ["标签1", "标签2"],
  "evidence_basis": "释义依据：哪几句象、用了什么典故，原文哪句支撑。"
}
```

### 字段职责（精义 ≠ 现代释义，严格分两层）

| 字段 | 干什么 | 禁止干什么 |
|---|---|---|
| **source_text** | 原书六句诗原文，一字不动 | 不改字、不补句 |
| **jingyi 精义** | 概括本组诗断**真正判断的命理/人生主题**（一两句） | ❌ 加原文没有的吉凶；❌ 编具体事件；❌ 现代心理学解释；❌ 扩成段落 |
| **modern_explanation 现代释义** | 把精义换成现代人能直接理解的语言（两三句） | ❌ 扩大原断语适用范围；❌ 鸡汤化；❌ 加原文没有的预测 |
| **semantic_tags** | 从原文意象抽 2~4 个中性标签（如「清高自守」「才高位下」「际遇反差」） | ❌ 贴无原文依据的标签；❌ 用子平/盲派/紫微术语 |
| **evidence_basis** | 写明释义靠哪几句、什么象/典故支撑 | ❌ 无依据空泛说「此诗吉」 |

`kuozhan_duanyu.json` 五块**各自独立建释义映射**，不与参评诗断混表：

## 四、LLM 释经禁则（硬线，违者返工）

释经时以下行为**一律禁止**：

1. ❌ 原文没有的吉凶，自行补充成「必富贵 / 必破败」
2. ❌ 把诗断解释成具体事件（如「你会离婚」「你会发财」）
3. ❌ 把传统术语强行心理学化（如「心象」「内在小孩」）
4. ❌ 把一句诗扩展成一大段现代鸡汤
5. ❌ 混入子平、盲派、紫微任何别家判断
6. ❌ 为了「好懂」改变原断语边界（范围、吉凶、对象）
7. ❌ 无 evidence_basis 的「想当然」释义

**可做**：忠于原文意象的主题概括；把文言判断转成现代白话；标注典故出处。
