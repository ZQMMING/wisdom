# 河洛（heluo）CI 依赖锁定 —— 主仓（2026-10-26）
#
# ⚠ 为什么单独一份，不直接用主仓 pyproject.toml
#   主仓是**多引擎共仓**（ziwei / bazi / blind / platform / yi …），
#   `pyproject.toml` 的 `[project].dependencies` 是**跨引擎的公共契约**
#   ⇒ 改它会影响所有引擎的安装 ⇒ **不属河洛域，不动**。
#
#   但河洛引擎对依赖有**比公共声明更高**的要求：
#     · `sxtwl>=2.0.0` —— 节气窗口/节气月序/真太阳时都基于 sxtwl 2.x 的 API；
#       公共声明写的是 `sxtwl>=1.0.0` ⇒ 理论上允许装 1.x
#       ⇒ **河洛 CI 在这里收紧到 2.x**（域内自保，不动公共声明）。
#     · 其余依赖与公共声明一致。
#
# ⚠ 若公共声明与本文件冲突
#   **以本文件为准**（河洛 CI 专用）。两条 pip 命令的先后顺序是
#   「先装公共依赖 → 再用本文件覆盖版本」⇒ 本文件的约束最终生效。
#
# ⚠ 与独立包 `requirements-ci.txt` 的关系
#   两者**版本一致**（同一套已验证组合）⇒ 两边 CI 的行为可比。
